## 2. 選択規則の安定性（val のみ・test 不使用）

5 規則を **同一の学習軌跡**から評価した。規則ごとに別 run を回していないため、
規則間の差は純粋に「規則の効果」である。

| 規則 | `val_metric_sd`(mean) | (max) | `epoch_spread`(mean) | `epoch_sd`(mean) |
|---|---:|---:|---:|---:|
| **R-topk（採用）** | **0.000900** | 0.001746 | 6.33 | 3.40 |
| R-acc（現行・基準） | 0.000979 | 0.002499 | 7.08 | 3.92 |
| R-loss | 0.001042 | 0.004122 | 2.17 | 1.23 |
| R-mf1 | 0.001666 | 0.004395 | 9.25 | 5.06 |
| R-last | **0.002439** | 0.007301 | **0.00** | **0.00** |

分母: 系統 × seed の 24 群（8 系統 × 3 seed）、各群 3 反復。`val_metric_sd` は val accuracy 基準。

**判定: RULE_INEFFECTIVE。** 採用された R-topk は R-acc 比 **0.920** で、
閾値「R-acc の半分以下」に遠く届かない。

### 決定的な反証: R-last

`epoch_spread = 0.00` / `epoch_sd = 0.00` で **選択ノイズが構造的にゼロ**であるにもかかわらず、
`val_metric_sd` は **5 規則中最悪（R-acc の 2.5 倍）**。
→ **ばらつきは epoch 選択ではなく学習軌跡そのものにある。**

補足: R-loss は「val loss は連続値で同点が起きにくい」という機構的理由で優先順位最上位に
置いていた。実際 `epoch_spread` は 2.17（R-acc の 7.08 に対し約 1/3）まで下がったが、
`val_metric_sd` は R-acc をわずかに上回った（0.001042 vs 0.000979）。
**epoch の選択が安定しても val 指標の安定性には結びつかなかった。**

### val 曲線の平坦さ（機構の想定自体は正しかった）

| 指標 | top1−top2 gap(mean) | (median) | ±0.001 以内の epoch 数 | 後半 50% の sd |
|---|---:|---:|---:|---:|
| val_accuracy | 0.001146 | **0.000660** | **2.22** | 0.004741 |
| val_loss | 0.020964 | 0.014715 | 1.04 | 0.059954 |
| val_macro_f1 | 0.002245 | 0.001490 | 1.56 | 0.008926 |

分母: 全 72 run。val accuracy の top1−top2 の中央値 **0.000660** は
**ちょうど 1 フレーム分（1/1515 = 0.000660）**であり、±0.001 以内に平均 2.22 epoch が入る。
val loss は gap が 18 倍大きい。
**「val accuracy は量子化されていて平坦」という想定は実在した。しかし直しても効かなかった。**

## 7. 以前の結論を改訂する点（n=9 で判定が変わった対比）

| 対比 | 指標 | 以前 | M2 (n=9) | 変化 |
|---|---|---|---|---|
| (5−1) | test/incision | 非超過（S3: +0.0343, p=0.2123） | **+0.0176, p=0.0048** | **非超過 → 超過** |
| (9−2) | test/macro-F1 | 非超過（S4: +0.0241, p=0.1987） | **+0.0144, p=0.0087** | **非超過 → 超過** |
| (8−7) | test/accuracy | 非超過（S4: +0.0016, p=0.8935） | **+0.0079, p=0.0177** | **非超過 → 超過** |
| (3−2) | test/incision | **超過**（G-2: −0.0308, p=0.0034） | −0.0068, p=0.3384 | **超過 → 非超過** |
| (4−2) | test/incision | **超過**（G-2: −0.0382, p=0.0300） | −0.0141, p=0.1257 | **超過 → 非超過** |

**(1) S3 の PASS は維持されない。** (5−1) が超過したため S3 の判定規約では
「**中間**（次元と情報の寄与を (2−5)/(2−1) の比で定量化）」に該当する。

| split | 指標 | (2−1) | (5−1)＝次元由来 | (2−5)＝情報由来 | (2−5)/(2−1) |
|---|---|---:|---:|---:|---:|

**test/incision では効果の 43.7% が次元由来**であり、S3 で「排除できていない」と記録した
規模の次元寄与が n=9 で実際に検出された。ただし (2−5) は全指標で超過しており、
**情報由来が主である**ことは変わらない。

**(2) G-2 の「マスク化は incision を有意に悪化させる」の根拠は弱まった。**
(3−2)(4−2) の test/incision は n=9 では点推定が 1/4〜1/3 に縮んで非超過になった。

G-2 の解釈（「劣化要因は背景除去ではなく画素数の減少」）は、
その根拠となった 2 つの超過がいずれも消えたため保留すべきである。

**(3) 手の効果は工程局在の形では現れない。** (9−2)(8−7) は overall（accuracy / macro-F1）
でのみ超過し、主指標の per-phase F1 では test 0/3・1/3 にとどまる。

## 8. 非決定性の発生源（M1-4・コードから確認）

対象 `scripts/train_g2.py`。設定されている seed は **`:172` の 1 行のみ**:
`random.seed(args.seed); np.random.seed(args.seed); torch.manual_seed(args.seed)`

| 項目 | 設定 | 備考 |
|---|---|---|
| `torch.cuda.manual_seed_all` | 未設定 | `:172` の `torch.manual_seed` が CUDA 側も seed するため実質的な欠落ではない |
| `use_deterministic_algorithms` | 未設定 | — |
| `cudnn.deterministic` | 未設定 | 既定 False |
| `cudnn.benchmark` | 未設定 | 既定 False |
| `worker_init_fn` | 未設定 | **かつ適用外** |
| `torch.Generator` | 未設定 | **かつ適用外** |
| `PYTHONHASHSEED` | 未設定 | **かつ適用外** |

`train_g2.py` は **`DataLoader` を使わない**（`grep` 0 件）。学習ループは Python リスト `tr` を
`random.shuffle`（`:195`）してから直接反復する（`:197`）。したがって
`worker_init_fn` / `torch.Generator` / `PYTHONHASHSEED` の 3 項目は
**この trainer では原理的に非決定性の発生源になり得ない**。

残る最有力候補は **cudnn の非決定的カーネル**（`tecno_head.py:32-33,51` の `nn.Conv1d` の
backward は atomics を使い得る）。学習側に `autocast` は無い
（`autocast` は特徴抽出 `build_roi_channels.py:258` のみ）ので混合精度は要因ではない。

## 9. 残る UNKNOWN と次手

- **非決定性の直接の発生源は未特定。** ただし**選択規則ではないことは確定した**（§2）。
  **次手は `use_deterministic_algorithms(True)` / `cudnn.deterministic=True` を入れて
  同一 seed が bit 一致するかを検証すること。** M2 では規則の効果と交絡させないため入れていない
- **動画は val 2 本 / test 3 本のまま。** n を 9 に増やしても動画方向の一般化は保証されない。
  符号一致の帰無確率は val 0.50 / test 0.25 で、慣習的な有意水準には原理的に到達しない
- **(8−7) が val 部分集合で 5/5 非超過・test 部分集合で 2 項目超過した理由は UNKNOWN。**
  val は mask≠bbox が 88.7% で希釈が小さいにもかかわらず超過しない
