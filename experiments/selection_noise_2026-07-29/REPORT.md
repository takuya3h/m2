## ★ 重大な発見 1: 選択規則は run 間ばらつきの主要因ではない

**§6 に従い専用セクションを立てる。本タスクの前提を覆す結果である。**

M2 は 5 規則を**同一の学習軌跡**から評価した（規則ごとに別 run を回していないので、
規則間の差は純粋に「規則の効果」である）。

| 規則 | `val_metric_sd`(mean) | (max) | `epoch_spread`(mean) | `epoch_sd`(mean) |
|---|---:|---:|---:|---:|
| R-acc（現行） | 0.000979 | 0.002499 | 7.08 | 3.92 |
| R-last | **0.002439** | 0.007301 | **0.00** | **0.00** |
| R-loss | 0.001042 | 0.004122 | 2.17 | 1.23 |
| R-mf1 | 0.001666 | 0.004395 | 9.25 | 5.06 |
| **R-topk（採用）** | **0.000900** | 0.001746 | 6.33 | 3.40 |

分母: 系統 × seed の群数（8 × 3 = 24 群）、各群 3 反復。`val_metric_sd` は val accuracy 基準。

**決定的な反証は R-last である。** `epoch_spread = 0.00` / `epoch_sd = 0.00` で
**選択ノイズが構造的にゼロ**であるにもかかわらず、`val_metric_sd` は 0.002439 で
**5 規則中最悪（R-acc の 2.5 倍）**。すなわち選択ノイズを完全に消しても run 間ばらつきは
減らず、むしろ増える。**ばらつきは epoch 選択ではなく学習軌跡そのものにある。**

採用された R-topk も R-acc 比 **0.920** で、指示書 M1-6 の閾値「R-acc の半分以下」に
遠く届かない。→ **RULE_INEFFECTIVE 相当**（選択以外に発生源がある）。

補足: R-loss は機構的優先順で最上位に置いていたが（val loss は連続値で同点が起きにくい）、
`epoch_spread` は確かに最小級（2.17、R-acc の 7.08 に対し約 1/3）である一方
`val_metric_sd` は R-acc をわずかに上回った（0.001042 vs 0.000979）。
**epoch の選択が安定しても val 指標の安定性には結びつかなかった。**

### val 曲線の平坦さ（M1-2 相当。M2 の履歴から算出）

| 指標 | top1−top2 gap(mean) | (median) | ±0.001 以内の epoch 数 | 後半 50% の sd |
|---|---:|---:|---:|---:|
| val_accuracy | 0.001146 | 0.000660 | 2.22 | 0.004741 |
| val_loss | 0.020964 | 0.014715 | 1.04 | 0.059954 |

分母: 全 72 run。**val accuracy が最も平坦**（top1−top2 の中央値 0.00066 = 1 フレーム分
（1/1515 = 0.00066）に相当し、±0.001 以内に平均 2.22 epoch が入る）。
val loss は gap が 18 倍大きく、±0.001 以内は 1.04 epoch のみ。
**「val accuracy は量子化されていて平坦」という機構の想定は val 曲線のレベルでは正しかった**
が、それを直しても run 間ばらつきは減らなかった（上記）。

## ★ 重大な発見 2: n を 3 → 9 に増やすと判定が複数ひっくり返った

選択ノイズを消せなくても、**反復で n を増やせば SE は縮む**。実際 SE は大幅に縮み
（例: test (2−1) accuracy の SE は S3/S4 の 0.0104/0.0052 → M2 では 0.0035）、
複数の対比が判定を変えた。**向きは両方向である。**

| 対比 | 指標 | 以前 | M2 (n=9) | 変化 |
|---|---|---|---|---|
| (5−1) | test/incision | 非超過（S3: +0.0343, p=0.2123） | **+0.0176, p=0.0048 超過** | **非超過 → 超過** |
| (3−2) | test/incision | **超過**（G-2: −0.0308, p=0.0034） | −0.0068, p=0.3384 非超過 | **超過 → 非超過** |
| (4−2) | test/incision | **超過**（G-2: −0.0382, p=0.0300） | −0.0141, p=0.1257 非超過 | **超過 → 非超過** |
| (9−2) | test/macro-F1 | 非超過（S4: +0.0241, p=0.1987） | **+0.0144, p=0.0087 超過** | **非超過 → 超過** |
| (8−7) | test/accuracy | 非超過（S4: +0.0016, p=0.8935） | **+0.0079, p=0.0177 超過** | **非超過 → 超過** |

**選択ノイズは効果を膨らませる方向にも働いていた。** (3−2) と (4−2) の test/incision は
G-2 で「超過」だったが、n=9 では点推定が 1/4〜1/3 に縮んで非超過になった。
すなわち **G-2 の「マスク化は incision を有意に悪化させる」という所見は、
n=3 の選択ノイズによる過大評価だった可能性が高い**。

### M1-4: 非決定性 6 項目（コードから確認・推測なし）

| 項目 | 設定 | 行 | 備考 |
|---|---|---|---|
| `torch.cuda.manual_seed_all` | 未設定 | — | `:172` の `torch.manual_seed` が CUDA 側も seed するため実質的な欠落ではない |

| `PYTHONHASHSEED` | 未設定 | — | **かつ適用外**（下記） |

**§1.1 より踏み込んだ事実**: `train_g2.py` は **`DataLoader` を使わない**（`grep DataLoader` → 0 件）。
学習ループは Python リスト `tr` を `random.shuffle`（`:195`）してから直接反復する（`:197`）。
したがって `worker_init_fn` / `torch.Generator` / `PYTHONHASHSEED` の 3 項目は
**この trainer では原理的に非決定性の発生源になり得ない**（worker プロセスもハッシュ順依存の
データロードも存在しない）。

残る最有力候補は **cudnn の非決定的カーネル**（`tecno_head.py:32-33,51` の `nn.Conv1d` の
backward は atomics を使い得る）。学習側に `autocast` は無い（`autocast` は特徴抽出
`build_roi_channels.py:258` のみ）ので混合精度は学習の非決定性要因ではない。

**`use_deterministic_algorithms(True)` を入れて同一 seed が bit 一致するかは未検証（UNKNOWN）。**
M2 では事前登録どおり決定性制御を入れていない（規則の効果と交絡させないため）。
**「重大な発見 1」により、次手はこの決定性制御になる。**

### 判定表に無いパターン（§6 に従いそのまま記録）

1. **(5−1) が超過したことで S3 の PASS は維持されない。** S3 の判定規約では
   「(5−1) が一部超過 → **中間**（次元と情報の寄与を (2−5)/(2−1) の比で定量化）」に該当する。
   M2 の実測で定量化すると:

   | split | 指標 | (2−1) | (5−1)=次元由来 | (2−5)=情報由来 | (2−5)/(2−1) |
   |---|---|---:|---:|---:|---:|
   | test | incision | +0.0403 | **+0.0176** | +0.0227 | 0.563 |
   | test | accuracy | +0.0596 | +0.0054 | +0.0542 | 0.909 |
   | test | macro-F1 | +0.0525 | +0.0110 | +0.0416 | 0.792 |
   | val | accuracy | +0.0180 | −0.0014 | +0.0194 | 1.078 |

   **test/incision では効果の 43.7% が次元由来**であり、S3 で「排除できていない」と
   記録した規模の次元寄与が n=9 で実際に検出された。ただし (2−5) は全指標で超過しており、
   **情報由来の寄与が主である**ことは変わらない。

2. **(3−2)(4−2) の test/incision が超過 → 非超過に転じた。** G-2 の
   「マスク化は incision を有意に悪化させる」「randROI も同幅で悪化」という所見は、
   n=9 では点推定が 1/4〜1/3 に縮んで消えた。**選択ノイズは効果を膨らませる方向にも
   働いていた**ことになる。G-2 の解釈（「劣化要因は画素数の減少」）の根拠は弱まった。

3. **(9−2) と (8−7) は overall（accuracy / macro-F1）でのみ超過し、
   主指標の per-phase F1 では test 0/3・1/3 にとどまる。** 手の効果は
   「特定の工程に局在する」形では検出されず、全体としてわずかに効くという形で現れた。
