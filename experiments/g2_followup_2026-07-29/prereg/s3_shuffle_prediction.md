## 問い

G-2 で観測された 2−1（bboxROI − base、test accuracy +0.0607）は
「ROI の情報」が効いたのか、「入力次元が 3,840 → 7,680 に倍増した」だけなのか。

現状 bboxROI / maskROI / randROI は**全て 7,680 次元**であり、容量の効果が打ち消せていない。

## 系統

```
5. shuffleROI : base 3,840-d ＋ **別フレームから取った** bboxROI チャネル（計 7,680-d）
```

- シャッフルは **split 内**で行う（train / val / test をそれぞれ独立に置換する。
  split をまたぐと分布そのものが変わるため）
- 学習時・評価時ともシャッフル済み特徴を使う（学習と評価で条件を揃える）
- **置換は training seed ごとに別**に作り、seed から決定論的に導出する
  （置換のばらつきも seed 分散に入るため、(5−1) の検定は保守側に働く）
- **derangement であること**（どのフレームも自分自身に割り当たらない）を assert する
- チャネルの**周辺分布が bboxROI と完全一致**することを assert する
  （行の集合が置換で保たれるので、mean / std / ノルム分布は厳密一致するはず）

## 実行設計（指示書 §0.2 との衝突を明示して解決する）

指示書 §0.2 は「S3 は G-2 と同一 commit `ca280645…` で回す」と定める。しかし
`train_g2.py` の `--system` は `choices=["base","bboxROI","maskROI","randROI"]` であり、
`shuffleROI` を追加するには `train_g2.py` の変更が必要で、commit が必然的に動く。

このとき (5−1) と (2−5) を G-2 の既存 run（commit `ca28064`）と比較すると
**commit をまたぐ比較**になり、G-2 事前登録の無効化条件
「4 系統が同一 commit・同一ホストで実行されていない場合、比較を無効とする」に触れる。

**解決: S3 では base / bboxROI / shuffleROI の 3 系統すべてを新 commit で学習する（9 run）。**

- これにより (5−1) と (2−5) は**すべて commit 内・ホスト内の比較**になる
- 1 run 約 25 秒なので 9 run の追加コストは約 4 分であり、実行可能
- 副産物として、新 commit の base / bboxROI が G-2（`ca28064`）の値を再現するかを検証できる。
  **再現しない場合は S3 の結論を保留し、差異を定量化して報告する**
- G-2 の base / bboxROI の値は §1 の所与として参照するが、判定には新 commit の 9 run のみを使う

コード変更は以下に限定する（学習の数値・seed・順序に影響しないこと）:

1. `train_g2.py` の `SYSTEMS` に `"shuffleROI"` を追加（`--system` の choices を広げるだけ）
2. `env.json` に run 固有の実測値（開始・終了 ISO8601 タイムスタンプ、`system`、`seed`）を追加
   （S1 の申し送り。S1 判定自体は VALID だが、run ごとの実測であることが
   ファイルシステムの mtime に依存せず自明になるようにする）

## 予測（結果を見る前に固定）

- **予測 A**: shuffleROI ≈ base である。すなわち **(5−1) は判定閾値を超えない**
- **予測 B**: **(2−5) は判定閾値を超える**。これが「ROI の情報の正味の効果」である

## 判定規約（結果を見る前に固定）

| 結果 | 判定 |
|---|---|
| (5−1) 非超過 **かつ** (2−5) 超過 | **PASS** — 2−1 の効果は ROI の情報に帰属する |
| (5−1) が 2−1 と同程度に超過 | **FAIL** — 効いていたのは次元。2−1 の主張は成立しない |
| (5−1) が一部超過 | **中間** — 次元と情報の寄与を (2−5)/(2−1) の比で定量化して報告する |

## 判定手法

S2 で確定した方法を用いる:

- **主判定**: seed 水準の Welch。`SE = sqrt(sd_A²/3 + sd_B²/3)`、Welch の df、
  `|差| > t(0.975, df) × SE` を「超過」とする
- **併記**: 動画別の差の符号一致（val 2 動画 / test 3 動画）。
  帰無仮説下で全動画同符号となる確率は val 0.50 / test 0.25 であり、
  慣習的な有意水準には原理的に到達しない。**方向の一貫性の証拠としてのみ報告する**
- **補足**: 動画単位クラスタ・ブートストラップ（B=2,000）。
  相異なる多重集合が val 3 通り / test 10 通りしかなく解像度不足であることを明記して併記する
- 主指標は **per-phase F1**。overall accuracy / macro-F1 は併記のみで判定に使わない
- val と test の両方で評価し、**val だけの結果を結論と呼ばない**
