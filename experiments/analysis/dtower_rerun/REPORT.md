## 8. 評価の値の約束（注釈 id 0）

どの annotation ファイル（5 折り × val・test・train の 15 個）にも `id: 0` の注釈が 1 つある。pycocotools の COCOeval は一致した GT の id を `dtm` に入れ、0 を「一致なし」と読む。このため、その注釈に一致した検出が誤検出に数えられる。各 run の val・train・test の値（評価器の値）はこの影響を注釈 1 つ分だけ含む。前例と同じ経路なので、すべての run と前例に一様にかかる。
test で測った大きさ（評価器の値 − 注釈の id を +1 ずらした値）: A42 −2.27e-4、A123 −1.77e-4、B42 −1.65e-3、B123 −1.59e-3、C42 −7.08e-5、D42 −4.87e-3、E42 −2.74e-4。副次のまとめた評価は id を振り直したので、この影響が無い。
