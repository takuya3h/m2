# 則を選ぶ基準（結果を見る前に定めた）

**記録時刻: 2026-08-26 06:54:35 JST**
**この時点で存在するのは fold ごとの素の値だけであり、非独立を踏まえた則は 1 つも実装していない。**
新しい則の出力を 1 つも見ていない状態で本文書を書いた。順序は版管理の履歴で確かめられる。

## 0. 何を決めるか

採る則そのものではなく、**採用の候補として残す則が満たすべき性質**を決める。
性質はすべて対照で確かめられる形にする（SPEC.md 第 2 節）。

## 1. 対照の定義（これも結果を見る前に固定する）

SPEC.md Task 3 Step 2 の指定に従い、既存の結論から次の 2 つを選ぶ。

| 種別 | 結論 | 根拠（報告書 §3.9(d2) / §3.9 の記録値） |
|---|---|---|
| **陽性対照 P** | presence − GAP の **edit** と **seg-F1@50** | 15/15 fold で同符号。Δ=+32.20 / +0.338 |
| **陰性対照 N** | オラクル presence − 生 presence の **accuracy** | Δ=+0.0022、10/15、現行の則で |m|/SE=0.06 |

陽性対照は「分節の指標が十五の fold すべてで同じ向きに動いた結論」の定義に合致する。
陰性対照は SPEC.md が名指しした当のものである。

## 2. 候補として残す則が満たすべき性質

| # | 性質 | 確かめ方（両方向） |
|---|---|---|
| S1 | **陽性対照 P を検出する** | P に当てて「検出」と出ること。加えて、P の対の差を人為的に零へ潰すと検出しなくなること |
| S2 | **陰性対照 N を検出しない** | N に当てて「検出せず」と出ること。加えて、N の対の差を人為的に定数倍して大きくすると検出するようになること |
| S3 | **fold 間の独立を前提に置かない**、または**相関を推定して用いる** | 実装の中で、独立を仮定した SE = pstdev(d)/sqrt(n) をそのまま使っていないこと。読んで確かめる |
| S4 | **乱数を使うなら、種を固定すれば再現する** | 同じ種で二度走らせて完全一致すること。**かつ**種を変えれば値が変わること（片方向では常に同じ値を返す壊れ方と区別できない） |
| S5 | **推定が 15 fold で定義される** | 要素数不足で落ちない、NaN を返さない。落ちる場合はその旨を記録し候補から外す |
| S6 | **二つの則が実質一つでないこと** | 実装した則どうしが、全結論の上で常に同一の判定を返すのではないこと。返すなら比べたことにならない |

**S1 と S2 の両方を満たさない則は、採用の候補から外す。外した理由を記録する。**
S3 は本契約の目的そのものであるため、満たさない則は候補にしない。
S5 を満たさない則は候補から外すが、**「不安定だった」という事実自体は結果として記録する**
（起票者からの申し送り 3）。

## 3. 「検出」の定義（則ごとに事前に固定する）

則の系統ごとに、検出の閾は次で固定する。**結果を見てから動かさない。**

- **t 型の則**（統計量を散らばりで割る形）: 現行の則と同じ **絶対値が 2 以上**を検出とする。
  現行の則との比較が目的であるため、閾を揃えなければ則の違いと閾の違いが混ざる。
- **区間型の則**（並べ替え・再標本化で分布を作る形）: **両側 5% で零を含まない**ことを検出とする。
  t 型の閾 2 は正規近似でおよそ両側 5% に対応するため、対応する水準を選ぶ。
- **符号のみを見る則**: 本契約では判定則として採らない。符号の個数は判定と別に必ず残すため
  （SPEC.md Task 5 Step 4）、判定則としても使うと同じ情報を二度数えることになる。

## 4. 実装する則の本数と、異質性の要件

**少なくとも 2 種類**を実装する。**互いに同じ仮定を置く 2 つでは比べたことにならない**ため、
次の意味で異質であることを要件とする。

- 一方は **fold 間の相関を明示的に推定して分散へ繰り込む**系統。
- 他方は **分布の形を仮定せず、fold の入れ替えや再標本化で零分布を作る**系統。

この 2 つは「相関を推定して使う」か「相関を仮定せず経験分布で置き換える」かで異なる。

## 5. 決めないこと

**どの則を正本として採用するかは決めない**（SPEC.md 第 4 節・第 5 節禁止 6、
および 2026-08-26 の利用者の回答）。本契約は複数の則の結果を並べるところまでを範囲とする。
