## 1. 何を測ったか

今ある検出塔（D*-COCO 折り A seed 42、`experiments/baselines/stage1_dtower_r2/dcoco_foldA_seed42`、sha256 `30d199b1…`）と
工程塔（efros の P*-15-COCO 折り A seed 42。fine-tune 005・特徴 008・時間ヘッド 009 の写し）を凍結し、
塔のあいだに界面を一つ挟んで、界面に入れる信号だけを変えたときの val の差を測った。界面の最後の層は零で始め、学習前は塔単独と一致する。

| 型 | 方向 | 界面 | 学習範囲 | 腕の組 | seed |
|---|---|---|---|---|---|
| P1-W1 | 工程→検出 | 既存の FiLM（C5 を変調） | W1（界面だけ） | A5 | 42 |
| P1-W2 | 工程→検出 | 同上 | W2（界面と decoder の最終層・その層のヘッド） | A5 | 42 |
| P2L | 工程→検出 | 信号→9×15 の線形を decoder 各層のクラス logit に足す | W1 | A5 | 42 |
| P2F | 工程→検出 | 固定の表 B = log P(術具 │ 工程)（train の正解から） | なし（評価だけ） | A2F | — |
| P3 | 工程→検出 | 信号→9×256 の線形を decoder の 900 個の object query に足す | W2 | A5 | 42 |
| D1-L1 | 検出→工程 | 時間ヘッドの最初の層に、クラスごとの最大スコア（15）の入力を零で足す | W1 | A5 | 42, 123, 456 |
| D1-L2 | 検出→工程 | 同じ形で、領域トークン（3840） | W1 | A3 | 42, 123, 456 |
| D2 | 検出→工程 | FiLM（時間ヘッドの入力 2048 次元を変調） | W1 | A5 | 42, 123, 456 |
| D3-L1 | 検出→工程 | 術具ごとのトークン（スコア 15 + 枠 4 + 出所の印）への注意 | W1 | A5 | 42, 123, 456 |
| D3-L2 | 検出→工程 | 同上のトークンに query の埋め込み（256）を足した版 | W1 | A3 | 42, 123, 456 |

- 腕: 空（零）、予測-noCF（train も val も確定塔の予測）、正解、予測-CF（train は交差適合用の塔の予測、val は確定塔の予測）、
  正解予測-CF（正解と予測-CF の連結。正解が先。D3 はトークンの集合を合わせ、出所の印で区別）。A5 は 5 腕、A3 は空・予測-noCF・予測-CF、A2F は予測と正解
- D3 の予測のトークンは、後処理後の出力から**重複しない query** の上位 K = 11 個（利用者の決定。字面どおりの版は 45% の枠が同じ query の重複だった）
- 交差適合: 折り A の train 10 本を H1 = {01, 06, 11, 12, 15}、H2 = {02, 03, 08, 13, 14} に分けた（126 通りのうち、
  工程のフレーム比率と術具の枠のクラス比率の全変動距離の和 d の大きい方が最小。d(H1) 0.1469、d(H2) 0.1142）。
  片方で学んだ塔が、もう片方の動画にだけ信号を出す
- 止め方（最初の腕の前に固定）:
  - PD（W1 と W2 に同じ値）: 学習率一定、val の overall mAP が 2 epoch 改善しなければ止める、上限 4 epoch（当初 8。締め切りのため利用者の指示で変更）、最良の時点は学習した epoch から選ぶ
  - DP（W1）: 学習率 5e-4、重み減衰 0.01、val の macro Jaccard の停滞 10 epoch で止める、上限 100 epoch、平滑化 0.3
- 数値精度: PD の学習の順伝播は bf16 の自動混合精度（全腕で同じ）。評価は常に単精度。DP は単精度
- seed: PD は利用者の指示で 42 だけ（当初 42・123・456）。そのため **PD では R と §5.2 規則 2 の読みを出さない**

## 3. 恒等性と陽性対照

全型で、学習前の出力が塔単独と一致した（PD は val の mAP 0.7273450 と score・枠の差の最大 0.0、DP は val の Jaccard 0.7762186 とロジットの差の最大 0.0）。
界面の最後の層を N(0, 0.05²) にすると出力が変わった。値は `tasks/T-2026-10-18-stage2-pilot-folda/audit.md` の D-4 / D-5。
空の腕の陰性対照（空の腕で学んだ界面に、零の代わりに確定塔の予測を入れても出力が変わらないか）:

| 型 | 出力が変わったか | 差の最大 | 指標（零 → 予測） |
|---|---|---|---|
| P1-W1（FiLM） | 変わる | score 0.5907 | mAP 0.7303425 → 0.7302817 |
| P1-W2（FiLM） | 変わる | score 0.5445 | mAP 0.7289266 → 0.7291565 |
| P2L（線形） | 変わらない | 0.0 | mAP 0.7273490 → 0.7273490 |
| P3（線形） | 変わらない | 0.0 | mAP 0.7265779 → 0.7265779 |
| D1-L1・D1-L2・D3-L1・D3-L2 | 変わらない（3 seed とも） | 0.0 | Jaccard 0.7762186 のまま |
| D2（FiLM） | 変わる（3 seed とも） | ロジット 0.0433 / 0.0591 / 0.0463 | Jaccard 0.7733→0.7711 / 0.7840→0.7840 / 0.7723→0.7735（seed 42 / 123 / 456） |

FiLM の型だけが変わる。零の入力では FiLM の最初の層の重みに勾配が届かず初期値のまま残るため、零でない信号を入れると定数でない変調になる。
線形の型は信号にかかる重みが零のまま残り、学ぶのはクラスごとの一定の値（P2L・P3）だけである。PD の値は `negctl/`、DP は各 run の `negative_control`。
