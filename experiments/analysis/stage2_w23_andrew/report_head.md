## 1. 何を回したか

- 型: decoder-xattn（工程から検出、略 DX）と案 B（把持の地図を C5 に足す型、略 B）。受け取り手はどちらも検出塔 D*-COCO 折り A seed 42
- W: W2 と W3。腕: 空・予測-noCF・正解・入れ替え（利用者の指示 2026-11-02 で予測-CF・正解予測-CF と P1 を外した。計 16 本）
- 処方は W1 と同じ: 受け取り手の学習率 1e-4、界面 5e-4、AdamW（weight decay 1e-4）、batch 2、`presets.detr`、学習は bf16 の自動混合精度・評価は単精度、
  4 epoch の固定の長さ、最後の状態、seed 42。**`finetune_t1b` の群分けにより、backbone と `reference_points`・`sampling_offsets` の重みは学習率 × 0.1（1e-5）**
  （W3 で効く。既存の処方のまま）。腕と信号の対応は W1 の台本の写し（W1 の run の記録と 36/36 で照合）
- 1 枚 3 本で回した（W3 の記憶の山 11.4〜12.6 GB）。所要は W3 5.3〜5.9 時間、W2 3.1〜4.8 時間（同時に並べた本数で変わる）

## 2. 読み方の規則に沿った記述（SPEC §6.2）

seed は一つ、val は 2 動画。差は 1 本ずつの差として書く。

**W2（DX・B）**
- 正解の腕は Δ空 と Δ入替 が同じ向き: DX overall mAP +0.0043 / +0.0046、標的群 AP +0.0077 / +0.0091。B overall +0.0065 / +0.0071、標的群 +0.0098 / +0.0100。
  動画ごとの Δ空 は DX 09 +0.0005・10 +0.0051、B 09 +0.0083・10 +0.0071
- 予測-noCF の腕の差は小さい: DX overall Δ空 +0.0006・Δ入替 +0.0008、B +0.0008・+0.0014
- 空の腕の Δ塔（規則 3）: DX −0.0008、B −0.0032（標的群 −0.0006、−0.0101）。受け取り手の学んだ部分の動いた量（その部分の重みの L2 に対する差の L2）は 0.14 前後
- 案 B の空の腕は地図が全 0 で界面に勾配が届かず、界面の重みは 0 のまま（4 epoch 目の iface_l2 = 0）。動いたのは受け取り手だけ

**W3（DX・B）**
- 全腕で塔単独より下がった（Δ塔 overall: DX −0.0327〜−0.0103、B −0.0375〜−0.0148）。epoch 1 で −0.03〜−0.07 落ち、epoch 4 までに一部戻った。
  受け取り手の重みは全腕で相対 0.055 動いた
- **入れ替えの腕そのものが空の腕より高い**: DX +0.0224、B +0.0193（overall）。空の腕が四腕で最も低い
- Δ空 と Δ入替 の符号が食い違う腕（規則 4。両方を書く）:
  - DX 予測-noCF: overall Δ空 +0.0120・Δ入替 −0.0104、標的群 +0.0106・−0.0164
  - DX 正解: overall Δ空 +0.0145・Δ入替 −0.0079。標的群は +0.0320・+0.0049 で同じ向き
  - B 予測-noCF: overall Δ空 +0.0070・Δ入替 −0.0123、標的群 +0.0078・−0.0194
- B 正解は同じ向き: overall Δ空 +0.0227・Δ入替 +0.0034、標的群 +0.0296・+0.0024。ただし Δ入替 の動画ごとは 09 +0.0132・10 −0.0174 で向きが分かれる
- W3 の四腕の overall の幅は DX 0.0224、B 0.0226 で、W2 の幅（DX 0.0046、B 0.0071）より大きい。受け取り手全体が動くと、腕の間の差に信号の中身以外の動きが
  大きく混ざる。seed 一つではこれを分けられない

**型の間・W の間の並べ**（規則 2。同じ型の中でだけ比べ、W1 は参考の表に置く。W1・W2・W3 はすべて andrew で回したが、W1 は別の契約の run）
- 正解の腕の Δ空（overall）: DX は W1 +0.0021 → W2 +0.0043 → W3 +0.0145、B は +0.0091 → +0.0065 → +0.0227
- 正解の腕の Δ入替（overall）: DX は W1 +0.0022 → W2 +0.0046 → W3 −0.0079、B は +0.0075 → +0.0071 → +0.0034
- W1 の案 B の空の腕は塔単独と同値（界面に勾配が届かない）。W2・W3 では空の腕も受け取り手が動くので塔単独と一致しない

## 4. 既知の限界（SPEC §6.4）

- 折りは 1 つ（A）、val は 2 動画（09・10）、seed は 1 つ。差はすべて 1 本ずつの差で、幅を持たない
- 受け取り手は train で学習済みで、W2・W3 は同じ train でさらに学ぶ。W3 で全腕が塔単独より下がったのはこれと、学習率が一定であることの両方が効きうる（分けていない）
- 長さは固定の 4 epoch で、受け取り手を学ぶときの収束規則に従っていない（利用者の決定）。W3 は epoch 4 でも epoch ごとに値が動いている
- 工程塔の W3 は本契約に無い（本契約の型の受け取り手はどちらも検出塔）
- 型を二つのホストに配分したので、bengio の型と並べるときはホストの差を含む。本契約の 16 本と、参考に並べた W1・P1 の run はすべて andrew
- 数値精度は前回の経路のまま（学習は bf16 の自動混合精度、評価は単精度）
- W&B は手元だけ（offline、版管理の外 `$S/wandb/`）。`train_t1b.py` は W&B を配線しておらず、後処理が epoch ごとの val を手元に記録した
