# G-2 事前登録（2026-07-29）

> 本ファイルは指示書 Step E1-1 に従い、**学習を 1 本も回す前に**作成・コミットするものである。
> 実測結果は一切参照していない（この時点で G-2 の学習は未実施。§追記 のとおり実行ブロッカーあり）。

## 予測 1: 効果の上限アンカー

T1a(+0.0497) − B2a(+0.0383) = +0.0114 が region-token の presence 超過分の全て。
mask 化が改善しうるのは appearance 成分のみで、presence 成分は背景除去では変わらない。
よって G-2 の上振れ幅は +0.0114 と同オーダーが目安。
※これは推論であり硬い上限ではない。より良い appearance が現在の appearance チャネルより
  多くを引き出す可能性は排除しない。

## 予測 2: 効果の局在

signature 3 術具（Bipolar Forceps / Scalpel / Needle Holders）の充填率は 0.12–0.20 で
bbox の 80–88% が背景。したがって背景除去の効果はこの 3 術具に集中する。
→ incision / hemostasis / 閉創 の per-phase F1 が動く。残り 6 工程は動かない。

## 予測 3: 希釈

G-2 は「注入表現の被覆率」を上げず「質」だけを上げる。
9 工程中 3 工程しか照らさないため、overall macro-F1 の伸びは 3/9 に希釈される。
→ 主指標は overall ではなく per-phase F1 とする。

## 判定規約（結果を見る前に固定する）

- PASS: 予測 2 の 3 工程の per-phase F1 が、bbox 版 T1a に対して有意に改善
- 部分的 PASS: 3 工程のうち一部のみ改善 → どれが動きどれが動かなかったかを機構と突き合わせる
- FAIL: 3 工程とも動かない → 「region-token の質はボトルネックでない」という負の結果
- 予測外: 予測 2 以外の工程が動いた → 被覆率仮説の反証。最も情報量が大きい結果として扱う

## 追記（登録と同時に記録・実測に基づく）

本事前登録の作成時点で、E1 の実行には以下 2 つのブロッカーが確認されている。
**予測の内容はブロッカーの発見前に指示書 §E1-1 の規定どおり確定させたものであり、
結果を見てから書いたものではない。**

1. **機構上のブロッカー**: 現行 T1a の region-token は ROI Align による画素プーリングではなく、
   DETR デコーダの object-query 埋め込み
   （`scripts/extract_t1a_regiontoken.py`: `region[c] = sigmoid(logits)[q*,c] · tokens[q*]`、15×256=3840-d）。
   「ROI 内で mask==1 の画素のみを平均する」という指示された置換は、平均する画素が存在しないため
   そのままでは適用できない。
2. **環境上のブロッカー**: `.venv` の torch は 2.13.0+cu130 だがドライバは 535.309.01 のため
   `torch.cuda.is_available() == False`。GPU 推論・学習が実行できない。

詳細と選択肢は `../REPORT.md` §0 を参照。
