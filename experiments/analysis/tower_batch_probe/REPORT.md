## 4. 読み方の規則に沿った記述

- 溢れた水準は det_b8（歩 38、rank 1）と ph1_b32（歩 1）である。収まった最大の水準を「上限」とは呼ばない。`expandable_segments` や別の確保の規則、別の歩（縦横比や画像の大きさで記憶が変わる）で結果は変わりうる。det_b8 は 37 歩まで収まってから溢れた
- 検出塔の GPU 使用率の平均は 43〜69 %（b2〜b6）と低い。学習ログの `data_time` は 0.01 s 未満だが、使用率の平均は起動の間を含むため、低い理由が読み込みの律速かどうかは本計測では切り分けていない（UNKNOWN）。工程塔は 94〜98 % で、読み込みの待ちは一歩の 0.05 % 未満
- 見込み時間は §1 の定義どおり「歩数 × 一歩の平均」で、val・評価・起動の時間を含まない。表の値は `make_tables.py` が計算し直して一致を確かめている
