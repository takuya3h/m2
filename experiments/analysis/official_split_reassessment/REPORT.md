## 1. 何を確かめたか

### 1.1 所在（Phase A）

**三つの異質な方法で数え、いずれも一致した。**

| 方法 | val | test |

**陰性対照**（存在しない語で同じ探索）: `@zzznosuchsplit` → **0 件**、
`zzznosuchtoken` → **0 件**、`qqq_not_a_method` → **0 件**。**探索は働いている。**

**文書側との食い違いを 1 件見つけた。**
`docs/research_review_and_next_plan_2026-08-22.md` §3.17 は
「test 指標を持つのは `t1a_base_test_*` / `t1a_regiontraj_test_*` の 2 群のみだった」と書き、
test の値（acc 0.8286 / edit 52.32 など）を表に載せている。
**索引ではこれらの行の `split` は `val` であり、`test` ではない。**
索引の `split` 列は**評価に使った分割ではなく、集計の枠を表している**可能性がある。
**本契約は索引を正として扱い、文書の値は採用していない。**（→ `§4 UNKNOWN 1`）

### 1.2 効果量と揺らぎの出所（Phase B）

**公式の分割で判定を持つ 136 行すべてが、同じ出所である。**

| 項目 | 実測 |
|---|---|
| 揺らぎの出所 | **`sigma_source = paired_delta` / `delta_sigma_source = paired`（136/136 件）**。すなわち**対の差から求めたもの**であり、反復の散らばりそのものではない |
| 対の由来 | `pairing_provenance = from_config_yaml`、`delta_method = paired` |
| 種の数 | **`delta_n_seeds = 3`（全行）**。実験によっては `n_seeds=5` の記録があるが、差の計算に使われた種は 3 |
| 測られた分割 | **すべて検証側（val）** |
| **決定性が制御されていたか** | **記録が無い。** `experiments.csv` と `index.csv` のどちらにも決定性を表す列が **0 件**（`determin` `cudnn` `benchmark` `nondet` のいずれも該当なし） |

🔴 **「記録が無い」は「制御されていた」を意味しない。**
先行する契約の実測（SPEC 第 5 節）は「判定のすべてが決定性を制御していない実行の上に立っている」
「決定化して走った実行は判定を一つも持たない」と述べており、**本契約の実測はこれと整合する。**

**したがって、ここに並ぶすべての効果量について、種の間の散らばりには
種の効果と非決定性が混ざっている。** 各行の `sstd` はその混ざったものである。

各行の値は `inventory.txt` にある。**推定で埋めた欄は無い。記録が無い欄は `(記録なし)` と書いた。**

### 1.3 当てられる判定と当てられない判定（Phase C）

**当てられない判定 — 分け方の間の相関を扱うもの（2 件）**

**公式の分割には分け方が存在しない。** 分割は一通りである
（`conventions#split` の原文: train `01,02,03,06,08,11,12,13,14,15` / val `09,10` / test `04,05,07`）。
索引に fold を表す列は **0 件**（`fold` `cv` `leave` を名に含む列が無い）。

**当てていない。** 当てれば意味を持たない数字が出る。

**当てられる判定 — 対の差にもとづくもの**

136 行すべてが `paired_delta` であり、これは公式の分割でも成立する。
**ただし §1.2 の非決定性の制約から自由ではない。**

**対照（両方向）**

🔴 **SPEC が指定した対照は、公式の分割に存在しなかった。**

- 指定の陽性対照「全体平均の特徴を足す害」→ **公式の分割で 0 件**
- 指定の陰性対照「工程の情報を術具検出へ渡す」→ **公式の分割で 0 件**

**実測から代替を選んだ。**

| 対照 | 選んだもの | 判定 | Δ分類 | \|Δ\|/σ | 同符号 |
|---|---|---|---:|---:|---:|
| **陽性** | `b2a_det2phase_oracletool`（正しい術具存在） | `significant` | **+0.05979** | **11.42** | True |
| **陰性** | `t1a_region_only_mask_top3` | `not_significant` | **+0.00049** | **0.21** | False |

**陽性の `|Δ|/σ` は陰性の 55.1 倍。判定は二つを別々の値へ分けている。**
常に検出する判定でも、常に検出しない判定でもない。

**陰性対照は構造上の零ではない。** 同じ学習・同じ評価・同じ対の差の手続きを通ったうえで、
結果として零に近い値が出ている（`Δ工程平均 = −0.00482`、`Δ分節 = −4.62615` と、
指標によっては零から離れる）。**経路を通っている。**

## 2. 撤回の対象は、公式の分割ではどうだったか（Phase D）

**撤回の対象＝「工程を弁別しない術具を落とす」。公式の分割（検証側）で 11 件。評価側は 0 件。**

**分類の正しさ**: 最小 −0.01799 / 中央 +0.02403 / 最大 +0.05462。**11 件中 10 件が正。**
**工程ごとの成績の平均**: 最小 −0.03741 / 中央 +0.05898 / 最大 +0.11108。**11 件中 8 件が正。**

### 2.1 起票者の申し送りは実測と食い違う

**申し送り 3**: 「公式の分割では分類の正しさは動かず、工程ごとの成績を平均した指標が改善していた」

**実測**: **分類の正しさも動いている。** 11 件中 10 件が正で、`|Δ|/σ` は 0.21〜28.32。
工程平均も動いている（8/11 件が正）。
**「分類は動かず工程平均だけ改善」という形にはなっていない。**

零に近いのは 11 件中 2 件（`b2a_ro_oracle_top3noise_p030` と `t1a_region_only_mask_top3`）だけである。

### 2.2 二つの枠組みの並置

| 枠組み | この結論について何が言えるか |
|---|---|
| **公式の分割（検証側 val）** | 11 実装のうち 9 実装で分類・工程平均とも正の効果。2 実装で零に近いか負。**評価側では測られていない。** |
| **一つ抜き検証** | 先行する契約が符号の個数にもとづき撤回を報告した（本契約は再集計していない） |

**食い違いは、符号の向きそのものにある。**
公式の分割の検証側では大半の実装が**正**の効果を示すのに対し、撤回の根拠は**負**の方向であった。

**どちらが正しいとは書かない。** 枠組みが違えば違う数字が出る。
**書けるのは、公式の分割の検証側では大半が正であり、評価側では測られていない、ということである。**

**撤回を維持するか取り消すかは、起票者と利用者の判断事項である。本契約は判断しない。**
