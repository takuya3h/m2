## 3. 規則による選択（prereg §3）

| 水準 | val mAP の平均（全桁） | 最大との差 | 同点幅 0.0076 の内 | 標的群 AP の平均 | 陰性対照群 AP の平均 | 2 本の差（42 − 123） |

| b4 | 0.7297248 | -0.0059273 | はい | 0.8205 | 0.6659 | -0.0028 |
| b6 | 0.7356521 | +0.0000000 | はい | 0.8211 | 0.6745 | +0.0056 |

1. 平均の最大は b6（0.7356521）で候補
2. 最大との差が 0.0076 以下の水準は b2・b4・b6 の 3 つで、同点
3. 同点の中で最も大きい batch を選ぶ: **b6（GPU ごとの batch 6、実効 12）**
4. 標的群 AP の平均の最良も b6。co-primary の食い違いは**なし**
5. 発散・非数・溢れの水準は無い（候補から外した水準は 0）
6. b2 は同点幅まで 0.0004471 の余りで同点に入った。判定は全桁の平均で行った
7. 記録だけ: b2 の平均 0.7285 と探索の 12 番（dlsta、0.7374）の差は -0.0089。ホストが違うので比べない

**陽性対照.** 同点幅を 0 にしても選択は b6 のまま（最大の平均と最大の batch が同じ b6 のため、実データではこの対照は同点の規則を見分けない）。合成した入力（b2 0.740、b4 0.735、b6 0.730）で選択の関数を呼ぶと、同点幅 0.0076 で b4、0 で b2 を選んだ（audit §6 D-2）。平均と差は各 run の `metrics.json` から別の経路で計算し直して一致した。
