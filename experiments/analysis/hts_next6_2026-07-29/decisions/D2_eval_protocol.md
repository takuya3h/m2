## Step 5-3: 3 案の比較

| 案 | 内容 | 利点 | 欠点（実測値で充填） |
|---|---|---|---|
| **A** | train 内 leave-one-video-out CV で rare 工程を評価 | 再分割にあたらない（train 内で完結） | disinfection は train に **11 枚**しかなく、<br>HT subset では **0 枚**。CV を組んでも統計的に無意味。<br>dressing も train 12 枚（HT subset 10 枚）で同様 |
| **B** | 公式 split のみ。rare 工程は評価対象外と明記 | 最も安全。既存 Δ と完全に地続き | disinfection / dressing / irrigation の 3 工程が永久に測れない |
| **C** | 主結果は公式 split、rare 工程のみ補助的に CV | 二層構成で査読説明が容易 | 実装コストが 2 倍。かつ A と同じ枚数制約を受けるため、<br>disinfection については二層目も無意味 |

### 実測が示す追加の制約

- **disinfection は A・C を採用しても評価できない**（HT subset で 0 枚、canonical でも train 11 枚のみ）。
- **irrigation と dressing は test で評価可能**（HT subset で 72 枚 / 54 枚）。
  val では 0 枚のため、**val 上で rare 工程の改善を主張することは不可能**。
- §1.3 I5（3-seed, paired-σ）を満たす統計処理は、数十枚規模のクラスでは
  効果量の信頼区間が極めて広くなる。枚数を併記せずに per-phase F1 を報告しないこと。

## Step 5-4: 追加であって置換ではない

既存の全結果（§1.2 の S4 base / B2a / T1a / H-6 / oracle-tool 等）は **公式 split 上で測られている**。
新しい評価プロトコル（案 A・C）を導入する場合も、

- **既存結果を置き換えてはならない**。
- 新プロトコルの数値は**別系列として併記**し、公式 split の数値と同じ表に混ぜない。
- 論文では「主結果 = 公式 split」「補助 = CV」と層を明示する。

これは不変量 **I1**（評価フレーム集合の一致）および **I2**（split 定義の一致）を守るために必須である。

## 推奨（決定ではない）

**B を推奨し、rare 3 工程については「評価対象外」と明記することを推奨する。**

根拠:
1. disinfection は canonical val/test に元から 0 枚で、HT subset でも 0 枚。
   どの案を採っても測定できない（実測）。
2. dressing / irrigation は test でのみ評価可能（54 / 72 枚）。
   CV を追加しても train 側の枚数（10 / 45 枚）が小さく、実装コストに見合わない。
3. 除外セグメントは phase ラベルが存在しないため、A・C が前提とする
   「使えば評価できる」という選択肢自体が成立しない（実測）。

**ただし**、rare 工程の評価が研究上どうしても必要な場合は、
案 C の二層構成を dressing / irrigation の 2 工程に限定して適用するのが現実的である
（disinfection は除外せざるを得ない）。
