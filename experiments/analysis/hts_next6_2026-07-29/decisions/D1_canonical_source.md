## 決定 1: Hand-Tool の正本

### 前提が実測で覆った点（最重要）

指示書 §3 T1 の導出「完全版 `merged_annotations.json` を使えば被覆率が **87% 以上に上がる**」は
**実測で否定された**。

`merged` が by_split 版より多く持つ 4,521 フレームは、**全て annotation 0 件の空エントリ**である。

| 検証 | 実測結果 |
|---|---|
| `A∩C(ann≥1)` と `A∩B` の集合一致 | **完全一致**（train/val/test すべて、差分 0 件） |
| フレーム毎の annotation 数の一致 | **9,106 フレーム全てで一致**（不一致 0 件） |
| 「復活」した 4,521 フレームのうち ann≥1 | **0 件** |
| 動画 03（欠落とされた動画） | merged に画像エントリ 1,472 枚、うち ann≥1 は **0 件** |
| 動画 14（欠落とされた動画） | merged に画像エントリ **0 枚**（そもそも存在しない） |

つまり **merged は動画 03・14 の Hand-Tool を復活させていない**。§1.4-c の「完全版」という位置づけは
annotation 水準では成立しない。

### 選択肢

| 選択肢 | 分母（実測） | 利点 | 欠点 |
|---|---:|---|---|
| **A. `merged_annotations.json`** | entry 13,627 / **使用可 9,106** | entry 数は最大に見える | 追加分は全て空エントリで情報ゼロ。<br>ファイル整合性の欠陥あり（下表） |
| **B. `fusion/*_toolhand_withmask`** | **9,106** | 検出パイプラインと同じ前処理。<br>空エントリ・dangling ともに **0 件** | 動画 03・14 が train から欠落（A でも解消しない） |
| **C. 両者の積集合** | **9,106** | 最も保守的 | A・B と同一集合のため保守性の利得が無い |

**3 案の使用可能フレームは全て同一の 9,106 枚**（集合として一致、annotation 数も一致）。
選択によって分母は変わらない。

### `merged_annotations.json` のファイル整合性（実測）

| 項目 | 実測値 |
|---|---:|
| 画像エントリ | 17,603 |
| annotations 配列長（論文値 41,605 に対応） | 41,605 |
| うち **有効**（image_id が images に存在） | **40,201** |
| うち **dangling**（image_id が images に存在しない） | **1,404** |
| dangling が指す image_id | 17604–18019（画像 id の最大 17,603 を超える） |
| **annotation 0 件の画像エントリ** | **6,618**（37.6%） |

論文の「Hand-Tool 41,605」は annotations 配列の生の長さであり、
うち 1,404 件は参照先画像を持たない。

### 影響見積もり（実測値で充填）

| 指標 | A | B | C |
|---|---:|---:|---:|
| 分母（使用可フレーム） | 9,106 | 9,106 | 9,106 |
| 被覆率（対 canonical 15,437） | 0.5899 | 0.5899 | 0.5899 |
| train / val / test | 5,668 / 1,344 / 2,094 | 同左 | 同左 |
| 有効 annotation 数 | 34,175 | 34,175 | 34,175 |
| signature 術具が使えるか | 3 種とも可（T3 参照） | 同左 | 同左 |
| 前処理の追加実装 | 空エントリと dangling の除去が必須 | 不要 | 積集合計算が必要 |

### 推奨（決定ではない）

**B（`fusion/*_toolhand_withmask`）を推奨する。**

根拠:
1. 3 案の分母・annotation は完全に同一であり、A を選ぶ利得は存在しない（実測）。
2. A は空エントリ 6,618 件と dangling 1,404 件を含み、素直に読むと
   「annotation 0 件のフレーム」を分母に数えて被覆率を 88.3% と誤認する。
   本タスクで実際にこの誤認が起きかけた。
3. B は検出パイプラインと同じ前処理であり、不変量 I4（凍結源・特徴抽出パイプライン不変）に整合する。

**A を選ぶ場合の必須条件**: 読み込み時に「ann≥1」でフィルタし、dangling を除去すること。
これを行うと結果は B と同一になる。

## 決定 2: 術具クラス体系の正本

### 4 版の実測（T3）

| 版 | 実体 | 宣言カテゴリ数 | 実データを持つクラス数 | ann 数 |
|---|---|---:|---:|---:|
| V31 | `by_video/tool` | 31 | 31 | 67,687 |
| V14 | `03_tool/coco_splits_14cls_cleaned` | 14 | 14 | 51,329 |
| V15k | `03_tool/coco_splits_15cls_withkidney` | 15 | **14**（Skewer が 0 件） | 51,052 |
| **VBS** | `data/annotations/egosurgery_tool`（**既存実験の凍結源**） | 15 | 15 | 49,652 |

**注意**: 「15 クラス」を名乗る版が 2 つあるが中身が違う。
- VBS 15cls = 14cls + **Mouth Gag**
- V15k 15cls = 14cls + **Kidney Dish** − Skewer(0 件)

### VBS → V14 の写像（実測）

- **一意写像である**（頑健基準: 支配率 5% 以上の写像先が複数あるクラスは、
  IoU 閾値 0.95 / 0.90 / 0.70 / 0.50 のいずれでも **0 個**）
- signature 3 術具は V14 で全て生存し、他クラスへの吸収は **0 件**

| signature 術具 | VBS ann | V14 ann | 他クラスへの吸収 |
|---|---:|---:|---|
| Bipolar Forceps | 696 | 713 | なし |
| Scalpel | 1,066 | 1,125 | なし |
| Needle Holders | 4,829 | 5,307 | なし |

- **VBS にあり V14 に写像先が無いクラス: `Mouth Gag`（5,985 ann）** ← V14 採用時に脱落する

### V14 採用の隠れたコスト（実測・最重要）

**V14 の bbox は VBS の bbox と座標が一致しない。** 同一インスタンスでも数ピクセル異なる。

| 指標 | 実測値 |
|---|---:|
| VBS の各 box に対する V14 側 best-IoU の中央値 | **0.871** |
| IoU ≥ 0.95 を満たす割合 | 15.6% |
| IoU ≥ 0.99 を満たす割合 | 0.4% |
| 小物体（面積 < 5×10³ px）で IoU ≥ 0.95 の割合 | 0.4% |

つまり V14 はラベルの付け替えではなく **box そのものが別導出**である。
V14 を正本に採用することは検出 GT の座標を差し替えることを意味し、
§0 の禁止事項「凍結源（検出器 backbone / box 枝）を変更しないこと」および
不変量 **I4** に抵触する可能性が高い。

### 選択肢と影響見積もり

| 選択肢 | 利点 | 欠点（実測値で充填） |
|---|---|---|
| **A. VBS 15 クラスに統一** | 既存 Δ 基準点をそのまま使える（再計算 0 件）。<br>凍結源・I4 を維持。<br>Mouth Gag 5,985 ann を保持 | mask は 14 クラス側にあるため、mask を使う G-2/G-3 では<br>Mouth Gag に mask が存在しない（14cls に無いため）ことを明記する必要 |
| **B. V14 14 クラスに統一** | 論文値と一致 | ① §1.2 に列挙された Δ 基準点 **7 件すべて**が再計算対象。<br>② Mouth Gag **5,985 ann** が脱落。<br>③ **box 座標が変わる**（best-IoU 中央値 0.871）ため<br>　 凍結源変更 = I4 違反のリスク。<br>④ 検出 mAP（S0-frozen 0.7051 / Relation-DETR 0.7303）が<br>　 別 GT 上の値になり、既存 Δ の分母が無効化 |

### 推奨（決定ではない）

**A（VBS 15 クラスを正本に維持）を推奨する。**

根拠:
1. B は「クラス数の変更」に見えて実際は **box 座標の差し替え**であり、
   §0 の凍結源変更禁止に抵触する。得られるのは論文値との一致のみ。
2. VBS → V14 は一意写像かつ signature 3 術具が全て生存するため、
   **論文値と比較したい場合は「A を正本にしつつ、報告時に V14 へ写像する」**ことで
   凍結源を変えずに両立できる（写像表は `t3_class_mapping.json` に保存済み）。
3. Mouth Gag（5,985 ann、VBS 全体の 12.1%）を失わない。
