## 0. この報告の位置づけ

前回の非公式の予備測定（T-2026-10-18-stage2-pilot-folda、PR #235）の値を、前回見つかった二つの欠陥を除いて出し直した。

- **欠陥 A（選び方）**: 前回は 1 epoch ごとに val を測り、最も高い epoch の値を結果にした。同じ val で選んで同じ val で報告したため、
  学習が起きる腕にだけ「たまたま良かった分」が乗る。本報告の値は**すべて学習を 4 epoch 終えた時点の状態**で、最良の回を選ばない
- **欠陥 B（比べる相手）**: D1・D3 の空の腕は零から始めた界面に零を入れるため勾配が届かず、塔単独と同じ値になる。空の腕との差には
  信号の中身の効果と、零でない値が入ることで界面が学べるようになった分とが混ざる。本報告は全型に**入れ替えの腕**を足した。
  予測（交差適合なし）の腕と同じ値の集まりを使い、フレームとの対応だけを壊した腕である

## 1. 方法

- **データ**: 折り A（公式分割）。train 10 動画 9,657 フレーム、val 動画 09・10 の 1,515 フレーム（術具と工程の両方の注釈があるもの）。
  test の動画（04、05、07）は信号の作成・学習・評価のどこにも通していない（§6）
- **受け取り手と界面**: 前回と同じ。PD は検出塔 D*-COCO 折り A seed 42、DP は工程塔の時間ヘッド（P*-15-COCO 折り A seed 42 の写し）。
  界面の型・容量・学習範囲・学習率（一定）・重み減衰・増強・batch・数値精度（PD の学習の順伝播は bf16、評価は単精度）・seed 42 は前回の同じ型と同じ。
  変えたのは止め方（固定の長さ）と、入れ替えの腕の信号だけ
- **固定の長さ**: 4 epoch 学習し、途中で止めず、4 epoch 目を終えた状態を結果にする。PD は `train_t1b.py --fixed-epochs`、DP は
  `dp_train.py train --fixed-epochs 4`。結果の metrics.json・クラス別・動画別・notes.md・界面の重みはすべてその状態で、
  記録に `result_selection: final_epoch` を残す
- **値の出所**: 回し直した run（PD 8 本、DP の seed 42 の 21 本）は本契約の run の値。回し直さない PD の run（12 本）は前回の run の
  epoch ごとの記録（`logs/val_metrics_by_epoch.json` の epoch 3 の mAP とクラス別 AP。群の AP はクラス別 AP から conventions#det_groups の表で作る）。
  前回の学習中の評価器のクラス別 AP は、前回の報告の値を作った評価器（予測から計算し直すもの）と、最良の epoch で全 run 差 0.0 だった
- **入れ替えの腕**: split ごとに、フレーム名の昇順の列を seed 42 で一つの固定の順に並べ替え、フレーム f が元のフレーム π(f) の値を持つ。
  train と val を別々に、それぞれ split 全体にわたって入れ替える（動画の中だけでは入れ替えない）。同じ split の信号（P0、D0、D0-RT、D0-INST-UQ）は
  同じ並べ替えを使う。集合の信号（D0-INST-UQ）はフレームごとの集合を丸ごと入れ替える。学習時と評価時の両方で入れ替えた信号を使う。
  型ごとの信号: P1-W1・P1-W2・P2L・P3・P2F は P0、D1-L1・D2 は D0、D1-L2 は D0-RT、D3-L1 は D0-INST-UQ から埋め込みを除いたもの、D3-L2 は D0-INST-UQ
- **差**: Δ空 = 値(型, 腕) − 値(同じ型の空の腕)、Δ入替 = 値(型, 腕) − 値(同じ型の入れ替えの腕)、Δ前回 = 前回の REPORT の Δ（最良の回。
  DP は seed 42 の Δ）、選び方による差 = Δ前回 − Δ空（回し直した腕では再現の差も含む）
- **指標**: PD は overall mAP、標的群 AP（併記）、陰性対照群 AP。DP は macro Jaccard、frame accuracy（併記）、クラス別 Jaccard
