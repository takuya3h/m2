## 5. 最も情報量の大きい所見

**(a) ROI チャネルの追加そのものは明確に効く。** test で incision +0.04384、closure +0.03902、
dissection +0.14795、accuracy +0.06073、macro-F1 +0.05748 がいずれも両基準を超過。

**(b) しかし ROI を絞ると悪化する。** test/incision で

- maskROI − bboxROI = **−0.031**（超過）
- randROI − bboxROI = **−0.038**（超過）

真のマスクと「同面積・同重心のランダム形状」が**ほぼ同じ幅だけ悪化**している。
劣化の要因は「背景を除いたこと」ではなく「平均する画素を減らしたこと」側にあることを示唆する。
事前登録の予測 4 は「4 が 2 を**上回る**」場合（= 画素数減少や正則化が効いている）を想定していたが、
実際は **両方が 2 を下回る**という形で現れた。すなわち box 内の背景画素は雑音ではなく、
情報を担っているか、少なくとも平均の安定性に寄与している。

## 8. 明示すべき制約

1. **ブートストラップの解像度が原理的に粗い。** クラスタ（動画）が val 2 本・test 3 本しかないため、
   復元抽出で生じる相異なる多重集合は **val 3 通り・test 10 通り**しか存在しない。
   B = 2,000 はこの少数パターンを重み付きで引いているだけであり、CI 端点に `+0.00000` が
   頻出するのはこのためである。事前登録の設計に由来する制約であり、実行上の欠陥ではない。
2. **val の mask / bbox コントラストは構造的に弱い。** val はフォールバック率 0.2409 で、
   約 1/4 の box が `maskROI = bboxROI` になる（うち 23.07pt は Mouth Gag / Skewer で、
   これらはマスクが原理的に存在しない）。val の 3−2 はこの希釈込みで読む必要がある。
3. **A-3 の相関は n が小さすぎて推定不能**（上記 7 節）。
4. セグメント単位（val 3 / test 6）ではなく**動画単位**（val 2 / test 3）でクラスタリングしている。
   事前登録が「動画単位」かつ「test は 3 動画しかない」と明記しているため。
   同一動画のセグメントは相関しており、セグメント単位ではCI を過小評価する。
