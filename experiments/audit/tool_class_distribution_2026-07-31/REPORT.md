## 結論（先に要点）

1. **EgoSurgery-Tool 論文 arXiv:2406.03095v4 の Table 3(a) と 55 セル全一致**（不一致 0 件）。
   本ファイル群は論文の公式 split そのものであり、規模・クラス構成に乖離は無い。
2. カテゴリ定義は **3 split すべてで完全一致の 15 クラス**（`category_id` は **0 始まり**）。
3. **val には Retractor が 1 件も無い**（実出現 14 クラス）。これは**論文 Table 3(a) 自身が
   `Retractor / val = 0` と印字している公式 split の性質**で、配布データの欠損ではない。
   → **val の mAP は 14 クラス平均、test は 15 クラス平均**。分母が違うので直接比較不可。
4. split 間の `file_name` 重複は 3 組すべて **0** でリーク無し。動画単位 split（train 10 / val 2 / test 3 本）。
5. 退化 box・`iscrowd` はいずれも 0 件でデータ品質は良好。箱ゼロ画像のみ train 39 / test 84 枚存在。

## 所見

### F1（P1）val に Retractor が存在しない ※本監査は既知事項の再導出

> **既知**: `docs/m2_plan_rewrite/source_current.md` §33（2026/05/29）に記録済み。
> 同記録は本監査より踏み込んでおり、**`mmdet_components.py:87` が GT 不在クラスの NaN を 0.0 に
> 倒して平均に算入するため AP_common に約 -4.6pt の押し下げバイアスが乗る**ことまで特定している。
> 本監査の寄与は「論文 Table 3(a) と一致する公式 split の性質であること」を確定させた点のみ。

train 2,079 箱 / test 325 箱に対し **val は 0 箱**。pycocotools の `COCOeval` は
GT が 1 件も無いクラスの AP を `-1` として返し、`stats[0]`（mAP）の平均から除外する。
したがって:

- **val の mAP は 14 クラス平均、test の mAP は 15 クラス平均**であり、分母が異なる。
- val→test で mAP が動いた場合、それが手法の効果なのか分母の差なのか分離できない。
- per-class AP を見る場合も、val 側に Retractor の行が存在しない（または `-1`）。

これは動画単位 split の必然的な帰結である（val は動画 09/10 のわずか 2 本）。データの誤りではなく
**論文が公式 split として配布している構造的な非対称**なので、修正ではなく運用で回避する。

**再発防止**: val と test の mAP を並べるときは必ずクラス集合を明示し、比較が必要な場合は
Retractor を除外した **14 クラス共通部分集合**で両者を再計算する。

### F2（P2）クラス不均衡が約 30 倍

train の最多 Tweezers 6,467 に対し最少 Skewer 212（約 30 倍）。
val の rare クラスは Bipolar Forceps 55 / Raspatory 76 / Syringe 96 箱しかなく、
per-class AP は数枚の当たり外れで大きく振れる。
`|Δ| > 1σ` による改善主張（CLAUDE.md §10.1 準拠）を per-class で行う際は、
この分散を σ の推定に織り込む必要がある。

なお Skewer は train 212 / val 103 / test 29 と **val が test より多い**逆転が起きており、
Skewer の val AP は test AP の予測子として特に信頼できない。

### F3（P3）箱ゼロ画像の扱い

train 39 枚 / test 84 枚 / val 0 枚。学習・評価で空アノテーション画像を除外するか
含めるかで実効サンプル数と FP ペナルティが変わるため、実験間で揃える必要がある。

## 「51,329 と一致しない」件の裁定（解決済み）

本 REPORT の初版に「tool 14 クラス = 51,329 と一致しない」と書いたが、**これは別論文・
別母集団との誤った比較**だった。以下に裁定を記録する。

| | 出典 | 母集団 | クラス | インスタンス |
|---|---|---|---:|---:|
| 51,329 | **EgoSurgery-HTS** (arXiv:2503.18755) | `03_tool/coco_splits_14cls_cleaned`、26 セグ / 19,560 枚 | 14 | 51,329 |
| **49,652** | **EgoSurgery-Tool** (arXiv:2406.03095) | `by_split`、22 セグ / 15,437 枚 ＝ **本ファイル群** | 15 | 49,652 |

両者は同一の生データに対する**異なる curation** であり、一致しないのが正しい挙動である。
既に以下で裁定済みだったので、本監査は追認にとどまる。

- `experiments/analysis/hts_next6_2026-07-29/decisions/D1_canonical_source.md:91-93`（V14 と VBS として並記）
- `data/raw/OpenSurgery_Dataset/SCALE_VERIFICATION.md:83-85`
  （31cls/67,687 → 14cls_cleaned/51,329 → 15cls_withkidney/51,052 → **by_split/49,652**）

**教訓**: 規模照合を行う際は、必ず「どの論文の・どの母集団か」を先に確定させる。
EgoSurgery は Tool / Phase / HTS の 3 論文が同一の生映像を共有しており、
数値だけを見て突き合わせると別データセット同士を比較してしまう。
