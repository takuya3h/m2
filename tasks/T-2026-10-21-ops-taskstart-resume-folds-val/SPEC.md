### 5.1 task-start の分類

「同じ経路」は、`origin/phase0` の木がその経路のファイルを追跡していることをいう。

| 手元のファイル | phase0 の同じ経路 | 扱い |
|---|---|---|
| 追跡下の変更 | 問わない | 止める（今と同じ） |
| 無視されていない未追跡 | 在り、中身が同じ | 汚れに数えない。切り替えの後も中身が同じ |
| 無視されていない未追跡 | 在り、中身が違う | 止める。経路を一覧にする |
| 無視されていない未追跡 | 無い | 止める（今と同じ）。経路を一覧にする |
| 無視された未追跡 | 在り、中身が同じ | 通す |
| 無視された未追跡 | 在り、中身が違う | **止める。** 経路を一覧にする（黙った上書きを防ぐ） |
| 無視された未追跡 | 無い | 触れない（今と同じ） |

- 抑止の目印（`.sync-pause` とその類）は今と同じ扱いにする
- 無視されたファイルは数が多い（仮想環境など）。phase0 の木と経路で突き合わせてから中身を比べる形にし、所要時間を audit に記録する
- 同期で届く、統合前の他の契約の出力（2026-10-21 に andrew へ届いた `experiments/analysis/dlsta_tower_feasibility/` など）は、
  「無視されていない未追跡・phase0 に無い」に当たり止まる。phase0 に無いことを分類で確かめた経路は、利用者が無視の一覧に足してよい

## 6. 禁止事項

**禁止は実行者の操作に対するものであり、同期処理による配布を含まない。**

1. **本契約では GPU を使用しない。** 学習も推論もしない。Python の処理は装置を見えなくした状態で動かす
2. ほかのホストへ接続しない（`origin` からの取得と push、PR の作成、`make task-report` を除く）
3. `data/` 配下に書き込まない。データを読まない。`data/splits/` の既存ファイルを変えない
4. **作業ツリーのファイルを消したり repo の外へ移したりしない。** `.git/info/exclude` を変えない（試験の隔離した場の中は除く）
5. 規約の既存の規則の中身を、§5.3 以外で変えない。既存の節を消さない。アンカーの名前を変えない
6. 既存の道具の、§5.1 と §5.2 以外の挙動を変えない
7. `context/auto/*` と `tasks/inbox.md` を再生成しない。生成物の検査（`make taskindex-check`、`make inbox-check`）を回さない
8. `runindex/**` を手で編集しない。既存の `tasks/*/` を変えない。他の契約の `conventions_rev` を書き換えない
9. 資格情報の値を記録・出力しない。資格情報の扱いが拒まれたら回避せず諮る
10. 統合しない（PR を作るところまで）。外部への送信は `make task-report` 以外の経路で行わない

## 8. 想定外と停止条件

- 本ホストの repo の位置や起点が `context/env-facts.md` の記載と違う → 停止して諮る
- 作業ツリーが別の契約の分岐にある、または別の契約が作業中 → 起動しない。停止して諮る
- Task A の 5 で、無視された未追跡のうち phase0 と中身の違うものが 1 件以上 → 停止して諮る（関門 G1）
- §5.1 を、作業ツリーのファイルを消すか repo の外へ移さなければ実現できないと分かった → 停止して諮る
- 統合済みの契約の完了済みの扱いが一件でも変わる → 停止して諮る
- 規約に置く規則の中身を変えたくなった → 停止して諮る
- 意図しない節が変わった、アンカーが解決しない → 停止する（関門 G3）
- 試験の失敗の名前の集合が増えた → 停止する
- 実行基盤が書き込みや移動を拒む → 回避せず諮る
