学習開始より前に commit する。commit 後は変えない。変更は `meta.amendments` に追記する。

## 1. 問い

凍結した ImageNet-1K ResNet-50 の空間特徴（0.5 fps、GAP 後 2048 次元）の上に載せる online-causal の時間ヘッドとして、
三候補のどれが折り内 val の macro Jaccard で最良か。確定した塔（P\*-21、P\*-15）を Stage 2 の送り手にする。

## 2. 候補（提案関門を通したカード。生成と批判は利用者の指示で同一会話。F に記録）

| 候補 | 内容 | 掃引（主要因） | 固定 |
|---|---|---|---|
| A | causal 多段 TCN、2 段（TeCNO 型） | 受容野（履歴長）2 水準: 短・長。水準の値は実装の受容野の式から実行者が決め、記録する | 段数 2、損失は重み付き CE、lr・batch・epoch は Stage 0 の S4 の処方 |
| B | A の出力埋め込みの上に過去のみの Transformer 集約（Trans-SVNet 型、PE なし） | 集約する履歴 step 数 2 水準: 30、60 | 下段は A の掃引 2 点それぞれ（計 4 構成） |
| C | A の損失に truncated MSE の平滑化項（MS-TCN 型） | 平滑化の重み 2 水準 | 下段は A の掃引 2 点それぞれ（計 4 構成） |

候補間で recipe・seed 数・探索回数を同一にする（M §5.1）。掃引集合はここで固定し、後から足さない。

## 3. データと折り

- 折り表は `conventions#folds`。折り A の test は公式 test、val は公式 val
- P\*-21: 各折りの train に追加 6 動画（17〜22）を足す。追加 6 動画は test にも val にも現れない
- P\*-15: 15 動画のみ
- seed: 折り A は 42・123・456 の 3 本、折り B〜E は 42 の 1 本

## 4. 予測（結果を見る前に書く）

1. 候補 A が 5 折り平均の val macro Jaccard で最良
2. 候補 B は A より低い（EgoSurgery-Phase で Trans-SVNet 23.1 が TeCNO 27.3 を下回った同ドメインの否定例による）
3. 候補 C は A との差が折り A の seed 間 SD の内側
4. P\*-21 は P\*-15 より高い
5. 折り A の P\*-21 は、Stage 0 の凍結工程塔（検出 backbone 由来、val Jaccard 0.6447 ± 0.0146）より低いか同程度。
   理由は、検出 backbone の特徴が動画の同一性を運んでいた疑いがあり（M §2.1）、ImageNet 特徴はそれを持たないため。
   この比較は判定に使わず、記録だけする

## 5. Primary endpoint

候補・掃引点ごとの **5 折り平均の折り内 val macro Jaccard**（折り A は 3 seed の平均、他は 1 seed）。
co-primary は frame accuracy で、同方向であること。指標の定義は `conventions#eval_recipe`（online-causal、Jaccard strict）。

## 6. 判定規則（G1）

1. P\*-21 の recipe は、5 折り平均の val macro Jaccard が最大で、co-primary が同方向の候補・掃引点に決める
2. 最良と次点の差が折り A の seed 間 SD 以内なら、1 run の所要時間が短い方
3. それでも決まらなければ停止して利用者に諮る（decisions_required）
4. P\*-15 には同じ recipe を適用する。別のトーナメントは行わない
5. test は確定した塔（P\*-21、P\*-15）について折りごとに一度だけ評価し、test アクセス台帳に記録する。
   選定に test の値を使わない

## 7. 対照

- 折り A で、同じ特徴の**単フレーム線形分類**（時間ヘッドなし）を 1 seed 回す。候補 A がこれを上回らなければ時間ヘッドが働いていない
- 特徴抽出の決定性: 同じ入力で二度抽出し、要約値が一致すること

## 8. 停止条件

- 追加 6 動画の画像か注釈が無い → 停止して諮る（P\*-15 だけで進めるかは利用者が決める）
- 候補 A の折り A が単フレーム線形分類を下回る → 停止して諮る
- 特徴抽出の要約値が二度で一致しない → 停止
- 1 run が 1 時間を超える → run 数の見直しを諮る
