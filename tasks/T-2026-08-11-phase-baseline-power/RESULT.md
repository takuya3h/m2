## 4. 二つの揺らぎ（足す前と足した後）

| 時点 | 本数 | 種 | σ_rep | σ_seed |

| 足す前 | 17 | 3 | 0.0052501 | 0.0037141 |

**足した本数が 0 のため、両者は同一である。**

分解は釣り合わない一元配置の変量模型による。

    SS_w = Σ_i Σ_j (x_ij − x̄_i)²        df_w = N − k = 14   MS_w = 2.75638798e-05
    SS_b = Σ_i n_i (x̄_i − x̄)²           df_b = k − 1 = 2    MS_b = 1.04652782e-04
    n_0  = (N − Σ_i n_i² / N) / (k − 1) = 5.5882
    σ²_rep  = MS_w
    σ²_seed = max(0, (MS_b − MS_w) / n_0)      ← 0 への丸めは発生していない

**ホスト差による交絡を確かめた。** 分母は efros 14 本 / lecun 3 本の混在で、
`recipes_match` は `server_name` の相違を**警告しつつ True を返す**。efros のみ 14 本に
