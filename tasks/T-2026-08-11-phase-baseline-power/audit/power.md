## 式

n 本の種で対の差の平均を取ると、その揺らぎは `SE = σ_d / √n`。
事前登録の「二倍の揺らぎを超えて捉える」は `Δ ≥ 2 · SE` である。したがって

    Δ ≥ 2 σ_d / √n   ⇔   n ≥ (2 σ_d / Δ)²
    n_req = ceil((2 σ_d / Δ)²)   ただし下限 1

## σ_d の取り方が二つある

| 取り方 | σ_d | 由来 |
|---|---|---|
| **分解由来（事前登録の決め方）** | **0.0074248** | `σ_d = √2 · σ_rep`。両側が同じ種を共有し、再現しない分だけが独立に乗ると見る |
| 前契約の直接の実測 | 0.0035940 | 容量を足したときの対の差の揺らぎとして実測された値 |

**両者は 2.066 倍食い違う。** n は σ_d の二乗で効くため、約 4.3 倍の差になる。

食い違いの正体は独立の仮定である。`σ_d² = 2 σ_rep² (1 − ρ)` と置くと、実測に合わせるには
**ρ = 0.766** の正の相関が要る。対の両側は同じ種・同じ凍結源・同じ並び順を共有し、
違うのは注入の有無だけであるから、正の相関が生じること自体は説明が付く。
**どちらが正しいかは本契約では決められない。** 記録して次へ回す。

## 決めた本数（G2）

事前登録により、**中の大きさ 0.010 を捉えられる本数**を本命に要る数とする。

| 項目 | 値 |
|---|---|
| 要る種の数 | **3** |
| 既存の種 | **3** |
| 足す本数 | **0** |
| 上限（6）への到達 | していない |

**保守的な方（分解由来）でちょうど 3、直接実測の方なら 1 である。**
どちらの見積もりを採っても既存の 3 種で足りる。**結論は σ_d の取り方に依存しない。**

事前登録は「既存の種がその数に足りなければ、足りない分だけ足す」と定めている。
3 は 3 に足りているため、**足す本数は 0 である。**

事前登録は併せて「**結果を見てから本数を増やさない。増やせば、揺らぎの見積もりが
都合のよい方へ寄る**」と定めている。したがって 0 を上回る本数を走らせることはできない。

## 契約の他の部分との食い違い

**算出結果は契約の次の三点と食い違う。実測と事前登録に従い、記録する。**

1. `outputs.expected_runs: 6` — 起票者は 6 本を足すことを見込んでいた。算出は 0 である。
2. Phase D Step 1・2 は「足す前／足した後」を並べる表を求めている。足す本数が 0 のため
   両者は同一になる。
3. Phase C の G3（足した run の照合）は、照合の対象が存在しないため空振りになる。

食い違いの原因は、起票者自身が SPEC で言い直したことと同じ構造にある。SPEC は
「本命の差は同じ種で対にして取るため、既存の分母の揺らぎはその式に入らない。
効くのは基準点との比較の側だけである」と書いている。**本数を決める式は対の側から
出るため、分母を厚くしても本命の判定力は上がらない。** 分母を厚くする価値は
基準点との比較の側に限られ、それは事前登録の決め方の対象外である。
