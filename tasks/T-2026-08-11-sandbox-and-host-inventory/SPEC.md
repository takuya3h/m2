# Phase A — 隔離が作れない原因を測る

## Task 1: 道具の側か環境の側かを切り分ける

**Files:** なし（読み取りのみ）

- [ ] **Step 1: 道具を介さずに名前空間を作れるか測る**

**これが切り分けの本体である。** 隔離の道具が出す説明文を信じない。

    unshare --user true; echo "user_ns_exit=$?"
    unshare --user --map-root-user true; echo "map_root_exit=$?"
    unshare --mount true; echo "mount_ns_exit=$?"

| 結果 | 意味 |
|---|---|
| すべて成功 | **環境は名前空間を作れる。原因は道具の側** |
| 利用者名前空間だけ失敗 | 環境の側。ただし設定は許可されている。**別の制限がある** |
| すべて失敗 | 環境の側。より根本的な制限 |

**片方だけでは切り分けられない。3 つとも測る。**

- [ ] **Step 2: 道具の実体を調べる**

    ls -la $(command -v bwrap); command -v -a bwrap
    ls -la /usr/bin/bwrap 2>&1; ls -la /usr/local/bin/bwrap 2>&1

**権限ビットが付いているかを見る。** 系の標準の場所にも別の実体があるかを確かめる。

**両方が存在する場合、どちらが使われるかは経路の順序で決まる。** 順序も記録する。

- [ ] **Step 3: 系の標準の実体があれば、それでも測る**

Step 2 で別の実体が見つかった場合、**その実体で同じ操作を試す。**

    /usr/bin/bwrap --ro-bind / / --dev /dev true 2>&1; echo "system_bwrap_exit=$?"

**見つからなければ「存在しない」と記録する。** 推測で結論しない。

- [ ] **Step 4: 隔離された環境の中にいるかを測る**

    cat /proc/1/cgroup 2>&1
    cat /proc/self/uid_map 2>&1
    ls -la /.dockerenv /run/.containerenv 2>&1
    systemd-detect-virt 2>&1; echo "virt_exit=$?"

**4 つとも記録する。** 1 つの指標で断定しない。

- [ ] **Step 5: 制限の候補を網羅的に読む**

    sysctl -a 2>/dev/null | grep -i "userns\|unprivileged\|namespace" > /tmp/ns_sysctl.txt; wc -l /tmp/ns_sysctl.txt; cat /tmp/ns_sysctl.txt

**0 行なら探し方を疑う。** 別の語でも探し、それでも 0 行なら「該当する設定が無い」と結論する。

- [ ] **Step 6: G1 — 切り分けを確定する**

Step 1 から Step 5 の結果から、**道具の側か環境の側か**を結論する。

**どちらとも言えない場合は `UNKNOWN` とし、何が分かれば言えるかを書く。**
**推測で結論しない。** `on_fail: ask` に従い、測った表を提示して判断を仰ぐ。
