# 同期の抑止に所有の記録を付け、外す道具を置く。会話の抽出物を共有フォルダへ移す

**task_id:** `T-2026-10-07-pause-release-tool-digest-relocate`  **kind:** impl
**推奨する実行ホスト:** efros（ほかの台でもよい。実行したホストを報告に書く）
**分岐:** `feat/pause-release-tool-digest-relocate`（`make task-start` が導く）
**PR の base:** `phase0`。**GPU:** 本契約では GPU を使用しない。

## 1. 目的と背景

二つの問題を一本の契約で片付ける。

**問題 1: 抑止の解除が機械化されていない。** `make task-start` は `.sync-pause` を置くが、
外す処理はどこにも無い。手順書（SKILL.md）の命令例に付いた注記だけが解除を求めている。
解除を忘れると、そのホストだけ自動同期が止まったままになる（中心 philip で取り残しの実例がある。
`tasks/inbox.d/T-2026-08-25-sync-ignore-scope.md`）。

**問題 2: 会話の抽出物が作業ツリーを汚す。** 終了フックはセッションの最後、つまり契約の最後の
commit の後に抽出物を `docs/sessions/digest/` へ書く。次の契約の `make task-start` は
未追跡が一件でもあると止まるため、ほぼ毎回止まる。

### 利用者の決定（2026-10-07、運用会話）

1. 抽出物は版管理に記録しない。出力先を repo の外の共有フォルダ `~/claude-sync`
   （Syncthing の共有フォルダ。全台へ配られる）の配下へ移す。旧い置き場は版管理の対象から外す。
   理由: repo は公開であり、会話由来の抽出物を公開する必然性が薄い。全台からの検索は共有フォルダで保てる
2. task_start.sh が置く目印に**所有の記録**（どの契約が置いたか）を入れる
3. 外す道具は、完了の終わり方で次の前提を**すべて必須**とする（§3 の R6）。台帳の状態は前提に含めない
4. 解除した後の分岐はそのままにする（定位置の分岐へ戻さない）
5. 手順書（SKILL.md）の改訂は**別の契約**で行う。本契約では SKILL.md を変えない

**決定 1 は 2026-08-09 の「抽出物は版管理へ記録する」の撤回である。** 文書の改訂（Task E）で
撤回の日付と理由を本文に残すこと。

## 3. 達成すべきこと

手段は実装を読んで決めてよい。決めた手段と理由を報告に書く。

### 所有の記録（task_start.sh）

- **R1** 新たに置く目印の中身に、少なくとも契約の識別子を入れる。中身の形は実行者が決める
  （外す道具が読めること）
- **R2** 既存の振る舞いを変えない。終了コード（0、2、3、4）、実行前から在る目印に触れないこと、
  失敗時に自分が置いた目印だけを消すこと

### 外す道具

- **R3** 入口は Makefile に足す（名前は `task-` で始め、既存と衝突させない）。スクリプトを直接
  呼ぶこともできるようにする。**後続の SKILL.md の契約がこの名前を引くので、報告に明記する**
- **R4** 終わり方は二つ。**完了**（PR まで済み、最後の報告を送った後）と**中止**（契約を完了せずに
  終える）。中止は理由の文字列を必須にする
- **R5** どちらの終わり方でも、最初に次の二つを確かめ、満たさなければ外さない
  - 目印の所有者がこの契約である（所有者が違う、または読めない目印は外さない）
  - 目印の位置が m2-sync.sh の読む `$M2DIR` 直下と一致する
- **R6** 完了の終わり方では、次の前提を**すべて**満たすときだけ外す
  1. 現在の分岐がこの契約の分岐である
  2. 追跡下に未 commit の変更が無い
  3. 遠隔へ送っていない commit が無い（遠隔に分岐が在り、先頭が一致する）
  4. phase0 向けの PR が在る（開いているか、統合済み）
  5. `tasks/` 配下のこの契約の `RESULT.md` と `result.yaml` が HEAD に含まれる
- **R7** 前提が**欠けている**ことと、**確かめられない**こと（照会の失敗など）を区別して表示する。
  どちらの場合も外さない
- **R8** 外し方は削除を優先し、削除が拒まれたら無視される名前（`.sync-pause` で始まる名前）へ移す。
  どちらの場合も、外した後に目印が存在しないことを確かめてから終える
- **R9** 目印が元から無ければ何もせず、その旨を失敗と区別して返す
- **R10** 結果を区別できる終了コードで返し、**加えて一行の状態表示を出す。** `make` 経由では失敗が
  make 自身の終了コードに潰れるため、状態表示だけで結果が分かるようにする
- **R11** 道具は commit、push、統合、stash、分岐の切り替え、目印以外のファイルの削除を行わない。
  前提を確かめるために遠隔を参照するのはよい
- **R12** 試験のために目印の位置を差し替える手段を設けるなら、その手段を使わないときは
  m2-sync.sh と同じ位置に解決されること

### 抽出物の置き場

- **R13** 既定の出力先を `~/claude-sync` 配下の専用のディレクトリにする。名前は実行者が決めて報告する
- **R14** どのホストの記録かが、ファイルの名前か中身で分かるようにする
- **R15** 第二の実装系の走査は、**切り替え前に旧い置き場へ抽出済みの記録を、新しい置き場へ作り直さない**

- **R17** `.gitignore` に旧い置き場を足す。各ホストに残っている未追跡の抽出物が汚れとして数えられなくなる。
  **追跡済みの 48 件は追跡のまま残す**
- **R18** 伏せ字は従来どおり抽出の後に適用する

### 文書

  `git add docs/sessions/digest/` の指示を消し、新しい置き場と検索の方法を書く。

## 7. 想定外と停止条件

- m2-sync.sh か keeper が目印の中身を読んでいる → 停止して諮る（中身を書くと挙動が変わりうる）
- task_start.sh の既存の振る舞いを変えずに所有の記録を入れられない → 停止して諮る

- `make task-start` が作業ツリーの汚れで止まった → 開始前から在る未追跡は repo の外へ退避してよい。
  抽出物（`docs/sessions/digest/` の未追跡）は消さずに退避し、本契約の統合後は無視されるため戻してよい。
  それ以外の退避物は報告の後に戻す。退避先と一覧を audit に残す
- 実行基盤が書き込みや `rm` を拒む → 回避せず利用者に提示して許諾を得る。
  退避の `mv` が拒まれた場合は、要約値を記録してその場に残す
- 起票者の事実（§2）と実測が食い違う → 実測を正とし、起票者の誤りとして記録する
