## 4. 量の定義

既存の道具が在れば、その定義を正とする。下と食い違う点があれば差を記録する。

- **地図**: backbone の最後の空間特徴に対し、対象クラスの点数（softmax の前）の勾配を重みにして
  チャネル方向に足し合わせ、負の値を 0 にしたもの。点数は時間ヘッドの出力であり、過去フレームの特徴も入力に含む
- **寄与率**: 地図を元画像の大きさへ広げたうえで、領域の中の合計を画像全体の合計で割った値
- **密度倍率**: 寄与率を、領域の面積が画像に占める割合で割った値
- **四領域**: 術具の枠のみ／手の枠のみ／両方の重なり／どの枠にも入らない部分。互いに重ならない
- **正規化前の大きさ**: 地図を最大値で割る前の最大値と総和。フレーム間・時刻間の比較はこの値で行う
- **対象クラス**: 元の予測クラスと GT クラスの両方。二系統を比べるときは GT クラスの地図を使う

### Task D — 遮蔽

入力画像の画素を隠し、予測の変化を測る。

1. 隠す領域
   - 四領域（§4）のそれぞれ
   - 標的群の術具の枠だけ／陰性対照群の術具の枠だけ
   - 対照: 面積を揃えた、枠と無関係な位置（面積の効果と領域の効果を分けるため）。
     無関係な位置が取れないフレームは数えて除くか、重なりの割合を記録する
   - 対照: 全面
   - 対照: 何も隠さない（経路の検証）
2. 隠す範囲は二つ
   - 現フレームだけ隠す。過去フレームは元のまま
   - その動画の全フレームで同じ種類の領域を隠す。各フレームは自分の枠で隠す
3. 隠し方は一つに固定し、全条件で同じにする。選んだ理由と、学習時の前処理との関係を記録する
4. フレームごとに保存するもの: 予測が変わったか、元の予測クラスと GT クラスの点数（softmax の前）と確率
5. 器具は過去フレームにも写っている。**現フレームだけの結果で「不要」と書かない。** 二つの範囲を必ず並べる

### Task E — 過去フレームの寄与

1. 時間ヘッドが何フレーム前まで見うるか（受容野）を実装から読み、記録する
2. **時刻ごとの寄与**を二つの流儀で測る。対象は元の予測クラスと GT クラスの点数
   - 勾配に基づく寄与（過去の各時刻の特徴について、勾配と特徴の積の和。プラスとマイナスを分けて保存）
   - 入れ替えに基づく寄与（過去の特徴を対照に入れ替えたときの点数の変化）。
     何に入れ替えるかは計算の前に決めて記録する。少なくとも「現フレームより前をすべて入れ替える」と
     「直近から順に範囲を広げる」の形を含め、現フレームだけで予測がどこまで保たれるかを読めるようにする
3. **対照（両方向）**: 受容野の外の時刻を入れ替えても点数が変わらない。受容野の内側の直前のフレームを入れ替えると変わる
4. **位置の寄与**: 過去フレームのうち地図を作るものを、**結果を見る前に規則で決め、時刻つきで `audit.md` に残す**。
   時刻ごとの寄与が大きいものと、固定の間隔のものの両方を含める。数は実行者が決める
5. 選んだ過去フレームについて、その画像の中の地図を §4 の定義で作り、**そのフレーム自身の枠**と照合する。
   現フレームの地図と比べるときは正規化前の大きさを使う

| 折り A の塔、画像、注釈のいずれかが無い | 停止して諮る |
| 折り B・C・E の塔や注釈が無い | その折りを外して進める。欠けの一覧を RESULT に書く |
| 記録の val 主指標が再現しない | 停止して諮る |
| 空いている装置が無い | 停止して諮る |
| 装置の記憶量に収まらない | まとめて流す枚数を下げてよい。完了判定 d で結果が変わらないことを示す |
| 既存スクリプトが W&B や `experiments/` への出力を要求する | 既存コードを変えずに済む経路を実装から決める。挙動を変える変更が要るなら停止して諮る |
| 既存の道具が無い、または動かない | §4 の定義から作る。逸脱に書く |
| 同期が途中で材料が増減する | 増減が止まるのを待たず、その時点の状態を記録して諮る |
| 実行基盤が書き込みや `rm` を拒む | 回避せず提示する |
| `taskindex-check` と `inbox-check` が終了コード 2 を返す | 禁止 5 による想定どおりの結果。再生成しない |

## 9. 報告の構成

`RESULT.md` は起票者が判断に使う事実だけ。目安 150 行以内。

| 節 | 内容 | 入れないもの |
|---|---|---|
| 判定 | verdict と各関門 | 手続きの全文 |
| 完了判定 | 表。各項目に実測値 | 命令の全文 |
| 実測 | 対象のフレーム数と欠けの一覧、折りごと系統ごとの再現値、受容野、遮蔽の変化率（条件×範囲×系統、動画単位）、現フレームと過去の寄与の割合、枠の組み替えの対照との差 | 経過の説明 |
| 起票者の誤り | 型と内容。一件 3 行以内 | 引用の全文 |
| 逸脱 | 何をなぜ | 手順の再掲 |
| 想定外・UNKNOWN | 測れなかったものと理由 | 不要なログ |
| 送出 | PR 番号、base、終了コード | 出力の全文 |

`audit.md` へ: 命令とその出力、参照の解決の全文、材料の探索の記録、検証の出力、過去フレームの選び方の記録、変更範囲の一覧、台帳の応答。
`RESULT.md` からは `audit.md` を行番号で指す。同じ内容を二度書かない。

`REPORT.md` には、観察と、次の四つの読みのうち区別できたもの・できなかったものを書く。

- 読み a: 寄与の位置は合っているが、器具の種類を弁別できていない
- 読み b: 空間特徴ではなく時間ヘッドが誤らせている
- 読み c: 現フレームの寄与が小さく、過去の文脈で決まっている
- 読み d: 動画の術式が学習動画と違う
