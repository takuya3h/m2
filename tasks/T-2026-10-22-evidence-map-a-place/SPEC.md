# 証拠地図 A v2 と元の報告七件を docs/evidence/ に置き、様式の検査と書誌の照合を行う

**task_id:** T-2026-10-22-evidence-map-a-place  **kind:** impl  **PR の base:** phase0

**本契約では GPU を使用しない。**

## 背景

工程塔の候補の証拠地図 A を、新様式（docs/evidence/README と雛形 _template.md の様式）で作り直した（地図 A v2、下書き）。元の報告は A2（時間モデル）の四件（問い (9)(10) だけの補足の一件を含む）と A3（事前学習・基盤モデル）の二件で、ChatGPT の deep research と Claude の調査の二つのエンジンによる。旧地図 A（2026-09-16、v1）の 15 行も移し、その元の報告 A1 も置く。地図は報告に書かれた事実だけを載せ、報告者の解釈と提案は載せていない。

照合が済むまで、地図を提案カードの生成会話へ渡さない（docs/evidence/README）。本契約は三つを行う。

1. **置く。** 地図 A v2 を docs/evidence/ に、元の報告七件を docs/evidence/reports/ に置く。旧地図 A の表題の直後に v1 と後継を明記する一段落を挿入する（spec の amendments の決定1）
2. **検査と照合。** 様式の検査と書誌 ID の照合を行い、結果を docs/evidence/verification/ に残す
3. **並べる。** 抽出した ID の集合を expected-ids.txt と、分類の件数を本書の予測と並べる。**予測と違っても地図は直さない。** 差の反映は起票者が報告の後に扱う

前例は T-2026-10-18-evidence-verify-place（地図と報告を置いて照合した契約）と T-2026-10-19-evidence-maps-revise（地図を置き換えて照合し直した契約）。

## 環境の罠（実行者が知り得ないこと）

1. **bengio の .git/info/exclude に、Syncthing で届く他の契約の出力を外す行がある。** 消さない。experiments/ の未追跡を移さない・消さない（同期で他の台からも消えうる）

3. **arXiv の API は 429 を返し続けることがある。** 照合器は待ちを段階的に延ばす。間隔を詰めない。本契約の arXiv の ID は 96 件で、前例（地図ごとに 29〜37 件）より多く、時間がかかる
4. **make 経由では照合器の失敗が終了コード 2 に潰れる。** 照合器の終了コード（0、1 不在、2 使い方、3 到達不能）を見分けるなら tools/ を直接呼ぶ
5. **様式の検査（tools/check_evidence_map.py）は、違反があっても終了コード 0 を返す**（起票者が phase0 39dd92d6 の写しで、報告の sha256 を一か所壊した地図で確かめた。出力は「違反 1 件」、終了コード 0）。**判定は出力の「違反 N 件」の数で読む。** 終了コードで判定しない
6. **bengio の make test は収集の段で止まる**（third_party のファイルの欠落。前例の記録）。本契約はコードを変えないので試験は回さない。変更範囲で示す
7. **make spec-check は TASK を付けて回す**
8. **生成物の再生成と context-check・inbox-check・taskindex-check を本契約の分岐で回さない。** make forbidden-check は使う
9. **手順書が求める受け皿（tasks/inbox.d/ の本契約の一件）と本契約のディレクトリは変更範囲に入っている**
10. **元の報告に私用領域の文字がある。** 報告は様式の検査の対象外で、そのまま置く
11. **地図の行には、報告に著者・年が無く、報告の呼び名だけを書いた行がある**（照合不能の 17 件）。照合器は「年も『ほか』も無い」形を書誌なしとして読む（docs/evidence/README）。これは照合器の誤りではない
12. **受け渡しのファイルのうち三件は読み取り専用の属性で届くことがある。** 置いた後の属性は repo の既存の文書に合わせてよい（中身は変えない）

## 想定外のときの扱い

- 起点の要約値が表と違う、受け渡しの九件の要約値が違う → 停止して利用者に判断を求める（G1）

- 実行基盤が操作を拒む → 回避せず利用者に提示して許諾を得る
