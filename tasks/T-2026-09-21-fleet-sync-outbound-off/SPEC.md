## Goal

**中心の同期処理の外向き通信は止まった。** 手順は前契約の `handoff.md` に確定している。

**残る六台に同じ変更を、中心から SSH で順に当てる。**

| 別名 | 住所 | 口 |
|---|---|---|
| lecun | 192.168.196.176 | 50072 |
| bengio | 192.168.196.105 | 50072 |
| andrew | 192.168.196.190 | 50072 |
| ilya | 192.168.196.63 | 50072 |
| efros | 192.168.196.227 | 50072 |
| dlsta | 192.168.196.54 | 50072 |

**中心の `~/.ssh/config.d` の別名で解決する。** 六台とも公開鍵で入れることを利用者が確かめた
（`BatchMode=yes` / `PreferredAuthentications=publickey` で exit 0）。

### 確かめていないこと — どの鍵で入ったか

**中心からノードへ向かう鍵は、これまでの契約で一度も作っていない。**
入れたのは**利用者の端末の鍵が転送されていた**可能性がある。

**その場合、転送の無いセッションでは失敗する。** Task 1 で確かめる。

**禁止 2 と 3 が要である。** 七台の接続を切らない。

**ノードで命令を実行することは本契約で許す。** ただし読み取りと、`handoff.md` の項目の変更に限る。

**禁止事項は実行者の操作に対するものであり、同期処理による配布を含まない。**

### 規約と申し送り

**`proposal_gate` の禁止語を送出物に当てる。** `folds` と `symmetry` は適用されない見込み。確かめて記録する。

**`conventions#issuer_cautions` を参照する**（注入される）。

- **手順の正は `handoff.md`。** 本 SPEC と食い違えば `handoff.md` に従い、食い違いを記録する
- **ノードの遠隔のシェルは中心と違いうる。** 一度確かめてから命令を組む
- **一台ずつ当てる。** 一台が失敗したら次へ進まず判断を仰ぐ
- **`known_hosts` を汚さない。** 受け入れの控えを隔離する

`conventions_rev` は実行者が実測して置換する。`inputs.data` は参照しない。参照しなかったことを記録する。

## 想定外が起きたときの扱い

| 事象 | 対応 |
|---|---|
| **転送された鍵で入っていた** | **記録して報告。判断を仰ぐ** |
| **一台で失敗した** | **次へ進まない。判断を仰ぐ** |
| **中心との接続が切れた** | **報告する。自分で戻そうとしない** |
| 再起動しないと反映しない | **停止して判断を仰ぐ** |
| 版が中心と違うノードがある | **そのノードは変えない。** 記録して報告 |
| `handoff.md` と本 SPEC が食い違う | **`handoff.md` に従い、食い違いを記録する** |
| 実行基盤が操作を拒んだ | **迂回しない。利用者へ提示して許諾を得る** |

**言い訳をしない。事実と、測れなかったことを書く。**
