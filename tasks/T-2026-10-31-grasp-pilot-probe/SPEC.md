## 3. 信号と型の定義

**記号。** 注釈のあるフレーム = 把持関係 5 クラスの注釈があり、欠落の印（`loss_mask`）が付いていないフレーム。h は自分の左手か右手。
M_h,器具 は「h が扱う器具」のマスク、M_両手 は「両手で扱う器具」のマスク、M_h,手 は h の手のマスク。
**信号を作る関数は、正解（0 と 1 のマスク）と、二本目の契約の G の出力（画素ごとの確率）の両方に当てられる形にする。**
確率に当てるときは、存在 = 画素の確率の最大、面積 = 確率の和 ÷ 画素数、重心 = 確率で重みを付けた平均とする（0 と 1 のマスクでは下の定義と一致する）。

### 3.1 案 A — 把持の要約 g(t) と界面

- g(t) は 14 次元。時刻 t の 1 フレームだけから作る（online の規則）。**術具の種類は含めない**（カード）
  - h ごとに 5 個: 手の存在（M_h,手 に画素がある）、把持（M_h,器具 に画素がある）、扱う器具の面積（M_h,器具 の画素数 ÷ 画像の画素数）、
    重心 x・y（M_h,器具 の重心を画像の幅・高さで割った値。無ければ 0）
  - 両手で 4 個: 存在、面積、重心 x・y（M_両手 について同じ式）
- x(t) は 30 次元 = ［予測の半分 15 = g の 14 と旗｜正解の半分 15 = g の 14 と旗］。前回の検出から工程の形（使わない半分は旗ごと 0）にならう
  - 空の腕: すべて 0
  - 正解の腕: 予測の半分は 0 と旗 0。正解の半分は、注釈のあるフレームで正解の g と旗 1、無いフレームで 0 と旗 0
  - 予測の半分は二本目の契約で使う
- 界面: **D1 concat**（§2）を入力 30 次元で使う。受け取り手・学習範囲・処方・長さ・seed は前回の検出から工程と同じ。新しい型は作らない

### 3.2 案 B — 把持の地図 m(t) と新しい型

- m(t) は画素の 5 チャネル: 左手が扱う器具、右手が扱う器具、両手で扱う器具（把持関係 5 クラスから）、自分の左手、自分の右手（手 4 クラスから）。
  正解は 0 と 1。その種類の注釈が無いフレームのチャネルは 0
- 型: C5′ = C5 + W ∗ R(T(m))
  - T は、その画像に掛かった学習時・評価時の幾何の変換（反転、拡大縮小、切り出し、詰め物）。**地図は画像と同じ変換に従わせる。**
    チャネルの意味は反転で入れ替えない（手の印は画素に付いたまま動く）。詰め物の部分は 0
  - R は C5 の空間の大きさへの縮小（縮め方は実装を読んで決めてよい。記録する）
  - W は 1×1 の畳み込み（5 → C5 のチャネル数）。**bias なし、零初期化**。足す場所は neck の前（P1 の FiLM と同じ場所）
  - 界面のパラメータの名前は `phase_iface` で始める（W1 の選び方。§2）
- 空の腕は全チャネル 0、正解の腕は正解の m

### 3.3 案 D — 正解の枠ごとの把持の状態

- 検出塔の正解の枠 b ごとに、r_c(b) = （M_c と b の重なりの画素数）÷（b の画素数）。c は 左（左手が扱う器具）、右、両手
- 軟らかい 4 値 q(b) = （r_左, r_右, r_両手, 1 − Σ r_c）。重なりでΣ が 1 を超えるときは 1 で切る（記録する）
- 硬い状態 s(b): Σ r_c ≥ τ なら r_c が最大の c、そうでなければ「なし」。**τ = 0.1 を主にし、0.05 と 0.2 を併記する。** 注釈の無いフレームの枠は「注釈なし」

### 3.4 案 C — 標的を作る材料（本契約では標的を作らない）

- カードの 45 次元は、左手・右手・両手それぞれが握る術具の種類の分布（14 種となし）。repo の術具の分割は 31 クラスで、14 種との対応は未確認
- 本契約で測るもの: 術具の分割のクラスの名前と度数、14 種か検出塔の 15 クラスへの対応を書いた文書の在否、
  h ごと（と両手）に握られている術具のクラスの度数（M_h,器具 と最も重なる術具の分割のインスタンスのクラス。なしを含む）

- 実行基盤が書き込み・移動・削除を拒む（回避せず、利用者に提示して許諾を得る）

停止のときも、それまでの実測を `RESULT.md` と `audit.md` に書き、PR と `make task-report` まで行う。

## 10. 報告の構成

**`RESULT.md` は起票者が判断に使う事実だけ。150 行以内。** 命令と出力は `audit.md` に置き、`RESULT.md` から行番号で指す。

| 節 | 内容 |
|---|---|
| 判定 | status と G1〜G3 の結果 |
| 完了判定 | §8 の表に実測値 |
| 実測 | 使った注釈の集合と被覆、塔単独の再現値、案 A・案 B の腕ごとの 4 epoch 目の値と Δ空・Δ塔、読み出しの検査と誤りの数え上げの要約、1 本の所要 |
| 次の契約の材料 | G の構造の候補ごとの計測と費用の式、注釈の形の候補、学び直しの長さと費用、補助の頭の付け所、案 C の材料。研究上の判断が要る点は選ばずに並べる |
| 起票者の誤り | 型と内容。一件 3 行以内 |
| 逸脱 | 何をなぜ |
| 想定外・UNKNOWN | 測れなかったものと理由 |
| 送出 | PR 番号、`make task-report` の終了コード |

`REPORT.md`（`experiments/analysis/grasp_pilot_probe/`）には、腕ごとの全値、動画ごとの値、クラス別 Jaccard、界面の重みの推移、読み出しの検査の全値、
誤りの数え上げの全表、調査の全記録、§6.2 の読み方による記述、§6.3 の予測との照合、§6.4 の限界を置く。冒頭に「非公式の測定。関門と設計の判断に使わない」と書く。
