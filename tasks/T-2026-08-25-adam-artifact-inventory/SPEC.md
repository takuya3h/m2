### 本契約は読み取りだけを行う

**削除しない。移動しない。同期の経路も設定も変えない。他ホストへ接続しない。**

**控えを取ることは許す。** ただし**原本を動かさない。**

## 0. 前提と禁止事項

**版管理の位置は本ホストで未確認である。** 候補を順に試す。

    ls -d ~/slocal2/m2 ~/slocal/m2 2>&1
    cd ~/slocal2/m2 2>/dev/null || cd ~/slocal/m2
    pwd
    git --no-pager log -1 --format='%h %s'
    git --no-pager status --porcelain | grep -c ''

**どちらも無ければ停止して報告する。**

**常駐処理が動いていない可能性がある**（本ホストは再構築の対象外）。

    ls -la ~/bin/ 2>&1 | head -5
    grep -c "sync-pause" ~/bin/m2-sync.sh 2>/dev/null || echo "同期処理が無い"

**無ければ抑止は要らない。** その旨を記録して続行する。**在れば抑止を置く。**

| # | 禁止 |
|---|---|
| 1 | **何かを削除・移動する**（読み取りと複製だけを行う） |
| 2 | **同期の経路と設定を変更する。中継を張る。目印を作る** |
| 3 | 常駐処理と同期処理を起動・停止・再起動する |
| 4 | 他ホストへ接続する |
| 5 | 鍵を生成・変更・削除する |
| 6 | **生成物を再生成する** |
| 7 | **秘匿の値を出力・記録する。** 検査そのものが値を出力してはならない |
| 8 | 装置を使う |
| 9 | 未測定の値を書く（未測定は `UNKNOWN`） |
| 10 | `experiments/**` `transfer/**` `data/**` の中身を変更する |
| 11 | 学習・評価コードを変更する |

**禁止 1 が要である。** **何が失われうるかを測るための契約で、何かを失っては本末転倒である。**

**禁止事項は実行者の操作に対するものであり、同期処理による配布を含まない。**

## Task 2 (Phase B): 失われうるものを評価する

**Files:** Modify: `tasks/T-2026-08-25-adam-artifact-inventory/audit.md`

- [ ] **Step 1: 復元の可否で分類する**

**`audit.md` に表を作る。**

| 分類 | 意味 | 対処 |
|---|---|---|
| **版管理に原本がある** | 失われても戻せる | 何もしなくてよい |
| **他ホストにも在る** | 同期か手作業で戻せる | 優先度は低い |
| **本ホストにしか無い** | **失われたら戻らない** | **保全が要る** |
| 判別できない | | `UNKNOWN` |

**「他ホストにも在る」は本ホストからは確かめられない**（禁止 4）。
**推測で埋めず、`UNKNOWN` とするか、版管理の記録から判断する。**

- [ ] **Step 2: 版管理へ入れられるかを判断する**

| 判断 | 材料 |
|---|---|
| 入れられる | 大きさが妥当。秘匿を含まない。`.gitignore` に反しない |
| 入れられない | **大きすぎる**（重みや checkpoint）。秘匿を含む |
| 判断できない | 理由を書いて `UNKNOWN` |

**入れられないものは、同期で配るか、諦めるかの判断になる。** 本契約では決めない。

- [ ] **Step 3: 秘匿が混ざっていないかを確かめる**

**保全の候補に秘匿の値が含まれていれば、そのままでは版管理へ入れられない。**

**判定するのは件数ではなく形である。** 一致を一件ずつ確かめる。
**検査そのものが値を出力してはならない。** 長さと有無で測る。

**陽性対照を取る。囮は版管理へ入れない。**

- [ ] **Step 4: 控えを取る（原本は動かさない）**

**「本ホストにしか無い」ものについて、版管理の外へ控えを取る。**

**原本を動かさない。複製である。**

**控えの位置と要約値を記録する。** 原本と一致することを確かめる。

**大きすぎて控えを取れないものは、その旨を記録する。**
