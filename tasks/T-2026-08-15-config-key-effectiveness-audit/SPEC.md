# 設定に書いてある項目が実際に読まれているかを全て照合する

**task_id:** `T-2026-08-15-config-key-effectiveness-audit`  **kind:** `analysis`
**depends_on:** `T-2026-08-15-injection-signal-variants`
**実行ホスト:** `lecun`

## Goal

**設定に書いてある項目が、実装から一度も読まれていなかった事例が見つかった。**

前の契約で、注入の実験の設定にあった信号の形を指す項目は**ただの注釈**であり、
実挙動は別の項目が決めていた。**記述と挙動が一致していたのは偶然だった。**

**同じことが他の項目で起きていないかは、誰も調べていない。**

これは実験の妥当性に直結する。「設定にこう書いてあるから条件はこうだった」という
読み方が、**項目によっては成り立たない**ことになるからである。

**過去の run は 851 件ある。**その記録が条件を正しく表しているかを確かめる。

### 調べること

| # | 問い |
|---|---|
| 1 | 設定に現れるのに、実装から読まれていない項目はどれか |
| 2 | 実装が読むのに、設定に書かれていない項目はどれか（既定で動いている） |
| 3 | 読まれていない項目のうち、**条件として引用されうるもの**はどれか |
| 4 | 過去の run の記録に、実挙動と食い違う記述がどれだけあるか |

**3 が最も重い。** 読まれていない項目でも、誰も条件として引用していなければ実害は無い。
**引用されているものが読まれていないなら、その引用は誤りである。**

### 前の契約で確定していること（再測定は不要）

| 事実 | 実測値 |
|---|---|
| 実装から読まれていなかった項目の例 | 注入の実験の、信号の形を指す項目 |

| 索引の run の件数 | 851 |

# Phase B — 読まれていない項目を実挙動で確かめる

## Task 2: 名前の一致ではなく挙動で判定する（G2）

**Files:** Create `audit/effectiveness.json`

**「実装に現れない」だけでは、読まれていない証明にならない。**
**値を変えて挙動が変わらないことを、実際に走らせて確かめる。**

- [ ] **Step 1: 確かめる対象を絞る**

  「設定にあり実装が読まない」に分類された項目のうち、
  **条件として引用されうるもの**を優先する。

  | 優先度 | 例 |
  |---|---|
  | 高 | 学習や評価の条件を表すもの。分割・凍結源・腕・信号の形など |
  | 中 | 最適化に関わるもの |
  | 低 | 記述だけのもの。名前や覚え書き |

  **全部を確かめられなくてよい。** どれを確かめ、どれを確かめなかったかを記録する。

- [ ] **Step 2: 値を変えて挙動が変わらないことを確かめる（G2・要点）**

  対象の項目について、**値を変えた設定で短く走らせ、結果が変わらないこと**を確かめる。

  | 確認 | 期待 |
  |---|---|
  | 値を変える前 | ある結果 |
  | 値を変えた後 | **同じ結果** |

  **世代を最小にすること。** 本番規模を走らせない（禁止 10）。
  出力は `tasks/` 配下へ書く。

  **同じ結果になるかの判定に何を使ったかを記録する。**
  学習が非決定なら、**同じ値でも結果が揺れる。** その揺れより小さい差を
  「変わらなかった」と述べてはならない。

  **非決定の大きさは並行する契約で測られている。** 本契約では、
  **同じ設定で二度走らせた差**を先に測り、それを判定の基準にすること。

- [ ] **Step 3: 読まれている項目で、値を変えると挙動が変わることを確かめる（G2・対照）**

  **これが対照である。**

  「設定にあり実装が読む」に分類された項目を**少なくとも一つ**選び、
  **値を変えると結果が変わること**を確かめる。

  | 確認 | 期待 |
  |---|---|
  | 読まれない項目 | 変えても**変わらない** |
  | **読まれる項目** | 変えると**変わる** |

  **後者を確かめなければ、測り方が壊れていて何を変えても変わらない場合と
  区別できない。** 変わらなければ **G2 は `stop`。**

- [ ] **Step 4: 判定できないものを分類する**

  丸ごと渡す経路などで辿れず、短く走らせても差が非決定の揺れに埋もれるものは、
  **`UNKNOWN` として記録する。** 憶測で「読まれている」「読まれていない」と書かない。

| Phase B 完了判定 | 期待 |
|---|---|
| 確かめた項目と確かめなかった項目 | 明記 |
| 同じ設定で二度走らせた差 | 実測値。判定の基準として使った |
| 読まれない項目で変わらないこと | 実測値 |
| **読まれる項目で変わること** | **実測値。対照** |
| 判定できないもの | `UNKNOWN` として列挙 |
