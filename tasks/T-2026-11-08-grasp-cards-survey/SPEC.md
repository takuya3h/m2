## 2. 測るもの（S1〜S7）

### S1 工程塔の空間特徴（案 3）

1. `PT_CACHE` の中身の形（配列の名前、次元、空間の軸の有無）と、作った台本・層を記録する
2. fine-tune の checkpoint（`PT_FT_CKPT`）を読み、val の 1 動画について、layer4 の出力（空間の地図）を評価時の前処理で取り出す。形（チャネル・高さ・幅）、1 フレームの時間、1 動画の保存の大きさ（fp16 で保存した場合も）を記録する
3. 対照: 取り出した地図の空間平均が、同じフレームの既存のキャッシュの特徴と許容差（相対 1e-3）で一致すること。別のフレームの特徴と比べると一致しないこと
4. 案 3 が要る「マスクの外接矩形で切り出す」ために、地図の 1 画素が入力の何画素に当たるか（縮小率）を記録する

### S2 把持の注釈の密度（案 4・5・6、全案の参照段）

1. 折り A の train と val の動画ごとに、術具注釈のあるフレーム数、HTS の把持関係の注釈があるフレーム数、loss_mask のあるフレーム数、工程注釈のあるフレーム数、工程注釈があって術具注釈の無いフレーム数を表にする
2. 対照: test の動画（04・05・07）を集合に混ぜると件数が変わる。存在しない動画番号で 0 件
3. 注釈の無いフレームの並び方（連続して欠けるか、散るか）を、欠けの連の長さの分布で記録する

### S3 術具注釈フレームの時間間隔（案 5）

1. 折り A の各動画で、術具注釈のあるフレームをフレーム番号（または時刻）の順に並べ、隣り合う差の分布（最小・5%・中央・95%・最大）を記録する。フレーム番号から時刻への換算（fps）の出所を書く
2. 工程注釈のフレーム（0.5 fps）と術具注釈のフレームの対応（同じフレームか、ずれるか）を記録する
3. これにより、案 5 の「過去 k 時点」が何秒の窓に当たるかが分かる。窓の設計は本契約で決めない

### S4 検出塔の出力の形と較正（案 1・4）

1. 評価の経路（`eval_relation_detr_map.py` と third_party の該当箇所）が NMS を使わないことを、実装の該当行で示す。1 フレームあたりの出力（query 数、クラス・得点・枠の形）を記録する
2. val の全フレームと train の一部（seed 42 で 1,000 フレーム）で、既存の checkpoint の出力を取り、得点の分布（分位点）と較正（得点の区間 10 の ECE。正解との対応は IoU 0.5 で）を記録する。train と val の ECE の差が、案 1 の #16「D の train での過信」の大きさになる
3. 出力先は本契約の置き場（重ねの BODY に書かない。§1 の罠）
4. 対照: 得点をすべて 1 にした写しで ECE が大きくなる

### S5 把持塔の中間特徴（案 2）

1. 確定の G の構造（Mask2Former 系。実装は repo の G の台本を読む）で、マスクの出力より前の層のうち、特徴を取り出せる候補を 2 つ以上挙げる（例: pixel decoder の出力、transformer decoder の query の出力。**実装を読んで決めてよい**）。各候補の名前・次元・空間の大きさ・1 フレームの時間を記録する
2. 確定の G と H1 で同じ層の特徴を同じ 100 フレームで取り、対応する次元ごとの相関の分布を記録する。案 2 の「交差適合の半分は基底が違う」の前提の実測。対照: 確定の G どうし（同じ重み）で相関 1
3. 重みは読むだけ。更新しない

### S6 工程塔の入力層の変更の可否（案 6）

1. `stage1_ptower_r3.py` の入力の経路（画像の読み込み・正規化・conv1）を読み、入力チャネル数を 3 から 8 に変えるのに何を変える必要があるかを記録する（conv1 の形、正規化、データの読み込み）。既存の台本は変えない。写しで確かめる
2. 写しで、conv1 を 8 チャネルにした ResNet-50（追加チャネルの重みは零、RGB の 3 チャネルは ImageNet の重みのまま）を作り、乱数のマスク 5 チャネルを連結した 1 batch の順伝播と逆伝播が通ることを確かめる。**optimizer の step は呼ばない。** 重みの要約値が前後で一致することを示す
3. stem が凍結である事実と、8 チャネルにするには stem を学ぶ必要があること（または追加チャネルの重みだけ学ぶ道があるか）を、実装の該当行で記録する。どちらにするかは決めない
4. 三周目の記録から、fine-tune 1 本（折り A）の壁時計と GPU の使い方を引く（S7 と共通）
