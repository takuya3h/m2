# 生成物の合流と抑止の解除を、実装系と併合の双方で成り立つ形にする

**task_id:** `T-2026-08-11-artifact-merge-and-pause`
**kind:** `impl`  **depends_on:** `T-2026-08-11-codex-parity`
**実行ホスト:** `lecun`（repo は `~/slocal2/m2`）

## Goal

前 task で第二の実装系から契約を通せるようになった。**その統合で 3 つの摩擦が実際に起きた。**

| 摩擦 | 実測 |
|---|---|
| **生成物の衝突** | 併合時に投影 2 件と集約結果 1 件が衝突し、人が手で解決した |
| **抑止の解除** | 目印の削除が実行基盤に拒否され、退避で代替した |
| **履歴の読み取り** | 頁送りが無いホストで失敗し、**終了コードを見る検査が空振りした** |

いずれも起票者の側の欠陥である。

**生成物の衝突。** 投影と集約結果は 1 ファイルに集まるため、並行して契約を回す限り必ず
衝突する。手順書は「触るファイルを分ける」と書きながら、**生成物が全契約で共有されることを
書いていない。** 併合のたびに人が解決するのは仕組みの欠落である。

**禁止領域の検査。** 完了判定に「生成物のある場所へ差分が無いこと」を要求しながら、同じ
契約の中で生成を必須にした。**指示どおり実行すると必ず判定を破る。** 起票者が毎回手で
命令を書いていることが原因であり、道具にすれば起きない。

**抑止の解除と履歴。** 削除が拒否される環境と、頁送りが無い環境がある。
どちらも手順書が前提を置いたまま検査していない。

## 0. 前提と禁止事項

分岐の作成と契約の取り込みは配布時の命令で済んでいる。**抑止の目印を確かめる。**

    cd ~/slocal2/m2 && ls .sync-pause >/dev/null 2>&1 && echo "抑止あり" || touch .sync-pause

**このホストの `.venv` には導入コマンドが無い。** 依存を増やす実装にしないこと。
要ると判断した場合は停止して報告する。報告まで終えたら抑止を解除する。
**解除の手段は Phase C で決める。削除に固定しない。**

| # | 禁止 |
|---|---|
| 1 | `runindex/**` `context/auto/**` を**手で**編集する（生成は可） |
| 2 | `experiments/**` `transfer/**` `data/splits/**` を変更・削除する |
| 3 | `context/conventions.md` を変更する |
| 4 | 学習・評価コードを変更する |
| 5 | `tools/harvest_runindex.py` `tools/build_context.py` を変更する |
| 6 | `~/claude-sync/**` を変更する（読むのは可。配布の経路が未特定） |
| 7 | 依存を新たに導入する（このホストには導入手段が無い） |
| 8 | 資格情報の値を出力・記録する |
| 9 | **外部への送信を `make task-report` 以外の経路で行う** |
| 10 | 配布台帳の**他の行**を変更・削除する |
| 11 | 演算装置を使う |
| 12 | 未測定の値を書く（未測定は `UNKNOWN`） |
| 13 | 統合する。自動統合を有効化する |

禁止 9 の理由。**外部への送信は一方向で取り消せない。** 秘匿の検査は `task-report` の
内側にあるため、別経路で送ると検査を通らない。承認は現在この環境で求められない設定である。

### 起票者からの申し送り

起票者の検査命令が検証対象を検証できていない誤りが **19 task 連続**で発生している。
**直近 1 日で 3 件を犯した。**

| 型 | 内容 |
|---|---|
| `check_does_not_check` | 設定を探す命令を repo の内側に限定し、実体が外にあることを見落とした |
| `self_contradiction` | 生成を必須にしながら、同じ場所への差分が空であることを要求した |
| `check_does_not_check` | 併合の解決手順で、頁送りに失敗した命令の終了コードを見た |

3 件目は**同じ日に自分で申し送りへ書いた注意を、自分の手順で守らなかった**ものである。
文言による自制は働いていない。

実行環境の対話シェルは bash ではない。**変数の直後に記号が続く場合は波括弧で囲むこと。**
配列の添字による終了コードの取得は使えない。単語分割も起きない。

**別のホストには対話用の頁送りが無かった。** このホストにあるかは未測定である。
履歴を読む操作は `git --no-pager` を使い、**終了コードではなく行数と中身で判定すること。**

**本 SPEC の検査も同型の誤りを含みうる。** 次を守ること。

| # | 注意 |
|---|---|
| 1 | 一致件数が 0 のとき、別の探し方でも 0 になることを確かめる |
| 2 | 仕組みの挙動は実装を読んでから信じる |
| 3 | 記録を作る流れに表示用の切り詰めを混ぜない |
| 4 | 検査が空振りでないことを陽性対照で確かめる |
| 5 | 対象の一覧そのものが正しいかを確かめる |
| 6 | **終了コードで判定する前に、その命令が本当に走ったかを確かめる** |
