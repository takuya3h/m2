| AC | 受け入れ一覧・他の鍵・目印が期待どおり |
| AD | 禁止語の検査を送出物に当てた（陽性対照つき） |
| AE | 秘匿検査を自分で行った（検査が値を出力していない。陽性対照つき） |
| AF | 分岐が送出され PR が存在し、報告が台帳へ返り、抑止が外れている |
| AG | 退避したものを戻した（**入れ子を作っていない**。件数を記載） |

## 想定外が起きたときの扱い

| 事象 | 対応 |
|---|---|
| **中心へ入れない** | **停止して報告。** 目印を作らない |
| **中継が立たない** | **記録して報告。** `~/.tunnel.log` を読む。**実行権を戻さない** |
| **常駐処理が起動しない** | 構文と権限を確かめる。**記録を探して原因を書く** |
| **同期処理が起動しない** | 実行権と記録を確かめる。**周回を二度越えても起きなければ報告** |
| プロセスが三件以上 | **記録して報告。** 二件は正常 |
| **自動更新が走った** | **記録して報告。** Task 2 Step 1 が効いていない |
| **共有領域の中身が消えた** | **停止して報告** |
| 記録が衝突した | **正常である。両方残る。記録する** |
| repo の同期が終わらない | **待たない。** 進み方を記録する |
| 中心の状態が変わった | **停止して報告。** 本契約は中心を触らない |
| **実行基盤が操作を拒んだ** | **迂回しない。利用者へ提示して許諾を得る。** 抑止も外さない |
| **退避物を戻して入れ子ができた** | **消す前に要約値で重複を確かめる。** 一致しないものは消さない |
| 属性名が想定と違う | **実在する名前を読んで使う。推測しない** |
| **計数の器が壊れていた** | **直してから測り直す。** 壊れ方を記録する |

**言い訳をしない。事実と、測れなかったことを書く。**
