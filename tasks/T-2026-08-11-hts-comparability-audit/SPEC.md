## Goal

**測るのは「補助信号を足したこと以外の条件が揃うか」である。** 揃わない条件があれば、
差が補助信号の効果なのか条件差なのかを分離できない。

## 想定外が起きたときの扱い

| 事象 | 扱い |
|---|---|
| 既存の監査レポートが見つからない | **そこで止めない。** 別の探し方で探し、それでも無ければ Phase B の範囲を全問に広げる |
| 既存の監査が古く、注釈が更新されている | 更新時刻で確認し、**古い場合は測り直す。** どちらを採ったかを記録する |
| 領域注釈の実体が本ホストに無い | Phase B を `UNKNOWN` とし、Phase A と C は続行する。**測れなかった問いを明記する** |
| 把持関係のラベルが存在しない | **導出規則を発明しない。** 導出可能性の判断材料だけを出し、可否は `UNKNOWN` とする |
| 陽性対照が働かない | **G2 は `stop`** |
| 除外フレームが特定のクラスに強く偏っている | `escalate_if` に該当。**RESULT の冒頭に書く** |
| 実装が SPEC の記述と食い違う | **実装に従う。** SPEC のどこが誤っていたかを書く |
| 常駐処理が作業分岐へ統合を行った | **実行者の逸脱ではない。事実として記録する** |
