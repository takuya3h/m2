# 同じ種で走らせれば同じ結果になるようにする

**task_id:** `T-2026-08-15-training-determinism`  **kind:** `impl`
**depends_on:** `T-2026-08-15-injection-form-sweep`
**実行ホスト:** `andrew`

## Goal

**測りたい効果と同じ大きさの揺らぎが、走らせ直すだけで生じている。**

| 実測 | 値 |
|---|---|
| 同じ種で走らせ直したときの揺らぎ | **0.0052501** |
| 種を変えたときの揺らぎ | 0.0037141 |
| 測りたい効果の大きさ | **0.005 前後** |

**再現しない分の方が、種の違いより大きい。**この状態では、どの差も判定できない。

直前の実験で、**走らせる順序を変えただけで対の差の揺らぎが 10.9 倍になった**
（0.000823 → 0.0089343）。前の実験は種ごとに二つの腕を隣接して交互に走らせており、
直前の実験は腕ごとに一括で走らせた。**隣接させると雑音が相関して打ち消し合っていた**
とみられる。

**根治は、雑音そのものを消すことである。**同じ種で走らせれば同じ結果が出るようにする。

そうなれば対の差は厳密になり、**種が三つでも 0.001 級の効果が見える。**
既存の判定の基準そのものが変わる。

### ここまでに確定していること（再測定は不要）

| 事実 | 実測値 |
|---|---|
| 学習一本あたり | 通常の形で 6.59〜6.82 秒。段階を分ける形で 8.31 秒 |
| 種を変えた揺らぎ | 0.0037141 |
| 同じ種で走らせ直した揺らぎ | 0.0052501 |
| 腕ごとに一括で走らせたときの対の差の揺らぎ | 0.0079〜0.0136 |
| 独立と仮定した見積もり | 0.0074248。**一括の実測と同水準** |
| 隣接して走らせたときの対の差の揺らぎ | 0.000823（前の実験。三つの種） |
| 六つの腕の重みの総数 | 528919 で一致 |
| 母集団 | train 9657 / val 1515 / test 4265 |
| 決定性の監査 | 新しい入口は**非決定と分類されている**。既知の課題として記録がある |

**同じ種で走らせ直した揺らぎが 0.0052 であることが出発点である。**
これを零にできれば、対の差の揺らぎも零に近づく。
