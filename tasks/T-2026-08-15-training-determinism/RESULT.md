## 冒頭に置く結論

**同じ種なら重みまでビット単位で一致するようになった。** 支配的な非決定源は
cuDNN の畳み込みカーネル選択で、`cudnn.deterministic + benchmark=False` だけで
50 世代すべてが一致した。出荷した実装はさらに `use_deterministic_algorithms(True)`
と `CUBLAS_WORKSPACE_CONFIG` を併せた完全版（決定的でない演算は**落ちる**）。

**ただし対の差の揺らぎはゼロにならない。** 決定化後の σ_d は 0.0054519 で、
これは測定雑音ではなく**種×腕の真の交互作用**である。「種が三つでも 0.001 級が
見える」という期待は、雑音ではなく実在する種間の効果不均一に阻まれる。

**併せて、sweep の「隣接が相関を生む」仮説は否定された。** 直す前の隣接実行の
σ_d は 0.00736 で一括（0.0100）と同水準。前実験の 0.000823 は n=3 の偶然だった。

## 4. 対の差の揺らぎ（直す前 / 後、順序の二通り、同じ 3 種）

| 状態 × 順序 | 種ごとの差 | 平均 | pstd |
|---|---|---:|---:|
| 前・隣接交互 | +0.00924 / +0.02046 / +0.00264 | +0.0107811 | 0.0073568 |
| 前・腕ごと一括 | −0.01320 / +0.01122 / −0.00264 | −0.0015402 | 0.0100007 |
| **後・隣接交互** | +0.00924 / −0.00264 / −0.00198 | +0.0015402 | **0.0054519** |
| **後・腕ごと一括** | **（上とビット単位で同一）** | +0.0015402 | **0.0054519** |

**決定化後は順序を変えても差がビット単位で一致し、順序問題は消滅した。**
残る σ_d = 0.00545 は測定雑音ではない。各測定が厳密である以上、
**種によって注入の効き方が本当に違う**（seed 42 は +0.009、123/456 は ≈−0.002）。

## 5. 種の数ごとに捉えられる大きさ

    Δ_min = 2 σ_d / √n（σ_d = 0.0054519）

| n | Δ_min |
|---|---|
| 3 | 0.0062953 |
| 10 | **0.0034481**（sweep の実績 0.0056506 から改善） |

改善は「測定を厳密にした」分であり、これ以上は種を増やすしかない。
0.001 級を n=10 で見るには σ_d ≈ 0.0016 が要るが、残っているのは真の不均一である。

## 7. 数式が変わっていないことの確かめ方と結果

**CPU を対照に使った。** CPU のカーネルは元から決定的であるため、決定化の有無で
結果が変われば数式が変わったことになる。同じ種・同じ設定・CPU・2 世代で
on / off を走らせ、**loss を含む全数値が完全に一致した**
（epoch1 の loss 3.525164524714152 が両者で同一）。損失・層・最適化の手順には
触れていない（変更は乱数の届き方とカーネル選択のみ。禁止 12 遵守）。

## 8. 既存の実験の判定への波及（本契約の値打ち）

1. **「隣接すると揺らぎが小さい」（sweep の読み）は誤りだった。** 直す前の隣接実行を
   実際に行ったところ σ_d = 0.00736 で、一括と同水準。**前実験（#111）の 0.000823 は
   n=3 の偶然**であり、順序の産物ですらなかった。sweep が申し送った「隣接で走らせる
   再測定」は**やっても判定力は戻らなかった**ことになる。本契約がその前にこれを
   実測できたのは幸運である。
2. **#111 の「負の効果（−0.0044、比 5.345）」は信じてはならない。** 真の σ_d が
   0.0054 級である以上、n=3 の平均 −0.0044 の実際の比は 0.8 程度であり、
   当時の pstd 0.000823 が幸運に小さく出たことで有意に見えただけである。
   sweep で再現しなかったこと（+0.0004）とも整合する。
3. **今後の実験は決定化を有効にすべきである。** 各測定が厳密になり、順序の配慮が
   不要になり、σ_d は純粋に「種×腕の交互作用」を表す。残る不均一は種を増やすことで
   しか縮まない（n=10 で 0.0034 級）。
4. **基準点の σ_rep = 0.0052（電力契約）は「装置の雑音」ではなく「消せる雑音」だった。**
   既存 17 run の分母の揺らぎ 0.0059 のうち再現性成分は、今後の run では発生しない。
