# 四台の公開鍵を中心の受け入れ一覧へ登録する（philip）

**task_id:** `T-2026-08-24-philip-accept-node-keys`  **kind:** `impl`
**depends_on:** `T-2026-08-24-bengio-syncthing-node`
**実行ホスト:** `philip`（中心）  **repo:** `~/slocal2/m2`

## Goal

**一台目のノード（bengio）が中心へ入れずに停止した。** 切り分けの実測はこうである。

    経路      TCP が開き SSH が名乗る          生きている
    鍵の対    秘密鍵と公開鍵の指紋が一致        誤りなし
    提示      Offering public key が出る        提示している
    受け入れ  Server accepts key が出ない       中心が受け入れていない

**起票者の欠落である。** 各ノードは公開鍵を `scripts/sync/hub_keys/` へ出したが、
**それを中心の受け入れ一覧へ取り込む契約を書かなかった。**
前契約は禁止事項で受け入れ一覧の変更を自ら禁じ、完了判定に `UNKNOWN` と記録していた。

**本契約はその欠落を埋める。四台の公開鍵を追記する。**

**旧構成の登録は使えない。** 鍵は保守作業の後に作り直されており、当時の指紋は合わない。

### 最大の危険

**既存の登録を一件でも失うと、いま入れている経路も切れる。**
本ホストの受け入れ一覧に何が入っているかは**未測定**である
（前契約で実行基盤が認証情報への接触を拒み `UNKNOWN` になった）。

**読めない場合、追記もできない。** その場合は停止して報告する。
