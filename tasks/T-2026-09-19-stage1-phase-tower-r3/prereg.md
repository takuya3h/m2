## 1. 問い

二周目（T-2026-09-19-stage1-phase-tower-r2）は ImageNet 初期化の R50 を工程ラベルで fine-tune し、val 0.387 / test 0.256。
S4（検出 backbone 由来）の 0.645 に対し折り A で 0.177 の差が残った。実測で分かった非対称:

| 条件 | 検出塔 D\* | 工程塔 P\*（二周目） |
|---|---|---|
| COCO 検出の事前学習 | あり（D\*-COCO） | なし |
| 入力 | 短辺 480〜800、全画面 | 短辺 256 → 中央 224 切り出し。**横方向の 49% しか残らない** |

M §5.1（2026-09-18 改訂）: 両塔の初期化の鎖は in-domain より前の段をすべて揃える。公開データの事前学習は両塔で同じ構成。

## 4. 予測（結果を見る前に書く）

1. 全画面・高解像度で、5 折り平均 val は二周目（0.387）より **5 点以上**上がる
2. **P\*-COCO ＞ P\*-ImageNet**（COCO 検出の事前学習は工程にも効く。SurgMAE の初期化源の知見からの外挿）
3. 折り A の S4 との差は二周目（0.177）の**半分以下**に縮む
4. 学習率は **高い方（3e-4）** が勝つ
5. 時間ヘッドの最良は候補 C とは限らない

## 5. Primary endpoint

候補・掃引点・学習率・系統ごとの **5 折り平均の折り内 val macro Jaccard**（折り A は 3 seed の平均、他は 1 seed）。
co-primary は frame accuracy で同方向。定義は `conventions#eval_recipe`。

## 6. 判定規則（G1）

1. **系統ごとに**、学習率と時間ヘッドの（候補、掃引点）の組を、5 折り平均の val macro Jaccard が最大で co-primary が同方向のものに決める
2. 同点規則は二周目と同じ: 差が折り A の seed 間 SD 以内 → 所要時間 ±20% 以内なら構成の単純さ（A ＞ C ＞ B）→ 受容野の短い方 → 折り A の seed 間 pstd の小さい方
3. P\*-15 を系統ごとに確定。P\*-21 は画像があれば同じ recipe。**系統間の優劣は選定に使わない**（両方を確定する。Stage 2 の 2×2 に要る）
4. test は確定塔（最大 4: 系統 2 × データ 2）について折りごとに一度。台帳に記録

## 7. 対照

- **二周目の確定塔**（224 中央切り出し、ImageNet、lr 1e-4）と**一周目の確定塔**（凍結特徴）を同じ折りで並置。解像度と初期化の効果量が段階的に出る
- 折り A で二周目の値を下回る折りがあれば停止（高解像度で悪化するなら実装を疑う）
- 特徴の決定性: 二度で一致、backbone を変えると変わる
- COCO 系統の初期値の要約値が D\*-COCO の出発点と一致
- 折り A の S4 との並置（判定に使わない）

## 8. 停止条件

- COCO 検出済み backbone の重みが無い、または D の初期化と一致しない → 停止
- 一本の fine-tune が 3 時間超、または記憶領域が収まらない → 諮る（解像度を下げる案は出さず、上限と停滞の epoch 数の見直しを諮る）
- 二周目を下回る折りがある → 停止
- 特徴の要約値が一致しない → 停止
- 装置が使われている → 停止
