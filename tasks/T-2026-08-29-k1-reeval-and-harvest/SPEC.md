## 5. Phase C — 再評価と照合

### Step C-1 再評価

六 checkpoint それぞれを、Step A-2 で特定した既存経路・val 分割で評価し、
run ごとの acc と per-phase F1（少なくとも hemostasis）を得る。

- **評価器の対照**: 同一 checkpoint を二回評価して同値になること（決定性）。
  異なる checkpoint で値が異なること
- 使った計算資源（GPU の有無・型・所要時間）を記録する

### Step C-2 記録値との照合

seed 対応が不明なため、照合は二層で行う。

- **第一層（seed 対応に依らない量）**: 両側の 3 値の平均とばらつき（ddof=0）、
  および平均の差。これを §1 の表と伝播許容差で照合する
- **第二層（対応の存在）**: aligndetr 側と relationdetr 側の 3×3 の全対応（六通り）を試し、
  記録の paired 差三つ組（-0.0561 / -0.0726 / -0.0785）を許容差内で再現する対応が
  **存在するか・一意か**を確かめる
- **集計器の対照**: 陽性は記録の paired 三件から -0.069067 が再現されること（前契約で確立済みの器）。
  陰性は一件を除いた平均が不一致になること

結論は三値で書く:

- **一致（実測復帰）**: 第一層がすべて許容差内で、第二層の対応が一意に存在する
- **不一致**: 第一層のどれかが許容差外。量ごとの乖離を表にする（解釈はしない）
- **評価不能**: 実装経路・特徴・分割のいずれかが確定できなかった。何がどこまで出来たかを記す

第一層が一致し第二層の対応だけが見つからない等、解釈が割れる場合は escalate。

### Step C-3 A7 と総括への追記

出所の種別（本契約の再評価／記録側の記載／前契約の実測）を明記して追記する。

checkpoint からの再評価値と記録値の一致で連鎖を閉じた」と記す。

## 7. 禁止事項

1. runindex の手編集（収穫は make runindex のみ）
2. experiments 配下・data 配下への書き込み（読み取りは可。六 run への metrics 書き戻しを含めて禁止）
3. 分割の再定義
4. 評価規則の新設（既存の評価実装をそのまま使う。変更が必要になったら停止して報告）
5. 数値の推定を実測として書くこと。測れないものは UNKNOWN
6. 過去の報告・完了済み契約・履歴・Stage 0 の既存本文の書き換え（追記のみ可）
7. 秘匿情報の出力・複製・移動
8. 外部サービスへの書き込み・新規設定

**禁止は実行者の操作に対するものであり、同期処理による配布や衝突ファイルの生成を含まない。**

## 8. 想定外の扱い

| 事象 | 対処 |
|---|---|
| 収穫対象が棚卸しから増減している | 実測を優先し、増減の内訳を記録して収穫を続ける（既存行の変更・削除が出た場合のみ停止） |
| 評価経路が複数あり当時のものを特定できない | 候補と根拠を並べて停止（escalate）。適当に選ばない |
| checkpoint の読み込みに実装の版差で失敗する | 失敗の内容を記録して停止。**互換化のための改変はしない** |
| 六 run の一部だけ評価できた | 出来た分の値と出来なかった理由を記す。結論は「評価不能」ではなく部分結果として報告 |
| 再評価が記録と系統的にずれる（全量が同方向） | 乖離の表を作り escalate（環境差の可能性。解釈はしない） |
| GPU が塞がっている | CPU で試みる。所要時間が過大なら部分結果で停止 |

失敗時の巻き戻し: 変更は分岐上のみ。停止する場合も分岐と audit を残したまま stopped で報告する。

## 9. 報告の構成

RESULT.md は起票者が判断に使う事実だけを書く。目安は百五十行以内。

- 判定: verdict と関門の結果
- 完了判定: §6 の表に実測値を埋めたもの
- **K1 の結論**: 三値のどれか。run ごとの値と照合の表（全量は audit・成果物へ）
- 実測: 次の契約で使う値（収穫後の索引件数・runindex_commit・評価の所要時間と使用資源）
- 起票者の誤り: 型と内容。一件三行以内
- 逸脱・想定外・UNKNOWN・判断待ち
- 送出: PR 番号と終了コードのみ

命令とその出力の全文・再評価の過程・対照の出力は audit.md へ置き、
RESULT.md からは行番号で指す。同じ内容を二度書かない。
