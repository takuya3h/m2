## 2. 結論

事前登録の予測「推論結果を渡した腕が無情報な腕を上回る」は**外れた**。
同じ seed の差 `inj - ctrl` は3本すべて負で、平均 `-0.004400440044004379`。
事前登録の絶対値ルールは PASS したため方向性のある効果は検出されたが、その方向は
**改善ではなく悪化**である。把持信号の注入は平均 accuracy を約0.4400 percentage point 下げた。

これは「検出できず」でも「効果なし」でもない。**逆方向の効果を検出し、改善仮説を棄却した。**

### 事前登録の決め方は符号に対して対称である

**この区別を曖昧にしない。** 決め方は次の二分岐であり、どちらに当たるかは実測で決まる。

| 分岐 | 条件 | 述べ方 |
|---|---|---|
| 検出 | `abs(Δ) / σ >= 1` かつ全 seed 同符号 | 符号の向きに応じて**正の効果**または**負の効果が検出された** |
| 未検出 | 上を満たさず、かつ `abs(Δ) < 0.010` | **検出できなかった**（効果なしとは述べない） |

実測は次のとおりである。

| 量 | 実測値 |
|---|---|
| `Δ`（paired mean） | `-0.004400440044004379` |
| `σ`（paired pstd、ddof=0） | **`0.0008232469497852892`** |
| `abs(Δ) / σ` | **`5.345224838248179`** ≥ 1 |
| 全 seed 同符号 | `true`（`[-1, -1, -1]`） |

**したがって当たるのは上の分岐であり、「負の効果が検出された」である。**
「改善しなかった」ではない。

`abs(Δ)` は `0.010` を下回るが、**下回ることは未検出の条件ではない。** 未検出は
「決め方を満たさず、かつ `abs(Δ) < 0.010`」であり、本件は決め方を満たしている。
満たせた理由は σ が `0.00082` と小さいことにある。対にして取ったことで種による
揺らぎが消え、`0.0044` の差が σ の 5.3 倍として立った。

## 10. Deviations

1. generic task 手順では L3 が Phase A より先だが、P4 は Phase A の prereg commit 後でなければ
   通らない。初回 FAIL で停止し、ユーザー選択1により SPEC 固有順序を優先して再開した。
2. 原設定の task_id が旧実装契約のままで CLI 上書きも無いため、禁止された `configs/**` を変えず、
   task 配下に task_id だけ置換した実行用コピー2件を作った。その他の内容が原本と一致することを検証した。
3. detached 起動は実行基盤が子 process を回収し、run未生成・log 0 byteだった。継続PTYへ切り替えた。
4. runindex harvester が新 step の `arm` と `phase_accuracy` を拾わないため、Phase C は生 metrics と
   checkpoint 再評価で行った。変更禁止の harvester は直していない。
5. **索引の再生成が、過去の退避 run 34 件を同時に投影した。分母は不変であることを実測で確認した。**
   34 件は新しく書かれた副次ファイルの数であり、そのうち索引の母集団を増やしたのは
   ユニーク 6 run（索引 9 行）のみで、25 件は元から載っていた。索引から消えた run は 0 件、
   34 件はすべて除外印つきで、解析対象（`excluded=False`）の増分は +6、すなわち本契約の run
   だけである。過去の Δ の分母（`control_of` の指す先）8 件のうち、今回の投影で合流されたものは
   **0 件**であった。本契約が参照した分母は 17 run・平均 `0.8973014948553677`・
   pstd `0.005917073407586465` が前後で一致した。**続行の根拠はこの実測である。**
   詳細は §9.1 と `audit/coprojection.json`。B-36 そのものは本契約では直していない。
