# 設計の判断に使う val 動画の部分集合を、ラベルの統計だけで全数列挙し、設計側と清浄側の偏りを表にする

**task_id:** T-2026-10-07-design-val-subset-balance  **kind:** analysis

## 1. 背景

折り表（`conventions#folds`）では、15 動画すべてがどこかの折りで一度 test になる。
したがって、ある折りの val の動画は、別の折りでは test の動画である。
1 つの折りの中では漏れていない。しかし、全折り共通の設計判断を val の値で行うと、
その val 動画が test になる折りでは、test の動画を見て設計を選んだ形になる。

対処の一つは、全折り共通の設計判断に使う val 動画を一部に絞ることである。本契約では次の語を使う。

- **設計側** — 設計判断に使う val 動画の集合。S と書く
- **清浄側** — 15 動画から S を除いた集合。設計判断が触れていない test の動画である。C と書く

折り表の均衡は、各折りの test の 3 本に対して最適化された（`tasks/T-2026-09-17-fold-table/audit.md` §5）。
val の動画の部分集合が工程と術具をどれだけ代表するかは、測られていない。

本契約は、S の候補をラベルの統計だけで全数列挙し、利用者が選ぶための表を作る。
**本契約は集合を選ばない。推奨もしない。** どの集合を採るかは利用者が決める。

材料をラベルの統計に限る理由: モデルの値の高低で集合を選ぶと、結果の見え方で設計用の集合を選んだことになる。

**本契約では GPU を使用しない。**

### Task B — 指標と対照

val 動画の空でない部分集合 S のそれぞれについて、次を出す。C は 15 動画から S を除いた集合である。

**設計側（S）**

- 本数、フレーム数、box 数
- 工程の欠落数と、欠落した工程名（S に 1 フレームも無い工程）
- 術具の欠落数。標的群の欠落数と名前。陰性対照群の欠落数と名前
- 標的群の各クラスの box 数と、その最小値
- d(S)

**清浄側（C）**

- 本数、フレーム数、box 数
- 設計側と同じ定義の欠落数と名前
- d(C)
- 折りごとの清浄本数（その折りの test のうち S に入らない本数）と、その最小値

**印**

- S に含まれる公式 test の動画の本数、公式 val の動画の本数
- S が折りの val の和集合に一致するか。一致するなら、どの折りか
- 非劣の印。本数が同じ部分集合どうしで比べ、次の五つのどれでも劣らず、どれか一つで勝る相手が居ない行に付ける。
  全体での印と、公式 test を含まない部分集合だけでの印を、別の列にする
  - 設計側の標的群の欠落数（小さい方が勝る）
  - 設計側の工程の欠落数（小さい方が勝る）
  - d(S)（小さい方が勝る）
  - d(C)（小さい方が勝る）
  - 折りごとの清浄本数の最小値（大きい方が勝る）

**対照（両方向で取る）**

1. 均衡指標: 五折りの test の値が §2 と小数第 4 位まで一致する。15 動画全体の値は 0 になる。動画 1 本の値は 0 より大きい
2. 欠落の計数: 15 動画全体での欠落を記録する。入力から工程を一つ、術具クラスを一つ、記憶上で除くと、欠落がそれぞれ一つ増える
3. 群の照合: クラス名を一文字変えた群の定義では照合が落ちる
4. 清浄側: §2 の三行の内訳と突き合わせる。食い違えば、起票者の誤りか実装の誤りかを折り表から判定して記録する
5. val の導出: val の動画を自分の折りの test に置いた表（記憶上）で、検査が落ちる

対照のどれかが期待どおりでなければ、列挙に進まず停止する（Gate G2）。

## 6. 想定外のときの扱い

- 15 動画全体で一度も現れない工程か術具クラスがあった場合: 停止せず、その種類を欠落の母数から除くかどうかを決めずに、
  両方の数え方を列にして記録する
- 標的群か陰性対照群のクラスが、どの val 動画にも現れない場合: 停止せず記録する。文書の冒頭に書く
- 非劣の行が多く文書に載せきれない場合: 文書には件数と表示順の上位だけを載せ、全行は csv の印で示す
- 生成器の関数が部分集合に対してそのまま使えない場合: 生成器を変えず、新しい道具の側で同じ定義を実装し、
  五折りの test の値の再現で同じ定義であることを示す
- 測れなかったものは UNKNOWN と書き、理由を添える。推定値で埋めない
