## Goal

**efros が群れへ戻る。** 前契約で基盤が整い、**公開鍵と識別子が版管理へ公開された。**

**本契約は中心の側を整える。二つを登録する。**

| 対象 | 出所 | 置き先 |
|---|---|---|
| 公開鍵 | `scripts/sync/hub_keys/efros.pub` | **受け入れ一覧** |
| 識別子 | `scripts/sync/device_ids/efros.txt` | **同期処理の設定** |

**値は版管理から読む。本 SPEC に転記していない。**

### 二つの登録は性質が違う

| 登録 | 危険 | 反映 |
|---|---|---|
| 受け入れ一覧 | **既存を失うと、いま入れている四台も入れなくなる** | 次回の接続から効く。**再起動は不要** |
| 同期処理の設定 | **稼働中である。** 書き換えが上書きされうる | **起動時に読む。反映の手段を確かめる** |

**後者が本契約の難所である。** 中心の同期処理は四ノードと繋がったまま動いている。
**設定を変える手段と、それが効く条件を先に確かめる。**

### 既存の実測（再測定は不要）

| 項目 | 値 |
|---|---|
| 受け入れ一覧 | **五件**（人の端末 + lecun / bengio / andrew / ilya） |
| 権限 | **`600`**（本ホストの実測。`664` ではない） |
| 同期処理 | **稼働中。四ノードと接続。`22000` 待ち受け** |
| 版 | `v2.1.3` |
| 共有フォルダ | `claude-sync` と `m2`。ともに `sendreceive` |
| 設定の場所 | `~/.local/state/syncthing/`（既定の場所） |
| **既定値のひな型** | **`id=""` の folder がある。同期対象ではない。触らない** |
