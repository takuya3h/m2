## 4. 原典の式（起票者が原典から写した。実装はこれに合わせる）

記法: p_t は時刻 t のクラス確率、ŷ_{t−1} は直前の状態、c は ŷ_{t−1} 以外のクラス。

1. 証拠の増分（式 3）: δ_t(c) = log p_t(c) − log p_t(ŷ_{t−1})
2. 片側の累積（式 4）: E_t(c) = max(0, E_{t−1}(c) + δ_t(c))
3. 正規化（式 5）: Z_t(c) = E_t(c) ÷ (√n_t(c) × σ_t(c))。n_t(c) は証拠の個数、σ_t(c) は証拠の標準偏差の逐次値。**原典は n と σ の更新式と初期値を書いていない。** 実装者が決め、RESULT に書く（例: n は累積が 0 に戻ってからの個数、σ は δ の逐次の標準偏差。σ が 0 や n が 1 のときの扱いも決める）
4. 状態の更新（式 6）: Z_t(c) の最大が k を超えるなら ŷ_t はその c、そうでなければ ŷ_t = ŷ_{t−1}
5. 遷移の後、累積の統計（E、n、σ）を 0 に初期化する
6. 原典の k の既定は 0.4（Cholec80）と 0.8（AutoLaparo）。本実装の `egtp_k` は既定を置かず必須のまま（exp の掃引で決める）
7. 最初の状態は t = 1 の argmax。`starts`（クリップの先頭の初期化）の意味は今のまま
8. log は p の下限で守る（0 の確率で発散しないように。下限の値は記録する）
