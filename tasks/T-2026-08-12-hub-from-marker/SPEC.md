# 中心の指定を定数から目印へ移す（正本のみ）

**task_id:** `T-2026-08-12-hub-from-marker`  **kind:** `impl`
**depends_on:** `T-2026-08-12-ilya-hub-feasibility`
**実行ホスト:** `lecun`  **repo:** `~/slocal2/m2`

## Goal

設定共有を **efros / lecun / bengio / andrew / ilya の五台**で復旧させる。中心は
**lecun** と決まった。中継は「各ノードが中心へ SSH して転送を張る」形である。

**ところが中心は常駐処理の実装に定数で直書きされている。**

    # hub(philip)へのSSHトンネル維持（~/.tunnel_to_philip が存在するノードのみ。中身=秘密鍵パス）
    if [ -f ~/.tunnel_to_philip ] && ! pgrep -f 'ssh.*-L 22001:127.0.0.1:22000' >/dev/null; then
      nohup ssh -N -L 22001:127.0.0.1:22000 -p 50072 -i "$(cat ~/.tunnel_to_philip)" \

名前も住所も目印のファイル名も、すべて `philip` に固定されている。**中心を変えるたびに
実装を書き換えるのでは、次に同じことが起きたときにまた同じ作業になる。**

**本契約は正本を「目印から中心を導出する」形に変える。** 各ノードは自分の目印で中心を
指定し、**目印を持たないノードは張らない**（＝中心自身）。

**稼働中の常駐処理には一切触らない。** `~/bin/keeper.sh` の置き換えとプロセスの再起動は
**次の契約で行う。** 本契約は `scripts/sync/keeper.sh` だけを変える。
