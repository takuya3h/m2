# 同期処理の外向きの通信を止める（中心で先行）

**task_id:** `T-2026-09-21-philip-sync-outbound-off`  **kind:** `impl`
**depends_on:** `T-2026-09-21-m2dir-local`
**実行ホスト:** `philip`（中心）  **repo:** `~/slocal2/m2`

## Goal

**同期処理が起動時に公開の中継補助（STUN）へ出ている**（dlsta の記録で実測）。

**公開の探索網と公開中継は無効にしてある。** それでも外へ出た。
**残っている設定がある。** dlsta では `natEnabled` が既定の `true` のままだった。

**本契約は中心で一台だけ試す。** 何が外向きの通信を決めているかを実装から確かめ、
**止める手順を確定させる。** 残る六台へは、確定した手順で後から広げる。

### 起票者が把握していないこと

**どの設定が何の通信を起こすかを、起票者は実装から確かめていない。**
`natEnabled` を落とせば STUN も止まる、とは**断定できない。** 別の設定かもしれない。

**Phase A で確かめてから変える。** 推測で変えない。

### 前提（前契約で確定）

| 事実 | 値 |
|---|---|
| **稼働中の設定変更** | **直接編集は効かない。処理が書き戻す。画面の経路を使う** |
| 版 | `v2.1.3` |
| 中心の接続 | 六ノードと接続中 |
| 無効化済み | 公開の探索網、公開中継 |
| 局所の告知 | 有効（旧構成と同じ） |

## 想定外が起きたときの扱い

| 事象 | 対応 |
|---|---|
| **再起動しないと反映しない** | **停止して判断を仰ぐ** |
| **六ノードとの接続が切れた** | **報告する。自分で戻そうとしない** |
| 中心の記録に外向きの痕跡が無い | **記録する。** 止まったことは示せない。dlsta との差として報告 |

| 変えても外向きが止まらない | **記録して報告。** 別の設定がある |
| 実行基盤が操作を拒んだ | **迂回しない。利用者へ提示して許諾を得る** |
