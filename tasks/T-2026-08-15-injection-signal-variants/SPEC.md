## Goal

**当たっている把持の信号を工程分類へ渡すと、精度が下がる。**理由が分かっていない。

原因を切り分けるため、**渡す信号の形を四通り足す。**本契約は実装までであり、
効果は測らない。測るのは次の実験の契約である。

### 疑っている四つのこと

**いずれも起票者の推測である。実測で確かめるのは次の実験である。**

| # | 疑い | 対応する形 |
|---|---|---|
| 1 | **学習の間に信号が動く。**把持を推論する部分は同時に学習されるため、工程側は世代ごとに違う入力を見る | **段階を分ける形** |
| 2 | **尺度が寄っている。**両手は最大 0.414、左手は最小 0.746。次元ごとに範囲がばらばら | **揃える形** と **押しつぶす前の値を渡す形** |
| 3 | 近道になっている。五次元は滑らかで低次元。二千四十八次元より先に使われる | 上の形で間接的に見る |
| 4 | **そもそも新しい情報が無い。**渡す五次元は工程側が既に持つ特徴の関数である | **正解を渡す形** |

**4 が最も重い。**正解を渡しても悪化するなら、**注入という機構そのものが有害**であり、
渡し方をいくら直しても改善しない。**設計を捨てる判断になる。**

### 足す四つの形

| 名 | 渡すもの | 何を切り分けるか |
|---|---|---|
| **正解** | 教師そのもの | **機構自体の可否。上限を測る** |
| **押しつぶす前** | 押しつぶす前の値 | 尺度の寄りと飽和 |
| **揃えた値** | 次元ごとに中心と広がりを揃えた値 | 尺度の寄り |
| **段階を分ける** | 推論する部分を先に学習して固定してから工程を学習 | 学習中に信号が動くこと |

**正解を渡す形について、必ず守ること。**

これは**上限を測るためだけのもの**である。測る側の教師を推論に使うため、
**実際に使える手法ではない。**

| # | 守ること |
|---|---|
| 1 | 設定にも記録にも、**上限測定用であることが分かる名を付ける** |
| 2 | **成果として報告してはならない**旨を、実装の説明文と設定の両方に書く |
| 3 | 教師の無いフレームで何を渡すかを決め、**記録する** |

**3 に注意する。**教師の無いフレームは全体の 2.98%（460 枚）である。そこへ零を渡すと、
**「教師が無い」ことが信号として漏れる。**漏れる量は小さいが、**記録しないと後で読めない。**
渡し方は実行者が決めてよいが、**選んだ方法と理由を必ず書くこと。**

## 想定外が起きたときの扱い

| 事象 | 扱い |
|---|---|
| 未知の値が黙って既定になる | **直す。**次の実験で腕を間違えても気づけない |
| 四つの形のいずれかが足せない | `escalate_if` に該当。**何が邪魔をしているかを記録して停止する** |
| 腕によって重みの総数が揃わない | **G3 は `stop`。**揃う作りに直せないなら記録して停止する |
| 信号が届かない形がある | **G2 は `stop`** |
| 段階を分ける形で信号が学習中に動く | 固定できていない。**直す** |
| 揃えた値を測る側から求めてしまった | 漏れる。**学習側から求め直す** |
| 計算装置が空いていない | **Phase D を `UNKNOWN` とし、Phase E へ進む。**待たない |
| 試走が途中で落ちる | 原因を記録する。**本契約の範囲を超えるならそこまでを記録して停止する** |
| 既存の検査の失敗が増えた | 原因を特定する。**特定できなければ停止して報告する** |
| 実装が SPEC の記述と食い違う | **実装に従う。**SPEC のどこが誤っていたかを書く |
| 常駐処理が作業分岐へ統合を行った | **実行者の逸脱ではない。事実として記録する** |
