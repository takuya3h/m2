## 2. 判定規則（実行の前に固定する。結果を見てから変えない）

### 統計量

ある量 x について、当該ホストの値と参照の値を比べる。

| 記号 | 定義 |
|---|---|
| d_host | 当該ホストで参照と同じ種を使った値と、参照の記録の値との差の絶対値 |
| d_seed | 当該ホストで種だけを変えた二つの値の差の絶対値 |
| d_rerun | 当該ホストで同じ種を二回回した値の差の絶対値（非決定性の下限） |
| r | d_host を d_seed で割った値 |

短い学習では x を**損失の軌跡**とする。**記録と当該ホストの両方に在る step だけ**を使い、
各 step の差の絶対値の平均を d とする。記録の間隔が当該ホストと違う場合は、共通する step だけを使う。

評価では x を主指標とし、d_seed の代わりに**参照の契約の記録にある、同じ構成の seed 間 pstd** を使う。

### 区分

| 区分 | 条件 | 割り当ての帰結 |
|---|---|---|
| **無視できる** | r が 0.5 以下 | ホストを跨いで折りや seed を分散してよい。枚数と実効 batch は揃える |
| **要注意** | r が 0.5 を超え 1 以下 | 対になる腕は同じホストに置く。折り単位でホストを割り当てる |
| **不公平** | r が 1 を超える | 同じ比較群は同じホストで回す（§8.0 条件 (1) のまま） |
| **判定不能** | d_seed が 0、または記録が無い | 区分を付けない。理由を書く |

**d_host と d_rerun が同程度なら、ホスト差は非決定性と区別できない。** その場合は区分に加えてそう書く。

**検出塔と工程塔は別々に判定する。** 片方の結果をもう片方へ流用しない。

## 4. 想定外が起きたときの扱い

| 事象 | 対応 |
|---|---|
| 参照の checkpoint が当該ホストに無い | **停止して諮る。** 取り寄せない。Task A の結果だけを報告してよい |
| 参照の run に一歩ごとの損失の記録が無い | **停止して諮る。** Task B と D は進めてよい |
| 記録から処方を一意に復元できない | **停止して諮る。** 候補を並べて書く |
| 処方が 24 GB に収まらない | **それを結果として記録し、その系の Task C を飛ばす。** 処方を変えない |
| 学習スクリプトが出力先を `experiments/` に固定している | **停止して報告する** |
| 評価や学習で非数・発散が出る | その系を止めて記録する。他の系は続ける |
| d_seed が 0 | 区分を「判定不能」とし、理由を書く |
| 禁止 4 と実行者の手順書の第 6 節が衝突する | **契約を優先し、投影を回さない。** 衝突を報告へ書く |
| 実行基盤が読み取りや書き込みを拒む | **回避せず、利用者へ提示して許諾を得てから続ける** |
