## 3. 定義

### 3.1 C3 の直し（利用者の決定 1）

- 被覆: 手注釈（raw 02_hand）が 1 件以上実在する動画（区間）の集合が 25 件で、03_3 を含まないこと。比べる両辺は同じ型（区間の名前）にする
- 件数: 手のインスタンスの集合件数（完全重複を一つに数える）が 57,172。重複の 1 件を記録する
- 欠陥 (1)・(3) を直す（入力が無ければ失敗にする。C1 は全件を見る）。結果は本契約の出力先に書き、`experiments/audit/l0_hts_acceptance/` の既存のファイルを上書きしない

### 3.2 G

- 構造と初期化: mmdet の Mask2Former、R50、COCO の instance の重み（一本目と同じファイル、sha256 を照合）。頭のクラス数を 38 にする
- 学ぶフレーム: 三種の注釈がそろうフレーム。確定の G は折り A の train 全体、H1・H2 はそれぞれの半分の動画。val は折り A の val
- 入力と処方は実装を読んで決めてよい（一本目の計測の形〔短辺 800、batch 2〕を基準にする）。3 本で同じにする
- 収束規則: epoch ごとに val の 38 クラスの mask mAP を測り、4 epoch 停滞で学習率 × 0.1、再び停滞で打ち切り、上限 36。最良の epoch の重みを使う。把持関係 5 クラスの mask mAP も epoch ごとに記録する
- 停滞の判定（何をもって改善とするか）は塔の実装の判定と同じにし、記録する

### 3.3 G の信号と教師の標的

- G の出力から、クラスごとの画素の確率 P_c(x) = そのクラスのインスタンスの（スコア × マスクの確率）の最大 を作る
- 案 A の g（14 次元）と案 B の m（5 チャネル）: 一本目の関数（`grasp_signals.py`）に P_c を当てる（一本目の SPEC §3 の確率の式）。旗は全フレームで 1
- 案 D の q(b): 一本目の SPEC §3.3 の式に P_c を当てる。train の正解の枠ごと
- 案 C の t(f)（48 次元）: 手 h（左手・右手・両手）ごとに 16 値。なし = 1 − （g の h の把持の値。両手は両手の存在の値）。残りの質量を、
  P_h,器具 と術具のインスタンス i の重なり Σ_x P_h,器具(x) × スコア_i × マスク_i(x) の比で 14 種とその他に分ける（14 種は §2 の 14 クラス、ほかの術具のクラスはその他）。
  重なりが 0 で把持の値が正のときは、その質量をその他に置く
- 交差適合: train のフレームの信号と標的は、そのフレームの動画を学んでいない半分の G（H1 の G は H2 の動画に、H2 の G は H1 の動画に）から作る。val は確定の G から作る
- 入れ替え: 案 A の g・案 B の m・案 C の t はフレームの間で並べ替える（§2 の作り方。split ごと）。案 D の q は三本目が作る（同じフレームの枠の間）
- 作るフレーム: 案 A・C は工程の経路のフレーム（一本目と同じマニフェスト）、案 B・D は術具注釈のあるフレーム。train と val

### 3.4 案 A・B の残りの四腕

| 腕 | 案 A の x（30 次元） | 案 B の地図 |
|---|---|---|
| 予測-noCF | 予測の半分 = 確定の G の g（train も val も）と旗 1 | 確定の G の m（5） |
| 予測-CF | 予測の半分 = 交差適合の g（train）・確定の G の g（val）と旗 1 | 交差適合の m（train）・確定の G の m（val） |
| 正解予測-CF | 両方の半分（予測は予測-CF と同じ出所） | 正解の m と予測-CF の m の連結（10 チャネル） |
| 入れ替え | 予測の半分 = 並べ替えた予測-noCF の g と旗 1 | 並べ替えた予測-noCF の m |

- 受け取り手・界面・学習範囲・処方・長さ・seed は一本目と同じ。案 B の正解予測-CF だけ入力が 5 チャネル多い（前回の予備測定と同じ扱い）
- 案 A は 6 本すべてを回す（1 本 1 秒前後）。案 B は、一本目の空と正解の腕と同じコードで回すことを `code_sha256.txt` で示す。
  コードを変えたときは、案 B の空と正解の腕も回し直す

### 3.5 案 C の 3 腕

| 腕 | fine-tune の損失 |
|---|---|
| 補助損失なし | 工程の交差エントロピーだけ（頭は置き、重み 0） |
| G を教師 | 工程の交差エントロピー ＋ 0.3 × 補助損失（t を標的） |
| 入れ替えた教師 | 同じ形で、標的は並べ替えた t |

- 補助の頭: fine-tune の段の GAP の特徴（2048）から 48 の線形。手ごとの 16 値に softmax を掛け、t との交差エントロピーを 3 つの手で平均する
- **3 腕は同じコードで回す**（補助損失なしの腕は重み 0）。処方は §2 の工程塔の処方のまま、21 epoch 回し、記録と同じ epoch で学習率を下げ（実装と記録を読んで同じ位置にする）、最後の状態を使う
- 特徴の取り出しと時間ヘッドもやり直す（時間ヘッドは記録と同じ処方で 18 epoch、最後の状態）。val の macro Jaccard と frame accuracy を、塔単独の評価と同じ経路で測る
- 推論の構造は今の工程塔と同じ（補助の頭は使わない）

## 6. 事前登録（測る前に固定する）

### 6.1 量

- 案 A・B: Δ空、Δ入替（入れ替えの腕との差）、Δ塔、正解の腕との差（予測-noCF − 正解）。指標は一本目と同じ
- 案 C: Δ教師 = G を教師 − 補助損失なし、Δ入替 = 入れ替えた教師 − 補助損失なし、G を教師 − 入れ替えた教師。指標は macro Jaccard（主）、frame accuracy（併記）、クラス別 Jaccard
- G: 選んだ epoch の val の 38 クラスと 5 クラスの mask mAP、正解との比べ（Task D-2）

### 6.2 読み方の規則（記述だけ）

1. seed は一つ。差は 1 本ずつの差として書く。陽性・陰性・有意などの語は使わない
2. 予測-noCF の Δ入替 を「その時刻の G の信号の中身による差」として読み、正解の腕の値と並べる
3. 案 C は、G を教師 − 補助損失なし と、G を教師 − 入れ替えた教師 の両方を書く。符号が食い違えば両方を書き、一つにまとめない
4. 案 B は overall mAP と標的群 AP と陰性対照群 AP を並べる。陰性対照群 AP が動いたときは書く
5. 動画ごとの差の符号が分かれるときは書く
6. 結果は関門の判定と設計の判断に使わない（§0）

### 6.3 予測（記述のための事前の記録。外れても判定は変わらない）

1. 案 B の予測-noCF の Δ空（標的群 AP）は正で、正解の腕の Δ空（+0.0153）より小さい
2. 案 A の予測-noCF の Δ空（Jaccard）の絶対値は 0.005 未満
3. 案 C の G を教師 − 補助損失なし（Jaccard）の絶対値は 0.01 未満
4. G の val の把持関係 5 クラスの mask mAP は 38 クラスの mask mAP より高い

### 6.4 既知の限界（報告に必ず書く）

- 折りは 1 つ、val は 2 動画、seed は 1 つ。工程は動画 09 が塔単独で上限に近い
- 腕の学習は固定の 4 epoch。一本目の案 B の正解の腕は 4 epoch 目でもまだ上がっていた
- G は三種がそろうフレームだけで学び、交差適合の半分は確定の G より少ないフレームで学ぶ（train と val の信号の質が違いうる）
- 案 C の補助損失なしの腕は記録の工程塔と同じ処方だが、ホスト（記録は efros）と止め方（記録は最良の回、本契約は最後の状態）が違うので、塔単独の値とは直に比べない
