## Goal

**この設計を続けるか捨てるかを決める。**

前の実験は揺らぎに阻まれて判定できなかった。**測定が厳密になり、種を二十倍にできる
ようになった今、決着をつける。**

    主たる差 = 正解を渡した腕 − 無情報な信号を渡した腕

| 結果 | 判断 |
|---|---|
| 上回らない | **機構そのものに価値が無い。設計を捨てる** |
| 上回る | 機構は健全。**渡し方のどこが悪いかを形の違いから絞り込む** |

### 腕と種

**六つの腕を、同じ六十個の種で走らせる。合わせて三百六十本。**

| # | 腕 | 位置づけ |
|---|---|---|
| 1 | 無情報な信号 | **対照。全ての差の引き算の相手** |
| 2 | **正解を渡す** | **主たる腕。上限を測る** |
| 3 | 推論した値 | 実際に使える形 |
| 4 | 押しつぶす前の値 | 尺度の寄りと飽和 |
| 5 | 揃えた値 | 尺度の寄り |
| 6 | 段階を分ける | 学習の間に信号が動くこと |

**六十にした理由。** 前の契約の実測で、測定を厳密にしても対の差の揺らぎは
**0.0054519 が残った。**これは雑音ではなく**種による効果の不均一**である。
雑音でない以上、**種を増やす以外に平均の精度は上がらない。**

一本およそ十五秒である。**三百六十本でおよそ九十分。**

### 判定の基準を変えている

**既存の実験は「比が一以上、かつ全ての種で符号が揃う」を使ってきた。**
**本契約は後半を外し、平均の標準誤差で判定する。**

**種が六十では、全種同符号は原理的に成立しない。**効果が真に一様でないため、
負になる種が八件前後は出ると見込まれる。**要件に残すと、種を増やすほど判定が
通らなくなる。**

**理由と、既存の判定との比較可能性が失われることを、報告に明記すること。**
詳細は `prereg.md` にある。

### ここまでに確定していること（再測定は不要）

| 事実 | 実測値 |
|---|---|
| 測定を厳密にすると | 同じ種なら**重みまでビット単位で一致する** |
| 非決定の源 | 畳み込みの実装の選び方。それだけで五十世代が一致 |
| 遅くなる分 | 2.15 倍。一本 6.8 秒が 14.7 秒 |
| 厳密にした後の対の差の揺らぎ | **0.0054519。**これは雑音ではなく真の不均一 |
| 走らせる順序 | **厳密にすれば順序は効かない。**ビット単位で同一になる |
| 前の実験の隣接実行 | 揺らぎ 0.00736。一括の 0.0100 と同水準。**順序の効果は無かった** |
| 六つの腕の重みの総数 | 528919 で一致 |
| 分母 | 17 run、accuracy 0.8973015、pstd 0.0059171 |

### 前の契約で判明した、設定の記述への注意

**設定に書いてあっても実装が読まない項目がある。**四十項目のうち十四が読まれない。

| 項目 | 実態 |
|---|---|
| 凍結源を指す四項目 | **読まれない。**実効はキャッシュの経路が決める |
| 評価の規約を指す三項目 | **読まれない。**実効は定数が決める |
| 信号の形を指す項目 | **入口によって読まれたり読まれなかったりする** |
| 勾配の切り離しを指す項目 | **実装に一度も現れない。**常に切り離される |

**したがって次を守ること。**

| # | 守ること |
|---|---|
| 1 | **凍結源の照合は、設定の記述ではなくキャッシュの経路で行う** |
| 2 | **評価の規約の照合は、設定の記述ではなく証跡で行う** |
| 3 | **入口を形が読まれる方に固定する** |
| 4 | **測定を厳密にする設定が実際に読まれていることを、実挙動で確かめる** |

**4 を落とさない。**読まれていなければ、厳密にしたつもりで測ることになる。

## 想定外が起きたときの扱い

| 事象 | 扱い |
|---|---|
| 厳密にする設定が読まれていない | **G1 は `stop`。**`escalate_if` に該当。厳密にしたつもりで測ることになる |

| 凍結源が分母と違うものを指す | **記録して停止する。**設定の記述ではなくキャッシュの経路で見ること |
| 計算装置が空いていない | `escalate_if` に該当。**待たずに停止する** |
| 一本が著しく長い | 走らせた本数を記録して止める。**無理に続けない** |
| 学習が落ちる | **本契約では直さない**（禁止 5）。何が落ちたかを記録して止める |
| 抜き取り検査で一致しない | 途中で厳密さが崩れている。**記録して止める** |
| 母集団が 14977 になる | 実装が壊れている。**記録して止める** |
| 評価条件が分母と一致しない | **G2 は `stop`** |

| 差が惜しいところで届かない | **腕も種も増やさない**（事前登録の止め方）。次の契約へ回す |
