# 起票の参照先を版管理へ置く

**task_id:** `T-2026-08-25-issuer-refs-to-repo`  **kind:** `impl`
**depends_on:** なし
**実行ホスト:** いずれか一台（**中心が望ましい**）

## Goal

**起票者の手順書が肥大している。** 毎回の読み込みで六百七十一行を消費し、
そのうち約半分は**契約へ毎回転記する内容**である。

**版管理へ置けば、手順書からも契約本文からも消せる。**

| 移すもの | 置き場所 | 効果 |
|---|---|---|
| 環境の実測 | `context/env-facts.md` | 起票時に必要な行だけ引く |
| 起票者の欠陥の実測例 | `docs/issuer-defects.md` | 同じ型を繰り返さないため |
| 実行者への申し送り | **`context/conventions.md` の新しい節** | **`inject_verbatim` で注入する** |

**三つ目が本命である。** 注入できれば、**契約ごとに十三項目を書き写す必要がなくなり、
実行者は常に最新版を読む。** いまは起票者が転記するため、古い値を書けば古いまま伝わる。

**効果の実測**: 手順書が六百七十一行 → 三百四十一行になる見込み。

### 起票者は内容を用意した

**バンドルには五つのファイルが入っている。**

| ファイル | 置き場所 |
|---|---|
| `spec.yaml` `SPEC.md` | 契約のディレクトリ（取り込みが置く） |
| `env-facts.md` | **`context/env-facts.md` へ置く** |
| `issuer-defects.md` | **`docs/issuer-defects.md` へ置く** |
| `issuer-cautions.md` | **`context/conventions.md` の末尾へ追記する**（ファイルとして置かない） |

**実行者は内容を作らない。配置する。**

**ただし文面の誤りは指摘してよい。** 特に次を確かめる。

- **実測と食い違う記述**（版管理の記録と突き合わせる）
- **既存の節との重複**（`conventions.md` に似た記述が既にあるか）
- **注入の仕組みが要求する書式**（見出しの形、識別子の付け方）

## 想定外が起きたときの扱い

| 事象 | 対応 |
|---|---|
| **既存の節が変わった** | **停止して報告。** 追加だけを行う契約である |
| **注入の書式を読めない** | `UNKNOWN` とし、**既存の節と同じ形を真似る。** 推測で新しい形を作らない |
| **新しい参照が解決しない** | **記録して報告。** 書式が違う。**推測で直さない** |
| 陰性対照を取れない | `UNKNOWN` とする。**「解決した」だけでは検査になっていない** |
| 置き場所が既に存在する | **停止して報告。** 上書きしない |
| 配られた本文が実測と食い違う | **実測を正として直し、直した箇所を記録する** |
| `forbidden-check` が違反を報告した | **記録して続行。** 追加のみである根拠を書く |
| 未追跡が減った | **停止して報告** |

**言い訳をしない。事実と、測れなかったことを書く。**
