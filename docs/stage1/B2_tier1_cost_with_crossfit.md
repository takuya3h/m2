## 2. TF32 の反映の有無

**反映していない。** `det_iface_w1` は単精度の実測 4.00 h（`tasks/T-2026-08-29-lecun-detector-env-pd/RESULT.md:88`）のままである。
TF32 の実測は折り A の W1 一本で 3.7406 h（`docs/stage0/C2_amp_compile_timing.md` §4、run 内 1.171 倍）だが、
採用は利用者が決めることとされ（C2 §7）、採用の記録は repo に無い。採用すれば Tier 1 の検出側の行（GPU 時間の大半）が
約 1/1.17〜1/1.18 になる。**本文の日数は単精度の値である。**
