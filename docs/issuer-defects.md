# 起票者の欠陥の実測例

**同じ型を繰り返さないための記録。** 起票時に該当箇所を確かめる。

## 型

- **`asserted_without_measuring`** — 実測せずに事実・値・挙動を断定した
- **`self_contradiction`** — 同一契約内の禁止と要求が両立しない
- **`check_does_not_check`** — 検査が意図した性質を実際には測っていない
- **`shell_assumption`** — シェルや実行方式の前提を誤った

**すべての根は同じ。実態を測らずに書いた。**

---

## 書いたコマンドが検査になっていなかった

    grep -A1 の向きが逆                    目的の値は一致行の前にあった
    echo "count=$?"                        終了コードを件数と呼んだ
    ${PIPESTATUS[0]}                       zsh では取れない
    grep -i tunnel                         .tunnel.log まで数えた
    find -name "syncthing*.log"            先頭がドットのものを落とした
    grep -o 'apikey>...' | cut -c1-12      秘匿を守る検査が値を出力した
    python(exact_arg)                      この環境の実行は .venv/bin/python。常に 0
    ${(P)var}                              bash が解釈できず照合が黙って飛んだ
    /proc/*/cmdline の部分一致             実行基盤の包み込みを拾い、否定対照が 1 を返した

**「実装を読んで決めてよい」と委ねた部分では、実行者はほぼ誤らない。**

## 禁止と要求が両立しなかった

- runindex を手で編集しない ↔ runindex 配下へ未解決事項を書かせる
- 統合しない ↔ **push を統合と読まれた**
- 中心で命令を実行しない ↔ **到達確認に `ssh ... 'echo'` を書いた**（`ssh -N` なら到達だけ確かめられる）
- 認証情報への接触が拒まれる ↔ **版管理内への控えを必須にした**
- 禁止領域は無変更 ↔ 同領域の件数増加を成功条件にする
- **`outputs.must_have` が RESULT.md のみ** ↔ 本文が result.yaml と受け皿の作成も求める

## 測らずに断定した

- 設定の場所を「既定ではない」と書いた（**既定だった**）
- 中心の住所を断定した（**局所から見える値と食い違った**）
- 登録名の初期値を「大文字始まり」と断定（**実測は `Bengio` / `Andrew` / `aolab`**）
- repo の大きさを定数で書いた（**54.7 GB / 47.5 GB とホストごとに違う**）
- 待ち時間の上限を過去の実測の最大値で書いた（**実装は `sleep 1800`。実測が上限を超えた**）
- 受け入れ一覧の権限を `600` と書いた（**実測は `664`**）
- `.env` の旧版を確かめず 2 変数と決めつけた（**5 変数あり、3 つを失わせた**）
- 「`~/.ssh/**` は拒まれる」と書いた（**拒まれないホストもあった**）

## 検査が空振りした

- **`default` を名前で指定**した（実体は `id=""` で一致せず残った）。集合か階層で指定する
- 秘匿検査が `BEGIN...PRIVATE` のみで、**設定に実値で入っていた画面の鍵を見逃した**
- 陽性対照が片方向のみ（**「常に 0 を返す壊れ方」と区別できない**）
- **必須項目を空で置いた**（「実行者が実測して置換する」は空にする意味ではない）

## 訂正が行き渡らなかった

**「確定した事実」の表だけ直して Task 本文を見落とし、同じ指摘を二度受けた**（待ち時間、大きさ）。
**訂正したら、その語で検索して残存が 0 であることを確かめる。**

## 報告を検証せずに認めた

**実行者が「道具が存在しない」と 3 件報告し、確かめると 3 件とも実在した**（古い版管理の状態で見ていた）。
**起票者はそれを検証せず「私の欠陥」と認めた。**

**認める前に、その報告が何を見た結果かを確かめる。**

## 置換前提の値を貼れる形で書いた

`<repo>` `<host>` `YOUR_PASSPHRASE` をそのまま貼られ、**別ホストのブランチで作業した**、**例示の合言葉が本番に設定された**。

**ホストごとに違う値は表で示すか、実値を埋めた完成形を渡す。**

## 完了判定の型ごとの確認方法

- **違反検出** — 違反を含む対照では検出し、含まない対照では検出しない
- **一覧の完全性** — 異質な方法で対象集合を作り突き合わせる
- **不変性** — 変更前の値を先に測定し比較する（**要約値で。表示属性では足りない**）
- **件数一致** — 比較元と比較先を明示する
- **プロセス計数** — 実在対象で 1 以上、存在しない対象で 0。**`/proc/PID/exe` で絞る**
- **秘匿検査** — 秘匿を含む隔離データでは検出し、安全なデータでは 0。**検査自身が値を出力しない**
