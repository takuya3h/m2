# 外科手術フェーズ認識モデル選定のための Evidence Map

## 読み方と対象範囲

本マップは、**open surgery・egocentric head-mounted video・学習動画およそ15–21本・推論時は strictly online/causal**という設定で、事前登録した tournament に投入する候補 architecture / training recipe を列挙するためのものとして整理した。論文間の優劣は判定せず、**設定・学習規模・因果性・入力条件・論文中の数値**を記録する。

比較時に混同しない方がよい指標定義がある。EgoSurgery-Phase 論文の `Jaccard` は phase ごとに計算して macro-average した値である一方、一般の temporal action segmentation における `F1@10/25/50` は segmental overlap F1 であり、phase-level F1 と同一ではない。Cholec80 系では transition 周辺を許容する `relaxed` と許容しない `unrelaxed` 評価が混在するため、以下では論文の名称をそのまま残した。citeturn3view0turn25view0turn23view0

また、**「online」には論文が明示的に current/past のみを使うものだけを入れた**。固定長 clip を入力しているだけで clip 内の future frame 排除が明記されない手法は、`causality not stated` とした。Trans-SVNet は過去 `g_{t-n+1:t}` のみ、LoViT は current frame と previous frames、TeCNO は causal temporal convolution を明記している。citeturn25view0turn26view2turn13view0

ラベル付き動画本数と自己教師あり pretraining の動画本数も別物である。たとえば Cholec80 の低ラベル SSL 実験では 5/10/40 本だけを downstream label として使いながら、unlabeled surgical video を representation learning に使う設定がある。したがって「15–21 videos」の制約が**ラベル付き動画だけを意味するのか、pretraining を含む全データを意味するのか**は tournament の preregistration で固定する必要がある。citeturn30view6turn30view9

以下には要求された null/negative ablation を複数含めた。具体的には、EgoSurgery 上の SurgMAE initialization、TeCNO の追加 refinement stage、Trans-SVNet の単純 feature concatenation、surgical SSL の ImageNet 上での追加 SSL、SurgPETL の pretraining-data scale、MS-TCN の feature forwarding、ASFormer の positional encoding などで、追加要素が改善しないか数値が低下したケースが報告されている。citeturn4view0turn15view0turn25view0turn30view6turn22view1turn28view1turn28view5

著者名については推測を避けた。識別子・本文・表を確認できたものの、今回保持された一次資料の抽出で author header を再確認できなかった少数の論文は、著者欄を「再確認不能」と明記している。数値についても同様に、表を読めなかったものは要求どおり `number not available` とした。

## 未検証の組合せ

以下は「効果がある」という主張ではなく、**上記の一次資料を横断したときに、同時に評価された記録を確認できなかった組合せ**である。理由は論文の実験設計からの推論であり、結果の予測ではない。

- **GGMAE / VideoMAE-style in-domain pretraining + causal TeCNO/LoViT head on EgoSurgery-Phase。** EgoSurgery 14-train-video benchmarkでは masked pretraining と複数 temporal baseline が別々に評価されているが、GGMAE ViT features を strictly past-only TCN/Transformer に入力する組合せは報告されていない。固定10-frame clip pretraining と長時間 streaming model を分離して学習する追加実装が必要になることが、未検証の一因として考えられる。citeturn3view0turn4view0turn25view0

- **Surgical masked-video pretraining + frozen/partially frozen backbone + causal head。** SurgMAE は最終 temporal model が Bi-GRU で offline、SurgPETL は frozen backbone/adapters を試すが strict causality は明示されない。したがって「surgical MAE encoder を freeze/PETL し、past-only TCN だけ学習する」条件は今回の検索では直接測定されていない。技術的には pretraining と streaming downstream を別段階にする必要がある。citeturn8view0turn21view4turn23view0

- **EgoVLP/EgoClip initialization + open-surgery phase recognition。** EgoVLP は head-mounted first-person domain に対して4-frame video-language pretrainingを行うが、確認した downstream は Ego4D/EPIC/Charades-Ego で、open-surgery phase labels は含まれない。未検証なのは surgical data と natural first-person narration data の双方を扱う研究が別コミュニティに分かれていることによる可能性がある。citeturn30view11turn30view13

- **EgoSurgery-Tool auxiliary supervision + EgoSurgery-Phase + causal inference。** EndoNet は Cholec80 で tool+phase joint training を行う一方、EgoSurgery-Phase の比較表は phase models と masked pretraining を中心にしている。今回の検索では EgoSurgery family の tool annotations を causal phase head の auxiliary target とする同一実験を確認できず、annotation alignment と multi-task sampling の追加実装が必要になることが一因として考えられる。citeturn30view2turn4view0

- **ASFormer-style local/hierarchical attentionを causal mask 化した surgical phase model。** ASFormer の small-data inductive bias は full-sequence action segmentation で評価され、Trans-SVNet/LoViT は surgical causal attention を評価するが、ASFormer decoder の hierarchical refinement を future-free にした実験は今回の検索では確認できない。Decoder refinement が全時系列 prediction を参照する構造を past-only に変更する必要があるため、architecture-level の変更になる。citeturn28view6turn25view0turn26view3

- **MS-TCN の truncated-MSE smoothing loss + EgoSurgery causal TCN。** 一般動画の MS-TCN は CE + truncated MSE を明示的に使い、TeCNO は causal multi-stage TCN を surgical phase recognition に移植しているが、EgoSurgery の14本設定でこの smoothing-loss choice 自体を ablate した値は報告されていない。モデル変更より loss-level の組合せであるため、未検証は技術的困難より実験選択による可能性がある。citeturn27view0turn13view0turn4view0

- **Gazeを pretraining 時だけ使い、inference は RGB-only の causal long-history model。** GGMAE は gaze-guided maskingを representation learning に使うが、その downstream clip classifier は strict causal と確認できない。Gazeを privileged training signal のみに限定し、その encoder を causal TeCNO/LoViT に接続した open-surgery result は今回の検索では確認できない。citeturn3view0turn4view1

- **Natural-image/video-language PETL + causal open-surgery streaming。** SurgPETL は WIT-400M/LAION/SURGERY-23M pretrained ViTsをほぼ frozen のまま10-video AutoLaparo に適応するが、入力 frame volume の strictly past-only 制約は明示されない。固定 clip adapter を streaming cache に置き換える必要があることが技術的理由として考えられる。citeturn23view0turn22view1

これらの中で「追加要素が常に効く」という前提は置けない。既存 ablation では、SurgMAE initialization が EgoSurgery scratch と近い値、SurgMAE in-domain pretraining が Cataract-101 で Kinetics initialization を下回る例、ImageNet 上に通常どおり SSL を重ねると surgical phase `F1` が最大1.9 point低下する例、Transformer positional encoding が ASFormer の F1/Edit を下げる例がすでに報告されている。citeturn4view0turn10view2turn30view6turn28view5

## 設定類似度による最接近論文

ここでは**結果値ではなく、domain/viewpoint、ラベル付き動画本数、online causality の順に設定の一致度を見て順位付け**した。

1. **Gaze-Guided Masked Autoencoder / EgoSurgery-Phase** — open surgery、head-mounted egocentric、**14 training videos**という三点が対象設定と直接一致する。相違点は、提案法の10-frame clip が strict past-only と明記されていないことである。Table 1 と Table 2 は、同一14-video setting で TCN/Transformer/MAE variants を比較する際の直接的な数値表になる。citeturn3view0turn4view0

2. **LoViT** — surgical phase recognition かつ **online/causal**で、AutoLaparo の **10 training videos**という小規模 split を含む。相違点は laparoscopic third-person/endoscope view であり、open/head-mounted ではない。Past-only transformer の長短 temporal context の実装条件を持つ。citeturn23view0turn26view2turn26view3

3. **TeCNO** — surgical phase recognition かつ明示的 **causal TCN**。Cholec80 は40 training videos で対象より大きいが、追加 refinement stage が低下した ablation があり、multi-stage temporal depth を小データで増やす場合の直接的な記録がある。citeturn14view0turn15view0

4. **Trans-SVNet** — surgical phase recognition、明示的 **future-free TCN + past-only 30-step Transformer**。Cholec80 40本/M2CAI16 27本で対象より多い。Table 3 は Transformer を置くだけではなく、query/key の構成によって `Jaccard 60.8–79.3` まで値が変わる同一-paper ablation を含む。citeturn25view0

5. **SurgPETL** — AutoLaparo **10 training videos**、ViT backbone を大部分 frozen にした parameter-efficient adaptation という点で小ラベル条件に近い。相違点は laparoscopic view と、strict causal inference が明示されていない点である。16×4 clip、30 epochs、frozen pretrained ViT + adapters という学習設定が明示されている。citeturn23view0turn22view2

この設定類似度から読み取れる未解決点は、**「open + egocentric + 14–21 labeled videos」についての直接データは EgoSurgery-Phase が提供する一方、「strict causality」の直接データは主として laparoscopic TeCNO/Trans-SVNet/LoViT から得る必要があり、この二つの条件が同一提案モデルでまだ重なっていない**ことである。citeturn4view0turn13view0turn25view0turn26view3
