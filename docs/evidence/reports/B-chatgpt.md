# 凍結済み手術フェーズモデルから凍結済み器具検出器への条件付け：Evidence Map

## 調査範囲と読み方

本マップは、**凍結済み surgical phase recognition model \(P\)** と **凍結済み DETR-family tool box detector \(D\)** の間に小規模な学習可能インターフェースだけを置き、phase 情報によって box-level tool detection の mAP が変化するか、という設定に対する証拠を整理する。論文間の優劣は判定せず、各論文が実際に置いた設定と報告値を記す。

比較時に区別すべき点がある。Cholec80 系の「tool detection」は多くの場合、**bounding-box detection ではなく frame-level tool presence classification** であり、box mAP とは受信タスクの粒度が異なる。EndoNet や MTRCNet-CL の phase は動画全体に一つだけ付くラベルではなく、各フレームに付与される手術進行状態だが、意味論的には局所的な物体ラベルより粗い temporal/workflow context である。さらに、EndoNet 型の joint multi-task learning では phase 情報が推論時に detector に明示注入されるのではなく、**学習中の共有表現への勾配**を介して結合されるため、凍結済み \(P,D\) と小規模 interface という設定とは分けて読む必要がある。 citeturn3view0turn5view0

また、以下の mAP/AP は定義が同じではない。tool-presence AP、bounding-box mAP@IoU、referring-segmentation IoU、CLEVR accuracy などを横断しており、**差分の符号と各研究内の ablation**を記録するもので、数値の絶対値を研究間で比較するものではない。

今回の検索で、**ground-truth surgical phase を oracle として box detector に与えた結果と predicted phase を与えた結果を同じ表で比較した論文は見つからなかった**。EndoNet には逆方向、すなわち ground-truth tool-presence binary vector を phase recognition に与える oracle があり、phase accuracy は EndoNet 75.2% に対して EndoNet+GTbin 75.3% だったが、これは tool→phase であって phase→tool ではない。 citeturn4view0

### 検索語と見つからなかったもの

検索語は、`FiLM conditional dense prediction feature-wise modulation`、`FiLM frozen backbone segmentation`、`cross attention conditioning dense prediction`、`conditional DETR external context query conditioning`、`MDETR text conditioned DETR`、`class prior conditioned object detection`、`task affinity dense tasks negative transfer`、`Which Tasks Should Be Learned Together semantic segmentation`、`Taskonomy transfer affinity`、`gradient conflict multi task dense prediction` を使用した。

`Conditional DETR` も検索対象にしたが、その “conditional” は外部の coarse context label を detector に与える意味ではなく、decoder query の spatial/reference conditioning を改善する DETR 内部機構であるため、本表の「phase sender→detector」という証拠には採用しなかった。 citeturn11academia21

Taskonomy 自体も検索したが、本決定に必要な「coarse sender を dense receiver に追加したときの with/without coupling」の一対の実験値より、task-to-task transfer affinity 全体を扱う設定であるため、数値の方向性を直接読める Standley et al. を表に採用した。Standley et al. はさらに、Taskonomy の transfer affinity と joint multi-task affinity が一致しない例を明示的に報告している。 citeturn28view1

本検索範囲では、**pretrained/frozen DETR object queries に一個の coarse categorical context labelだけを小規模 adapter で注入し、base DETR と同一 box-detection taskで比較する論文**は確認できなかった。また、**oracle hard label vs predicted hard label vs probability vector vs sender feature vector の四段階を同一 dense detectorで比較した研究**も確認できなかった。

一般メカニズム側で追加された family は、**task grouping / negative-transfer control** である。これは \(P\to D\) の推論時 interface ではないが、「別 task の supervision が receiver に入ること自体の符号は方向・容量に依存する」という training-side mechanism を測る。Standley et al. では SemSeg↔Depth が方向によって +4.17% と −5.41% に分かれる。 citeturn28view0

### Mechanism family × sender signal level

下表では surgical phase の直接証拠に加え、**同じ信号形式に最も近い cross-domain analogue**も含める。「reported null or negative」は、そのセルに negative/null observation が少なくとも一つ存在する場合を優先して付けているため、同じセルに positive variant が存在し得る。

## 設定類似度による近接論文と残っている実験空間

### 本設定に近い順

順位は結果の大小ではなく、**surgical/egocentric、coarse-to-dense、frozen tower、小規模 trainable interface、box-level receiver** の一致数で並べている。

| 類似順位 | 論文 | 一致する設定 | 異なる設定 |
|---|---|---|---|
| **1** | **MTRCNet-CL, Jin et al.** citeturn5view0turn6view0 | Surgery；phase→tool directionを明示；phase **temporal feature vector** から小さい learned mappingで tool prior を作る；label-space vs feature-space、one-way vs mutual coupling の ablationあり。 | \(P,D\) は frozen independent towers ではなく joint training；receiver は box detection ではなく frame-level tool presence；DETRではない。 |
| **2** | **CLIPSeg, Lüddecke & Ecker** citeturn17view0turn17view1 | **Frozen pretrained encoder**；sender embeddingで dense predictionを条件付け；約 **1.12M trainable parameters** の conditional decoder；FiLMを使用。 | Surgeryではない；receiverは segmentation；image and prompt share CLIP representation；detector tower \(D\) を丸ごと frozen にして adapterのみ学習する形ではない。 |
| **3** | **Context R-CNN, Beery et al.** citeturn31view0 | Sender側の長期-context feature extractorが **frozen**；small attention moduleで **box-level detector** を context-conditioned にする；feature additionとattentionを使用；temporal-window ablationあり。 | Context は phaseではなく other-frame ROI features；static-camera domain；receiver detector全体が frozenという設定ではない；Faster R-CNN系。 |
| **4** | **EndoNet / M2CAI Tool Presence, Twinanda et al.** citeturn4view0turn1view0 | Surgery；phase/tool task pairを同じデータ上で測定；phase couplingが tool metric に対して +0.1、−3.9、+0.3 という小さい/負の値を含む。 | Explicit inference interfaceなし；towersはfrozenでない；tool presenceであって box detectionではない；phase→tool output injectionをisolated ablationしていない。 |
| **5** | **MDETR, Kamath et al.** citeturn20search2 | **DETR-family box detector** に外部 high-level signalを条件として与える；senderから dense set of boxesへの coarse-to-dense structure。 | Senderはphaseではなく text queryで、query自体が「何を探すか」を規定するため phase contextより直接的；frozen \(P,D\)+small interfaceではない；no-context paired ablationは今回読めた資料では number not available。 |

SELSA は box-level、egocentric、temporal context という点で近いが、sender が phase representation ではなく他フレームの proposal features で、detector自体を sequence-level aggregation込みで学習するため上記5件の外に置いた。EPIC-KITCHENS では single-frame Faster R-CNN から SELSA への mAP@.5 が seen **36.57→37.97**、unseen **31.86→34.80** である。 citeturn30view0

### Evidence map上で未測定の対照条件

現在の検索結果から、ユーザーの frozen-\(P\)/frozen-\(D\) 設定で未測定のセルはかなり明確に分離できる。

第一に、**sender information content の対照**、すなわち同一 detector/interface capacity の下での `predicted hard phase`、`GT hard phase oracle`、`predicted probability vector`、`phase feature vector` の四者比較は見つからなかった。MTRCNet-CL は label-space と feature-space の比較を持ち、**86.8 vs 89.1 tool mAP** と feature representation 側で異なる値を報告するが、GT oracle を含む四段階比較ではない。 citeturn6view1

第二に、**interface location の統制比較**、すなわち同一 frozen DETR で `feature add/concat`、`FiLM`、`cross-attention`、`object-query conditioning`、`class-logit prior` を同一parameter budgetで比較した研究は見つからなかった。一般文献には各部品を別々に使う実例が存在するが、LAVT が示すように同じ sender でも conditioning の位置を変えると符号が変わる条件がある。 citeturn12view2

第三に、**output prior の oracle gap** が空いている。MTRCNet-CL は learned phase representation から tool prior を作るが、ground-truth phaseから直接 \(p(\mathrm{tool}\mid\mathrm{phase})\) を作った oracle と predicted-phase prior を並べていない。さらに learned prior を tool output と平均すると **89.1→88.8 mAP** となるため、priorが存在することと、post-hoc output fusionでmetricが上がることは同義ではない。 citeturn6view2

第四に、**phase temporal history と current phase の切り分け**も空いている。MTRCNet-CL は phase sideをLSTMでtemporalにし、SELSA/Context R-CNN は別領域でtemporal window拡大による変化を測っているが、`current phase probabilities only` と `phase-probability history` の controlled comparisonを surgical box detector上で行った証拠は確認できなかった。SELSAでは sequence-level context 73.62→80.25 mAP、Context R-CNNでは SS の時間幅が one minute 50.3、one hour 52.1、one day 52.5、one week 54.1、one month 55.6 mAP と報告されているが、いずれも phase history ではなく visual-feature history である。 citeturn30view1turn31view0

最後に、**frozen towers に限定したときの negative-transfer evidence** も直接は存在しない。EndoNet や Standley et al. の負の効果は shared weights に複数 loss の gradient が入る設定であり、完全に凍結した \(P,D\) の間にだけ interface を訓練する場合には、その gradient-conflict pathway 自体が存在しない。一方、MTRCNet-CL、LAVT、SELSA、Context R-CNN の結果は、**sender情報の形式、注入位置、aggregation ruleを変えるだけでも receiver metric の差分が正・零・負に分かれる**という別の種類の evidence を提供している。 citeturn6view2turn12view2turn30view2turn31view0
