## 0. この地図の読み方

### 0.1 問い

次の設計と同じか、ほぼ同じ設計の先行研究があるか。同じ手術動画の二つの課題（術具の box 検出 D、online の工程認識 P）について、D と P を自分のラベルだけで独立に学習して凍結し、間の小さな界面だけを学習する。界面に渡すのは相手の同時刻の予測だけ。同じ研究の中で結合なし・D→P・P→D を比べ、界面の入力を空・予測・正解・正解と予測の和に切り替える。データは EgoSurgery の 15 動画、動画単位の 5 分割の交差検証。

照合の要素:

| 要素 | 内容 |
|---|---|
| E1 | 独立に学習した二つの課題のモデルを凍結し、間の小さなモジュールだけを学習する |
| E2 | 一方の同時刻の出力（予測）を他方の入力に渡す。特徴の共有・共同学習ではない |
| E3 | 同じ研究で両方向を測り、方向による違いを比べる |
| E4 | 同じ界面で、入力を空・予測・正解に切り替え、予測と正解の差を測る |
| E5 | 課題の組が術具の検出（box・分割・在否）と工程・workflow の認識（手術映像）。さらに一人称の開放手術か |
| E6 | online（過去のみ）・少数動画・動画単位の交差検証 |

## 3. 予測と正解を入力として比べた値（E4 に近いもの。報告の記載）

- **ToolSeg（P→D、本文 表 1）**: 条件付けなし（v0）IoU 40.90／DSC 50.66。予測した工程と PCD-Gated（v3）48.77／57.52。正解の工程と PCD-Gated（v6）56.13／64.76。v0 は条件付けを持たない構造で、空の入力の対照ではない。正解と予測の和に当たる入力は無い（N1 L25–L29）。地図 B の B-15 と同じ値
- **EndoNet（D→P、§IV-C、表 III–IV、Cholec80。補助調査による）**: 工程認識の精度。術具の正解の二値ベクトルだけを入力にすると HMM の前 48.2%、HMM の後 offline 69.2%、online 47.5%。EndoNet の特徴（予測した術具の確信度を含む）では 75.2%、92.0%、81.7%。特徴に正解の術具ビットを足した EndoNet-GTbin では 75.3%、92.2%、81.9%。予測した術具の二値だけを入力にする条件は無い（N1 L30）。75.2・81.7・75.3・81.9 は地図 C の C-01 と同じ値。48.2・69.2・47.5・92.0・92.2 は N1 が新しく書いた値
