## 検査が見る項目

### 見出しの前の欄（全種類）

`**版:**`、`**種類:**`、`**状態:**`、`**元の報告:**`、`**検索日:**` の五つ。

`**種類:**` の値は次のどちらか。

- `探索の地図` — 文献探索の報告を行にした地図（地図 B・C など）
- `新規性の照合` — 新規性の探索の報告を、設計の要素ごとの一致で並べた地図（地図 N）

### 種類ごとの必須の節（見出しの語で探す。番号は問わない）

| 種類 | 必須の節 |

| 探索の地図 | 系統表／行の一覧／近さ／手法の位置／証拠の質／効果／実装／本研究との関係／見つからなかったもの／未検証の組み合わせ／検索記録 |
| 新規性の照合 | 照合表／見つからない理由の証拠／見つからなかったもの／検索記録 |

    ### 0.1 問い

    ### 0.2 規則
    - 行は報告に書かれた事実だけを載せる。数値・表番号は報告のまま。報告に書かれた差は起票者が検算する
    - 報告が「不明」とした欄は不明のまま。推測で埋めない
    - 現役度は報告の値（SOTA 級／定番の基準／新興／置き換え済み／不明）と理由
    - 距離は一つの数字にしない。§3 の軸に分け、探索の優先度には使わない
    - 報告者の解釈と提案、各行の「報告者の一行」、報告者の読みを含む要約は地図に載せず、起票者用の文書に置く
    - 見つからなかったものと未検証の組み合わせは、その設計が新しい・価値があるという根拠として読まない
    - 出所の列は報告の行番号
    - citation の印は除く
