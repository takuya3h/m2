## 0. 要約（先に結論）

### 0.1 これまでに確定していること（変更なし）

1. **det→phase は効く**（凍結検出器の術具信号 → 工程認識、val acc +5.0pt / macro-F1 +9.6pt、paired-σ 有意）。
   利得は EDA が予言した混同工程 hemostasis に局在し、F1 0.353 → 0.800 と倍増する。
2. **phase→det は機構非依存で弱い**（再スコア −0.04 / FiLM +0.0019 / CA +0.0018 / CA+gate +0.0004）。
   L0 監査で「under-tuning ではない」ことも実証済み。
   例外は clsbias-PE（frozen × phase-排他ゲート）で、test でも +0.156pt と小さく有意。

### 0.2 本セッションで新たに分かったこと（結論を書き換えるもの）

本書は GPU 学習を 1 本も回していない。既存 `experiments/` の横断再集計と、
`data/processed/` 上の CPU 実験（numpy / scikit-learn）だけで以下を得た。

3. **未整理だった run 群を集計すると、val ではオラクル術具存在（15 次元・画像特徴なし）だけで
   acc 0.9666 / macro-F1 0.8375 / edit 64.74 / seg-F1@50 0.724 に達する**（§3.2）。
   現行最良 T1a（0.9483 / 0.8044 / 37.07 / 0.431）との差は
   分類 +1.83pt に対し **edit +27.67・seg-F1@50 +0.293**（すべて paired-σ 有意）。
   **GAP は冗長ではなく有害**（削除で acc +0.88pt・3.31σ・全 seed 同符号）。
4. **予測 presence は GT より 1.74 倍（val）/ 2.25 倍（test）ちらつき**、
   誤りの **73.8% は 1 フレームの孤立フリップ**（§3.4・§3.6）。
   **因果 HMM forward filter** でちらつきは 0.596 → 0.355（GT 0.342）へ解消し、
   **遅延 2 フレームでオフライン平滑化とほぼ同等**に達する（§3.5・§3.6）。
5. **GPU 不要のプロキシ工程認識器**（本体の `PhaseEvaluator` を使用・因果）を作ると、
   val では本番 TeCNO をよく再現し、デノイズで acc +0.86pt / edit +30.1 が出た（§3.7）。
   **一様遷移の陰性対照は生 sigmoid より悪く**、利得は「学習した遷移事前分布」由来。
   **素朴な移動平均は hemostasis F1 を 0.804 → 0.596 と壊す**（D-aux の実測と一致）。

### 0.3 しかし test と LOVO で結論は反転した（最重要）

6. **同じプロキシを test split で走らせると結論が反転する**（§3.8）。
   - 分節指標は **test でも改善する**（edit 17.71 → 36.13 = **2.04 倍**）。
   - **accuracy / macro-F1 は悪化する**（−4.9pt / −11.4pt）。悪化は
     **短い工程**（design 30 frame: 0.795 → 0.370 / irrigation 84 frame: 0.457 → 0.081）に局在する。
   - **オラクル presence ですら test では生の予測 presence に accuracy で負ける**（0.7512 vs 0.7890）。
7. **15 動画すべてを 1 本ずつ hold-out（LOVO）して貼り直すと、次が確定的になる**（§3.9）。

   **(a) 研究の中心的主張 P1（det→phase は効く）は LOVO でも成立し、分節側で桁違いに強い**:

   | 差（対 GAP のみ） | accuracy | macro-F1 | **edit** | **seg-F1@50** |
   |---|---|---|---|---|
   | 予測 presence − GAP | +0.0728（\|m\|/SE=2.23・12/15） | +0.1264（4.35・13/15） | **+32.20（6.44・15/15）** | **+0.338（6.09・15/15）** |
   | GAP⊕presence − GAP | +0.0154（1.16・12/15） | +0.0359（4.12・14/15） | +4.76（2.92・12/15） | +0.046（2.12・12/15） |

   → **det→phase の本当の効き所は分類ではなく分節**（edit / seg-F1 は 15/15 動画で正）。
   **GAP を足すと利得が大きく削がれる**（+7.28pt → +1.54pt）＝GAP は有害。

   **(b) しかしオラクル presence の追加的な優位はほぼ無い**:

   | 指標 | 生 presence | Δ(オラクル − 生) | Δ(因果デノイズ − 生) |
   |---|---:|---|---|
   | accuracy | 0.8658 ± 0.1411 | **+0.0022（\|m\|/SE=0.06・10/15）** | −0.0032（9/15） |
   | macro-F1 | 0.8004 ± 0.1291 | +0.0083（12/15） | +0.0027（9/15） |
   | **edit** | 50.73 ± 24.93 | +5.88（9/15） | **+9.11（\|m\|/SE=3.06・12/15）** |
   | **seg-F1@50** | 0.514 ± 0.268 | +0.065（12/15） | **+0.068（\|m\|/SE=3.15・12/15）** |

   - **完璧な術具存在を与えても、予測 presence に対する追加的な accuracy 利得はほぼ無い**（+0.22pt）。
     **§3.2 の「オラクル上限 +1.83pt」は val（動画 09・10）固有の値だった。**
   - **因果デノイズは分節指標を一貫して改善し、しかもオラクルより大きく改善する。**
     「完璧な検出」より「信号の時間的整形」の方が分節に効く。
   - **動画間のばらつきが支配的**（acc は動画 14 の 0.459 〜 動画 09 の 0.996）。
     本研究が val→test 反転に繰り返し遭遇した根本原因はここにある。
   - **オラクルが劇的に壊れる動画がある**（動画 05: 生 0.918 → オラクル 0.433）。
8. **「誤りを除くこと」と「2 値化すること」を LOVO で分離した**（§3.14）。
   - **2 値化そのものは害ではない**（macro-F1 +1.17pt・1.99σ・11/15。分散も低下）。
   - **2 値化した信号から誤りを完全に除いても accuracy はまったく上がらない**（−0.11pt・0.03σ）。
     **検出をどれだけ正しくしても分類は上がらない**、が最も鋭い形で確認された。
   - 唯一 accuracy を動かしたのは **GT ⊕ 生スコアを両方渡す**腕（+3.26pt・1.83σ・
     動画間ばらつきが pstd 0.141 → 0.096 に低下）。
     **容量対照も取った**: 生⊕生 は −0.05pt、生⊕乱数 は +0.11pt で **容量の産物ではない**。
     時間シャッフルした GT は +0.94pt しか出さないので、
     **利得の約 7 割はフレーム整合した GT を必要とする**。
   - なお動画 05 の失敗（closure が丸ごと dressing に化ける）は
     **その動画の closure が Needle Holders をほとんど使わない**ことで説明できるが（§3.9(e)）、
     **「2 値化の害」という一般化は §3.14 で否定された**。
9. **誤りは「量」ではなく「形」で、壊す場所が変わる**（§3.10・介入実験・15 動画 LOVO）。
   オラクル presence に **同じ誤り率 5%** で iid ノイズ（ちらつく）と burst ノイズ（持続的に間違う）を与えると:

   | ノイズの形 | Δaccuracy | Δedit | **accuracy 1pt あたりの edit 損失** |
   |---|---:|---:|---:|
   | **iid（ちらつき）** | −3.02pt（5.51・13/15 負） | −18.45（3.24・14/15 負） | **6.1** |
   | **burst（持続誤り）** | **−11.45pt**（6.46・15/15 負） | −17.77（3.18・13/15 負） | **1.6** |

   **孤立フリップは主に分節を壊し、持続的な誤りは主に分類を壊す**（選択性は **3.9 倍**）。
   **ノイズを評価側だけに掛けると（学習はクリーン）選択性は 7.0 倍に鋭くなる**:
   iid は edit を **56.6 → 16.2** とほぼ崩壊させるのに accuracy は −3.8pt しか動かず、
   burst は accuracy を −12.6pt 壊すのに edit は 37.6 を保つ。
   **学習側も汚すと選択性が鈍るのは、モデルがノイズの形に適応するからである。**
   ※ 単一 test split では「iid は accuracy をまったく壊さない」ように見えたが、
   **LOVO では iid も −3.02pt 壊す**。完全な二重解離ではない、と訂正した。
   これで本書のすべての観察が統一的に説明できる（§3.10 の表）。
10. **原因は「術具⇄工程の対応が手術ごとに揺れること」である**（§3.8(d)）。
   signature 術具（Syringe / Scalpel / Skewer / Bipolar）の対応は安定だが、
   **closure の Needle Holders は 0.83（train）/ 0.92（val）/ 0.51（test）**、
   **Mouth Gag は val で closure・hemostasis とも 1.00 なのに test では 0.29**。
   **val は術具⇄工程の対応が異常にきれいな split** である。
11. **揺れへの最初の一手も見つかった**（§3.11・Q7 の答え）。
    **工程を弁別しない汎用術具を信号から落とす**だけで、LOVO で
    **acc +1.61pt（\|m\|/SE=2.37・8/15）/ macro-F1 +2.29pt（2.80・9/15）**。
    **本書で最も安定した「改善」である。**
    落とす術具は **fold ごとに train のみ**の正規化エントロピー `H(phase | tool present) > 0.45` で決まる。
    エントロピーには **0.474（Forceps）と 0.347（Retractor）の間に 0.13 のギャップ**があり、
    **しきい値が自然に決まる**（該当 5 本 = Gauze / Mouth Gag / Suction Cannula / Tweezers / Forceps）。
    → **事前登録可能な手続き**である。
    機序は、汎用術具の在室パターンが **工程ではなく手術（動画）を符号化している**こと。
    **【訂正】デノイズとの併用が「4 指標すべてで基準超え」という当初の見立ては、
    順位ベースの k 掃引でしか出ず、しきい値プロトコルでは再現しなかった**（acc +0.51pt・0.47σ）。
    **2 つの独立した介入として扱う**のが正しい（分類なら除去・分節ならデノイズ）。
12. **手法は 15 本中 14 本で多数決ベースラインを大きく上回る**（平均 **+32.6pt**・\|m\|/SE=5.70・§3.13）。
    **唯一の破綻は動画 14**（presence acc 0.468 < 多数決 0.740）で、機序も特定できた:
    **この手術は止血に Bipolar Forceps ではなく Forceps を使う**ため、
    §3.3 が「最も価値がある」と特定した hemostasis の signature がそもそも存在せず、
    **hemostasis の 70% が dissection に化ける**。P4 の最も純粋な実例である。
    なお per-video 性能を最もよく予測するのは、意外にも **動画の長さ**（r=−0.778 / ρ=−0.789）だった。
13. **ただし「揺れ」の測り方は未解決**（§3.12・負の結果）。
    動画ごとの `P(tool|phase)` の JS ダイバージェンスは **per-video 性能とまったく相関しない**
    （presence 絶対 acc で r=−0.23 / ρ=−0.09、n=15）。
    ずれ最大の 2 本（動画 14 と 15）が正反対の結果になる。
    **「対応の揺れが効く」ことは示せたが、まだ測れていない。**
14. **【訂正】「デノイズは短い工程を潰す」も単一 split の現象だった**（§3.15）。
    LOVO では design 0.587 → 0.584（ほぼ不変）・dressing 0.096 → 0.098・irrigation 0.129 → 0.117。
    §3.8(c) の崩壊（design 0.795 → 0.370）は **test split の design がわずか 30 frame** だったため。
    さらに **潰さないための改良案（非対称 HMM / max(生,デノイズ) / 連結）はどれも
    素の因果デノイズより分節指標が悪い**。**余計な工夫をせず素直に因果デノイズするのが最良。**
15. **2 つの介入の頑健性は非対称だった**（§3.16・6 凍結源で LOVO）。
    - **高エントロピー術具の除去（分類側）は最も信頼できる**:
      **Δacc は 6/6 の凍結源で正・範囲 +1.13〜+2.13pt と狭く、5/6 で `|m|/SE ≥ 2`**。
      落とす本数も平均 4.9 本で安定。**強 aug 検出器でも同じだけ効く**（検出器品質と独立）。
    - **【重要な補正】「デノイズで edit +9.11」は凍結源 seed42 に固有の高い値だった**。
      6 凍結源の範囲は **+1.04 〜 +9.11**（通常 3 seed 平均 +5.46 / 強 aug 3 seed 平均 +3.42）。
      **符号は 6/6 で正**（符号検定 両側 p=0.031）なので改善自体は凍結源に依らないが、
      **効果量は 9 倍も振れる**。**E1 の事前登録で「+9.11 を再現する」と書いてはいけない。**
      ちらつき倍率との相関は r=+0.584（n=6）で **予測の向きとは一致するが有意ではない**。
16. **GAP が有害な理由も特定した**（§3.18）。GAP 2048 次元は
   **クリップ（動画）ID を 99.8% の精度で線形識別できる**（偶然 7.7%）。
   region-token 97.5% / 予測 presence 71.6% / オラクル presence 62.9%。
   動画単位 hold-out では GAP は純粋な過適合源になる。
17. **【最重要】時間方向の受容野を与えると、2 つの介入の運命が分かれる**（§3.16(d)(e)）。
    per-frame 分類器に過去のラグ特徴（因果性は保つ）を与えて LOVO を回した。

    | 介入 | K=0（文脈なし） | **K=8（受容野あり）** | 解釈 |
    |---|---|---|---|
    | **因果デノイズ**（分節） | edit **+9.11（3.06σ・12/15）** | edit **+0.008（0.01σ・6/15）** | **消える** |
    | **術具除去**（分類） | acc **+1.61pt（2.37σ・8/15）** | K=8 **+1.12pt** / K=32 **+1.48pt** / **K=128 で macro-F1 +3.08pt（2.24σ）** | **残る** |

    **わずか 8 フレームの文脈でデノイズの利得は完全に消え、同時に生の信号のままでも
    edit が 50.73 → 58.99 に上がる**＝**時系列モデルが自力でちらつきを吸収している**。
    **TeCNO の受容野は 128 フレーム**なので、**入力側デノイズは本番でほぼ効かないと予測される**。
    一方 **術具除去の利得はほとんど縮まない**（正の fold 数はむしろ増える）。

    > **ちらつきは「時間の問題」なので時系列モデルが自分で直せる。
    > 揺れる術具は「情報の問題」なので、どれだけ時間文脈を与えても直せない。**

    → **実務提案としてのデノイズは取り下げ、E1 は「安価な反証テスト」に格下げする。**
    ※ **§3.10 の科学的主張（誤りの"形"で壊れる場所が変わる）は取り下げない。**
    介入実験で直接示しており受容野の有無とは独立である。
    ※ **K=128（TeCNO 相当）まで確認済み**。デノイズ側の edit は +2.83（1.09σ・7/15）で有意でなく、
    除去側の macro-F1 は +3.08pt（2.24σ・10/15）と最も強い。

    デノイズの利得は 8 フレームの文脈で消えるが、**除去の利得は残る**。

## 1. 研究テーマの確認

### 1.1 何を問うている研究か

`EgoSurgery`（エゴセントリック手術映像）上で、

- **検出タスク**: 術具 15 クラスの bbox 検出（+ 手 4 クラス、+ 把持関係）
- **工程タスク**: 手術工程 9 クラスの online / causal な認識

の 2 タスクを扱い、**「両者を結合すると相互に改善するのか、するならどの向きに・どの結合様式で・
なぜ効くのか」**を、汚染のない Δ（相互改善幅）で定量する。

研究の性格は当初の「SOTA を出す」から **「分析ファースト」**にピボットしており
（`prompts/research_pivot_summary_and_roadmap.md`, 2026-06-15）、
現在の主張は **機構の解明 + 負の結果の厳密化** が中心である。

### 1.2 方法論上の規約（Δ の汚染防止）

- **比較の三角形**: 単一タスク分母（S0-frozen / S4）と結合手法を、
  **凍結源・特徴・eval recipe・seed・schedule を完全に揃えて**比較する。
- **凍結源**: Relation-DETR seed42 の完走 ckpt（`checkpoints/incoming/seed42/best_ap.pth`）。
  ResNet-50 backbone を凍結し、その C5 / GAP / region-token / tool-presence を全下流で共有。
- **eval recipe**: DETR 系は NMS-free（`score_thr=0.0` / `nms_iou=None` / `max_per_img=300`）で一本化。
  class-agnostic NMS@0.6 を掛けると **4.5pt** 汚染することを実測済（2026-06-15）。
  工程側は `online_causal + jaccard_strict`（未来フレーム不使用）。
- **有意性判定 §10.1**: **paired-σ**（同一 seed 同士の対差）で
  `|mean| > pstdev(対差)` かつ **全 seed 同符号** を満たすときのみ改善を主張する。
  base 群 σ の流用は符号反転を見落とすため禁止（2026-06-20 に運用統一）。
- **研究インテグリティ**: 数値の捏造禁止。未達は未達と書く。
  実際、n=2 の「segmental 改善（+5〜10pt）」は n=3 の paired 判定で**撤回**された（2026-06-20）。

### 1.3 データの性質（EDA, 2026-06-20）

| 項目 | 実測 |
|---|---|
| 規模 | 術具 COCO 15,437 画像 / 49,652 インスタンス（動画単位 hold-out: train 10 / val 2 / test 3） |
| frame 結合 | 検出↔工程の join **100%**（未結合 0） |

| **術具⇄工程の準決定的結合** | Needle Holders→closure 99.9% / Skewer→design 99.7% / Scalpel→incision 97.4% / Bipolar Forceps→hemostasis 98.0% / Syringe→anesthesia 84.2% |

**(b) 遅延（ラグ）を許すとどこまで直るか** **[本書で新規集計]**

固定ラグ HMM 平滑化（時刻 t の判定に t+L までの観測を使う＝**遅延 L フレーム**）を実装して掃引した。
`L=0` が純因果（§3.5）、`L=∞` は完全な forward-backward（オフライン）に一致する。

| 方式 | マクロ F1 | 誤り率 | 完全一致率 | 遷移/frame |
|---|---:|---:|---:|---:|
| 生 sigmoid | 0.9103 | 2.81% | 69.2% | 0.5959 |
| HMM 因果（L=0） | 0.9238 | 2.39% | 72.2% | **0.3545** |
| HMM 遅延 1 | 0.9284 | 2.36% | 72.0% | 0.2784 |
| **HMM 遅延 2** | **0.9312** | 2.31% | 72.3% | 0.2639 |
| HMM 遅延 4 | 0.9315 | 2.30% | **73.0%** | 0.2612 |
| HMM 遅延 8 / 16 / ∞（オフライン） | 0.9309 | 2.28% | 72.8% | 0.2507 |
| **GROUND TRUTH** | 1.0000 | 0.00% | 100.0% | **0.3419** |

**2 つの重要な所見**

1. **遅延 2 フレームで、オフライン平滑化とほぼ同じ品質に達する**（F1 0.9312 vs 0.9309）。
   **オフラインにしても得るものはほぼ無い。**
   本研究は既に「min-segment debounce k=2」で 1 フレームの遅延を運用上許容しているので、
   **遅延 2 フレームの平滑化は既存の運用規約と矛盾しない**。
2. **遷移率で見ると純因果（L=0）が最も GT に近い**（0.3545 vs GT 0.3419）。
   遅延を入れると **GT より平滑になりすぎる**（0.26〜0.28）。
   **「ちらつきを最小化する」ことと「GT の遷移率に合わせる」ことは別の目標**であり、
   工程認識にとってどちらが良いかは未知（E1 で L=0 と L=2 の両方を測る）。

**限界**: 誤り率は 2.81% → 2.28% と 19% しか下がらない。
**残りの誤りは持続的（長いラン）で、時間フィルタでは原理的に直せない**。
つまり本手法が狙えるのは **「ちらつき」の除去であって「誤り率」の削減ではない**。
だからこそ E0（同じ誤り率で iid とバーストを比べる）が決定的になる。

実装: `docs/analysis_scripts/hmm_presence_fixed_lag.py`

### 3.7 【本セッションで実施した検証】GPU 不要のプロキシで、工程側への効果を先に測る

§3.5–3.6 は **presence の品質**を測っただけだった。工程への効果は torch が要る（本ホストの `.venv` は壊れている）。
そこで **GPU 不要のプロキシ工程認識器**を組んで、信号だけを差し替えて比較した。

**プロキシの構成**（因果性は厳守・未来フレーム不使用）
- per-frame 分類器: 多項ロジスティック回帰（presence 15-d → 工程 9 クラス、train で fit）
- 時系列モデル: **因果 phase HMM forward filter**（遷移行列は train の工程ラベルから推定）
- 評価: **プロジェクト本体の `PhaseEvaluator`**（`src/egosurgery/metrics/phase.py`）をそのまま import。
  したがって edit_score / seg-F1 の定義は本番と同一。集計単位も本番と同じクリップ単位。
- 実装: `docs/analysis_scripts/proxy_phase_presence_denoise.py`

**プロキシは本番をよく再現する**（信号が同じもの同士で比較）

| 信号 | プロキシ acc / mF1 / edit / segF50 | 本番 TeCNO acc / mF1 / edit / segF50 |

accuracy と macro-F1 はほぼ一致する。edit はプロキシの方が 10 ほど低い
（TeCNO の方が平滑化能力が高い）。**したがってプロキシは「信号の情報量の差」を測るには使えるが、
TeCNO 上で同じ幅の利得が出るかは別問題である。**

**結果（プロキシ + 因果 phase HMM・val）**

| 信号の作り方 | acc | macro-F1 | edit | segF1@50 | hemostasis F1 |
|---|---:|---:|---:|---:|---:|
| 生 sigmoid（対照） | 0.9472 | 0.8057 | 30.83 | 0.420 | 0.804 |

| 一様遷移 HMM（**陰性対照**） | 0.9393 | 0.7981 | 27.23 | 0.339 | 0.808 |

**4 つの所見**

1. **学習した遷移事前分布が本質である**。**一様遷移の陰性対照は生 sigmoid より悪い**
   （acc 0.9393 < 0.9472、edit 27.2 < 30.8）。
   利得は「確率へ写像したこと」ではなく **「術具の在室が時間的に持続するという事前知識」**から来ている。
2. **素朴な移動平均は害になる**。edit は上がるが accuracy が −2.2〜−4.2pt、
   **hemostasis F1 が 0.804 → 0.596 / 0.451 と壊滅する**。
   これは D-aux 系統②の実測（`movavg` は T-4 比 −0.59pp）と一致する。
   **「平滑化すれば良い」のではなく「正しい時間モデルで平滑化する」必要がある。**
3. **遅延 2 フレームで、accuracy はオラクルとの差の 42% を回収し、
   分節指標はオラクルを超える**（edit 60.95 > 54.26 / segF1@50 0.663 > 0.639）。
   オラクルを超えるのは、デノイズ済み信号が GT より平滑で、
   工程予測がより安定になるためである（§3.6 の「GT より平滑になりすぎる」と整合）。
4. **hemostasis だけはオラクルに届かない**（0.822 vs 0.933）。
   §3.3 のとおり hemostasis は Bipolar Forceps の presence 精度に最も敏感で、
   そこは**誤り率の問題**であって時間フィルタでは直せない。
   → **「ちらつきを直す」と「誤り率を下げる」は別々に必要**という §3.6 の結論を工程側でも裏づける。

**限界（誠実性）**: これはプロキシであって TeCNO ではない。
**本番の TeCNO は既に強い時系列モデルなので、デノイズの利得の一部を先に吸収している可能性がある**
（実際 TeCNO の edit は生 presence で 40.15 とプロキシの 30.83 より高い）。
**TeCNO 上で同じ利得が出るかは UNKNOWN であり、E1 で実測する。**

### 3.8 【最重要・本セッションで実施した検証】プロキシを test で走らせると結論が反転する

§3.7 のプロキシは **test split でも走らせられる**（torch 不要）。走らせた。**結論は val と反転した。**

**(a) presence 品質は test でも改善する（デノイズ自体は機能している）**

2. **accuracy / macro-F1 は test で悪化する**（acc −4.9pt・macro-F1 −11.4pt）。

**(c) 悪化はどこに局在するか — 短い工程が消える**

**(e) この節の位置づけ（誠実性）**

- **したがって E−1（オラクル上限を本番 TeCNO で test 評価する・再学習不要）は
  他のどの実験よりも先に実行しなければならない。**

   accuracy +7.28pt（\|m\|/SE=2.23）だけでなく、**edit +32.20 と seg-F1@50 +0.338 は 15/15 動画すべてで正**。
   **det→phase の本当の効き所は分類ではなく分節だった。**
2. **GAP を足すと利得が大きく削がれる**（presence 単独 +7.28pt に対し GAP⊕presence は +1.54pt）。
   §3.18 の「GAP は動画指紋」と整合し、**GAP は有害**が LOVO でも確認された。
3. **因果デノイズは GAP 比で edit +40.45（15/15）**と最良。
   presence 単独との差（+9.11・12/15）は §3.9 の表のとおり。

**この 3 点は、本研究の主張を「分節指標で語る」方向へ動かす最も強い根拠である。**

**(e) 動画 05 でオラクルが壊れる機序を追った（Q8 の回答）** **[本書で新規集計]**

|---|---|

**ここから出る示唆（ただし §3.13 で一般化は否定された）**

> **「オラクル presence」は情報量の上限ではない。**
> 誤りを除く代わりに **連続値が持つ段階的な情報を捨てている**。
> したがって §3.2 の「オラクル上限 0.9666」は

- これは §6 の **E3（soft か hard か）**が測るべき当のものである。
  E3 の腕に **「GT presence + 生スコアを連結」**を必ず入れること。
  **【追記・訂正】§3.13 で LOVO 分離した結果、「binary 化そのものは害ではない」（むしろ macro-F1 は僅かに改善）。
  したがって本項の機序は動画 05 については妥当だが、全体の説明としては成り立たない。**
- 同時にこれは **P4（術具⇄工程の対応の揺れ）の具体例**でもある。
  「closure なのに Needle Holders を使わない手術がある」という揺れが、
  binary 表現では致命的な衝突を起こす。

**限界（誠実性）**: これはプロキシであって TeCNO ではない。
また LOVO は分母をすべて取り直すので、既存の val/test 分母と直接比較できない。
**しかし「結論が 2〜3 動画の引きに依存する」という脆弱性は、プロキシでも本番でも同じ構造で存在する。**
**本番 TeCNO で LOVO を回すのが、本研究の全結論を頑健にする最短経路である**（§6 の E8）。

### 3.10 【決定的・本セッションで実施した検証】誤りは「量」ではなく「形」で別々のものを壊す

§3.9 までで「デノイズは分節を直すが分類は直さない」と分かった。
**では誤りの"形"を変えたら何が壊れるのか**を、介入実験で直接測った。

**方法**: オラクル presence（GT 0/1）に、**同じ期待誤り率**で 2 種類のノイズを与える。
- **iid**: 各 (frame, class) を独立に確率 p で反転（＝ちらつく）
- **burst**: 長さ L の連続ランを確率 p/L で反転（＝ちらつかないが持続的に間違う）

train / test の両方に同じノイズ過程を掛け（乱数は独立）、プロキシで工程認識する。
seed 3 本の平均。評価は **test split**。実装: `docs/analysis_scripts/proxy_noise_structure.py`。

**訂正（重要）**: 単一 test split では「iid は accuracy をまったく壊さない」ように見えたが、
**LOVO では iid も accuracy を −3.02pt 壊す**。したがって **完全な二重解離ではない**。
成立するのは次の **相対的な選択性**である。

| ノイズの形（p=0.05） | Δacc | Δedit | **accuracy 1pt あたりの edit 損失** |

> 分節の損失を分類の損失で割ると **iid は burst の 3.9 倍**である。
> **誤りの"量"が同じでも"形"で壊れる場所が変わる。**
>

> （−3.02pt → −11.45pt）のに、**edit の損失はほとんど変わらない**（−18.45 → −17.77）。

**選択性は 3.9 倍 → 7.0 倍に鋭くなる。**
`edit` は iid で **56.6 → 16.2** とほぼ崩壊するのに accuracy は −3.8pt しか動かない。
逆に burst は accuracy を −12.6pt 壊すのに edit は 37.6 と保たれる。

> **学習側も汚すと選択性が鈍る**のは、**モデルがノイズの形に適応するから**である。
> **信号そのものが持つ性質としては、ちらつきは分節を、持続誤りは分類を壊す**が、
> **学習でその一部は吸収できる**。
> これは E2（学習型デノイザ）の設計にも効く: **デノイザが無くても TeCNO はある程度適応する**ので、
> **本番での利得はプロキシより小さく出る可能性がある**。

**含意（本研究の中核的な主張になりうる）**

これで本書のすべての観察が統一的に説明できる。

| 観察 | 説明 |
|---|---|
| 因果デノイズが edit を大きく改善し accuracy は改善しない（§3.7–3.9） | デノイズが除去できるのは **ちらつき成分のみ**（§3.6: 誤り率は 19% しか下がらない）。ちらつきは主に分節を壊していたので、分節が直る |
| オラクルにしても accuracy が上がらない（§3.9） | 残る誤りは持続成分だが、それを除いても **術具⇄工程の対応の揺れ**（§3.8(d)）が同じ働きをする＝オラクルでも「持続的に間違った信号」と同型になる |
| 検出器強化（強 aug）が accuracy に出ず分節に出た（§5.5） | 強 aug が減らしたのは主に **ちらつき**（1.74×→1.49×）だから |
| 素朴な移動平均が hemostasis を壊す（§3.7） | 平滑化は ちらつきを消すと同時に **持続的な誤りを作る**（短い在室を潰す）＝分類を壊す側へ回る |

**限界（誠実性）**
- プロキシであって TeCNO ではない。
- 単一 test split の表は学習に **train + val** を使っている（§3.7–3.9 は train のみ）ため、
  ノイズ無しの基準値（test acc 0.6267）は §3.8 のオラクル（0.7512）と一致しない。
  **同一設定内での iid vs burst の比較は妥当**だが、他節の絶対値とは並べられない。
  **LOVO の表（本節の後半）が主たる根拠であり、単一 split の表は参考である。**
- LOVO のノイズ実験は **ノイズ seed 3 本 × 15 fold**。1 seed 版と結論は同じ（選択性 3.4 倍 → 3.9 倍）。
- burst は重なりでノイズが打ち消し合うため、実測誤り率が p をやや下回る（p=0.20 で 16.2%）。
  **不利な側（誤り率が低い側）に burst が振れているのに accuracy はより悪い**ので、結論の向きは強まる。

- **分類（acc / macro-F1）を上げたいなら 高エントロピー術具の除去**（両指標とも `|m|/SE ≥ 2`）。
- **分節（edit / seg-F1）を上げたいなら 因果デノイズ**（両指標とも `|m|/SE ≥ 3`）。
- **併用は中間に落ちる**。ただし **hemostasis（最難関の工程）は併用が最良**（0.626 → 0.691）で、
  **dressing は除去のみが最良**（0.096 → 0.145）。**工程によって最適な構成が違う。**

**所見**

1. **「工程を弁別しない汎用術具を信号から落とす」だけで macro-F1 が有意に改善する**
   （k=3 で **+3.40pt・2.58σ・10/15**、k=4 で +2.61pt・**3.34σ**・10/15）。
   **`|mean|/SE ≥ 2` を満たす、本書で最も安定した「改善」である。**
   EDA は「汎用術具は効かない」と言っていたが、LOVO は
   **「効かないどころか汎化を害している」**ことを示す。
   機序は明快で、**汎用術具の在室パターンは工程ではなく手術（＝動画）を符号化している**からである。
2. **accuracy も k=4 で +1.23pt（1.97σ）・k=5 で +3.27pt（1.82σ）**と改善方向だが、
   `|mean|/SE ≥ 2` にはわずかに届かない。
3. **併用は「素直な足し算」にならず、優位も頑健でない**（上の訂正）。
   **2 つの独立した介入として扱うのが正しい**:
   分類なら除去、分節ならデノイズ。**工程によって最適が違う**（hemostasis は併用、dressing は除去のみ）。
4. **どの術具を落とすかは train のみから安定して決まる**（15 fold で同一順序）。
   運用上、この手続きは **事前登録可能**である。

- **accuracy の利得は表現力を上げると縮んで消える**（+1.61pt・2.37σ → +0.59pt・0.74σ）。

- **macro-F1 の利得は残る**（+2.29pt → +2.02pt、いずれも `平均の絶対値/SE ≥ 2`）。

**k を LOVO の結果から選ぶと選択バイアスが入る**ので、
本番では **しきい値 `H > 0.45`（= 5 術具・エントロピーの自然なギャップ）を事前に固定**して
1 点だけ検証すること。**k を掃引して最良を選んではいけない。**
なお 生 k=5 の acc +3.27pt は `|mean|/SE`=1.82 で基準未達であり、
**macro-F1（k=3 で 2.58σ / k=4 で 3.34σ）が最も安定した指標**であることは変わらない。

  (i) 学習データが減り（1810 frame を抜くと −12%、420 frame なら −3%）、
  (ii) 評価対象が大きく多様になる。**n=15 では両者を分離できない。**
- 動画 14（長さ 1810・多数決 0.74）と 動画 15（長さ 420・多数決 0.71）は
  **どちらも 1 工程に支配されているが結果は正反対**（0.468 vs 0.993）。
  **偏りだけでは決まらず、長さとの組合せで効く。**

> **したがって §6.6 の P4 は「機序としては確かだが、まだ予測式にできていない」**という段階に留まる。
> 現時点で最良の予測子は **動画の長さ**（r=−0.778）で、
> **`signature 欠落率`（§3.12・r=−0.557）は診断には有用だが予測子としては劣る**。

（`docs/analysis_scripts/proxy_lovo_capacity_of_head_denoise.py`・LOVO 15 fold）。

| per-frame 分類器 | 指標 | 生 | デノイズ | Δ | 平均の絶対値/SE | 正の fold |
|---|---|---:|---:|---:|---:|---:|

| 線形 | seg-F1@50 | 0.514 | 0.582 | **+0.068** | **3.15** | 12/15 |

- **accuracy はどちらでも動かない**（デノイズは分節にしか効かない、が表現力に依らず成立）。

**重要な限界**: MLP も **per-frame の分類器**であって、時間方向の受容野を持たない。
**TeCNO の吸収能力は時系列モデルとしての受容野に由来する**ので、この検証では代替できない。
→ **そこで受容野そのものを与えて確かめた（次の (d)）。**

**(d) 【決定的・本書の主張を撤回する結果】時間方向の受容野を与えるとデノイズ利得は消える** **[本書で新規集計]**

per-frame 分類器に **過去のラグ特徴**（`t, t−1, t−2, t−4, …, t−K`。因果性は保つ）を与え、
受容野 K を増やしながら同じ LOVO 比較をした
（`docs/analysis_scripts/proxy_lovo_receptive_field_denoise.py`）。

| 受容野 | 入力次元 | 生の edit | **Δedit（デノイズ − 生）** | Δseg-F1@50 | Δaccuracy |
|---|---:|---:|---|---|---|
| **K=0（文脈なし）** | 15 | 50.73 | **+9.11（3.06σ・12/15）** | +0.068（3.15σ） | −0.32pt（0.44） |
| **K=8** | 75 | **58.99** | **+0.008（0.01σ・6/15）** | +0.025（0.97σ） | +0.18pt（0.25） |
| **K=32** | 105 | 57.40 | **+0.064（0.04σ・8/15）** | +0.017（0.65σ） | +0.55pt（0.65） |
| **K=128（TeCNO 相当）** | 135 | 56.94 | **+2.83（1.09σ・7/15）** | +0.046（1.96σ・10/15） | +1.86pt（1.35σ） |

**わずか 8 フレームの受容野を与えるだけで、デノイズの edit 利得は完全に消える**
（+9.11 → +0.008）。**K=32 でも +0.064、TeCNO 相当の K=128 でも +2.83（1.09σ・7/15）で
いずれも有意でない。** 同時に **生の信号のままでも edit が 50.73 → 58.99 に上がる**＝
**時系列モデルが自分でちらつきを吸収している。**

**ただし完全にゼロとも言い切れない**: K=128 では seg-F1@50 が **+0.046（1.96σ・10/15）**と
判定基準の境界にあり、accuracy も +1.86pt（1.35σ・10/15）と正方向である。
**K に対して単調でもない**（edit は +0.008 → +0.064 → +2.83）ので、
**15 fold では残差を分離できない**。**「消える」ではなく「有意に検出できなくなる」が正確な表現である。**

> **したがって §3.5–§3.9 で見えた「因果デノイズが分節を大きく改善する」は、
> プロキシの per-frame 分類器が時間方向の文脈を持たなかったことの帰結である可能性が高い。**
> **TeCNO の受容野は 128 フレーム**（`num_layers=8` の dilation で 2^7）であり、
> K=8 どころではない。**E1 は本番でほぼ効かないと予測すべきである。**

**これは本書で 7 件目の自己訂正であり、最も重いものである。**
§6 の主路のうち **デノイズ側（P3 の実務的な提案部分）は取り下げる**。
ただし **P3 の科学的な主張（誤りの"形"で壊れる場所が変わる）は取り下げない** —
それは §3.10 の介入実験で直接示しており、受容野の有無とは独立である。
**「ちらつきは分節を壊す。ただし十分な受容野を持つ時系列モデルはそれを自力で吸収できる」**
という形に精密化される。

**(e) 一方、術具除去の利得は受容野を与えても残る** **[本書で新規集計]**

同じ受容野の実験を **術具除去**について行った
（`docs/analysis_scripts/proxy_lovo_receptive_field_prune.py`）。

| 受容野 | **Δaccuracy（除去 − 全次元）** | **Δmacro-F1** |
|---|---|---|
| K=0（文脈なし） | **+1.61pt（2.37σ・8/15）** | **+2.29pt（2.80σ・9/15）** |
| **K=8** | **+1.12pt（1.84σ・11/15）** | **+2.14pt（1.13σ・10/15）** |
| **K=32** | **+1.48pt（1.50σ・8/15）** | **+1.80pt（1.83σ・9/15）** |
| **K=128（TeCNO 相当）** | **+2.96pt（1.36σ・9/15）** | **+3.08pt（2.24σ・10/15）** |

**利得は縮まない**（accuracy +1.61 → +1.12 → +1.48 → **+2.96pt**、
macro-F1 +2.29 → +2.14 → +1.80 → **+3.08pt**）。
**TeCNO 相当の K=128 で macro-F1 は `\|m\|/SE`=2.24・10/15 と最も強い。**
同じ K=128 でデノイズ側の edit は +2.83（1.09σ・7/15）で有意でない。

**これが 2 つの介入の決定的な違いである。**

| 介入 | K=0 | **K=8（受容野あり）** | 解釈 |
|---|---|---|---|
| **因果デノイズ**（分節） | edit **+9.11（3.06σ）** | edit **+0.008（0.01σ）** | **時系列モデルが自力で吸収する** |
| **術具除去**（分類） | acc **+1.61pt（2.37σ）** | acc **+1.12pt（1.84σ）** | **時系列モデルでは埋められない** |

> **ちらつきは「時間の問題」なので時系列モデルが自分で直せる。
> 揺れる術具は「情報の問題」なので、どれだけ時間文脈を与えても直せない。**
>
> **したがって主路は「工程を弁別しない術具を信号から落とす」の一本に絞るべきである。**

**E1 の位置づけの変更**: 「主路の検証」から
**「安価な反証テスト（30 分・15 run）」**へ格下げする。
プロキシが「効かない」と予測している以上、**効かないことを確認して閉じるための実験**である。
`docs/task_drafts/E1_causal_denoise.spec.yaml` の予測をこの向きに書き換えること。

**この節が意味すること**

- 本書の 2 つの介入の頑健性は **非対称**である。

| 介入 | 符号の頑健性 | 効果量の頑健性 | 判定 |
|---|---|---|---|
| **高エントロピー術具の除去（分類）** | **6/6 正** | **+1.13〜+2.13pt（狭い）** | **本書で最も信頼できる知見** |

  **E1 の事前登録では「+9.11 を再現する」と書いてはいけない。**

### 3.17 【重要な限界】§3.2–3.4 の再集計はすべて val 評価である

本書で新規集計した「はしご」「ノイズ勾配」「presence 品質」は
**すべて val（動画 2 本・3 クリップ・1515 frame）**の値である。
test 指標を持つのは `t1a_base_test_*` / `t1a_regiontraj_test_*` の 2 群のみだった。

| 構成 | val acc | val edit | **test acc** | test macro-F1 | **test edit** | test segF1@50 |
|---|---:|---:|---:|---:|---:|---:|
| T1a base（3-seed） | 0.9476 | 35.65 | **0.8286** | 0.6869 | **52.32** | 0.481 |
| T1a-RegionTraj（3-seed） | 0.9476 | 39.24 | 0.8302 | 0.5994 | 50.21 | 0.432 |

**注意すべき 2 点**

1. **accuracy は val → test で −11.9pt 落ちる**（0.948 → 0.829）。val は accuracy にとって「易しい」。
2. **edit は逆に val 35.7 → test 52.3 と上がる**。val（09_1/10_1/10_2）は
   短いセグメントが多く分節指標が厳しく出る構造になっている。
   → **§3.2 が示した「オラクルなら edit 64.7」という headroom が test でも同じ幅で存在するとは限らない**。

**理由は split の分節構造の差である（本セッションで `data/processed/phase_manifest` から実測）**

| split | 動画 | クリップ | frame | GT セグメント | 1000 frame あたりのセグメント数 | 平均セグメント長 | 5 frame 未満のセグメント |
|---|---:|---:|---:|---:|---:|---:|---:|
| train | 10 | 13 | 9,657 | 219 | 22.68 | 44.1 | 22 / 219 |
| **val** | **2**（09, 10） | 3 | 1,515 | 31 | **20.46** | 48.9 | 3 / 31 |
| **test** | **3**（04, 05, 07） | 6 | 4,265 | 63 | **14.77** | **67.7** | 6 / 63 |

**test はセグメント密度が val の 0.72 倍・平均セグメント長が 1.4 倍**である。
edit_score は「予測セグメント列と GT セグメント列の編集距離」なので、
**GT セグメントが長く疎な test の方が構造的に高く出る**。§3.17 の逆転はこれで説明できる（Q6 の回答）。

**工程分布も split で違う**（本セッションで実測。§1.4 の記述をより正確にする）:

| 工程 | train | val | test |
|---|---:|---:|---:|
| dissection | 3,832 | 506 | 1,102 |
| closure | 3,595 | 557 | **2,444** |
| hemostasis | 825 | **57** | 239 |
| incision | 763 | 170 | 163 |
| anesthesia | 281 | 98 | 120 |
| design | 245 | 103 | **30** |
| irrigation | 93 | **0** | 84 |
| dressing | 12 | 24 | 83 |
| disinfection | 11 | **0** | **0** |

- **test には irrigation(84) と dressing(83) が存在する**（val には irrigation が無い）。
  したがって **test の macro-F1 はこの 2 工程を含む**ため、val の macro-F1 とは母集団が違う。
- **hemostasis は val に 57 frame しかない**。本研究の主要な利得（S4 0.353 → T1a 0.800 →
  オラクル 0.946）は **57 frame の上で測られている**。test では 239 frame あるので、
  **hemostasis の結論は test で測り直す価値が特に高い**。
- `disinfection` は train 11 frame のみで val/test に 0 → **どの split でも評価不能**。

**したがって E1 の事前登録には、val の主終点に加えて test 追認を必ず含める。**
オラクル群の checkpoint（`checkpoints/best_tecno.pth`）は残っているので、
**再学習なしの eval-only で test の上限を先に測れる**（最優先の下ごしらえ）。
これを測る前に「edit を +12 回収する」という定量予測を立てるのは危険であり、
**E1 の成功基準はオラクル test 値が出てから最終確定する**（本書の +12 は val 基準の暫定値）。

### 3.18 【本セッションで実施した検証】なぜ GAP は有害なのか — 信号の「動画指紋」度 **[本書で新規集計]**

§3.2 で「GAP を外すと acc が有意に上がる（+0.88pp・3.31σ）」ことが分かった。理由を調べた。

**方法**: train の各信号から **クリップ（動画）ID を当てる線形 probe**（`StandardScaler` +
L2 ロジスティック回帰）。同一クリップのフレームを 7:3 に分けて hold-out で評価する。
本研究の split は **動画単位 hold-out** なので、信号が動画 ID を強く符号化しているほど
未見動画への汎化を害する。

| 信号 | 次元 | **クリップ ID 識別精度** | 対応する工程 acc | val edit |
|---|---:|---:|---:|---:|
| **GAP（凍結 backbone の大域特徴）** | 2048 | **0.9979** | 0.8986 | 41.08 |
| region-token | 3840 | **0.9745** | 0.9481 | 35.93 |
| 予測 tool-presence | 15 | 0.7160 | 0.9457 | 40.15 |
| **オラクル tool-presence** | 15 | **0.6287** | **0.9666** | **64.74** |
| （偶然水準・13 クリップ） | — | 0.0769 | — | — |

**読み取り（Q5 の回答）**

- **GAP はほぼ完全な「動画指紋」である**（99.8%）。凍結 backbone の 2048 次元 GAP は
  工程の意味情報より先に「どの手術動画か」を符号化している。
  動画単位 hold-out では、これは**未見動画で剥がれる手がかり**であり、
  意味的な信号（tool presence）が別に与えられた瞬間に**純粋な過適合源**になる。
- **オラクル presence でも 0.629 ある**のは、術式ごとに使う術具の組が違うためで、
  これが「意味的な信号が原理的に持つ動画識別性の下限」である。
  **GAP の 0.998 はこの下限を大きく超えている。**
- **edit_score は動画指紋度と逆順に並ぶ**（0.9979→41.1 / 0.9745→35.9 / 0.7160→40.2 / 0.6287→64.7）。
  n=4 なので相関を主張はしないが、
  **「見た目に依存する信号ほど per-frame で揺れ、過分節を生む」**という §6.0 の診断と整合する。
- **クリップ centroid の cos 類似度は train 同士で平均 0.752（最小 0.544）**＝動画間の GAP 分布は大きく離れている。

**これは反証可能な設計指針を与える**: 信号から動画固有成分を落とせば汎化と分節が改善するはず。
最小の実装は **動画ごとの標準化（z-score）**である（§6 の E7）。

### 3.19 phase→det のクラス別内訳（clsbias-PE・val と test）**[本書で新規集計]**

§2.3 で「phase→det で唯一 test でも有意なのは clsbias-PE」と書いた。その内訳を
`experiments/analysis/t1b_clsbias_pe/results.json` と
`experiments/analysis/t1b_clsbias_pe_test/test_eval.json` から再集計する。
値は **注入 − 対照（zero-ctx）の per-class AP 差・3-seed・単位 pp**。

| 術具 | 注入対象 | **val Δ** | val 判定 | **test Δ** | test 判定 |
|---|---|---:|---|---:|---|
| **Scalpel**（incision signature） | ○ | **+1.207**（pstd 0.425） | **有意** | **+1.483** | **有意（全 seed 正）** |
| **Skewer**（design signature） | ○ | **+0.767**（pstd 0.394） | **有意** | **+1.330** | **有意（全 seed 正）** |
| **Syringe**（anesthesia signature） | ○ | **+1.213**（pstd 0.489） | **有意** | **−0.487** | **符号反転・非有意** |
| Bipolar Forceps | **×（除外）** | **−0.000**（pstd 0.001） | 中立 | **−0.0002** | 中立 |
| 非注入 10 術具 | × | \|Δ\| ≤ 0.003 | 厳密中立 | — | — |
| **overall mAP** | — | **+0.228**（pstd 0.057） | **有意** | **+0.156**（pstd 0.051） | **有意（全 seed 正）** |

**読み取り**

1. **除外した Bipolar Forceps は val でも test でも厳密に中立**（\|Δ\| < 0.001pp）。
   **phase-排他ゲートが設計どおり機能している**ことの直接の証拠である。
   非注入 10 術具も \|Δ\| ≤ 0.003pp で、**定数 bias はクラス内順位を変えない**という
   理論的性質が数値で確認できる。
2. **注入した 3 術具のうち 2 つ（Scalpel / Skewer）は test でも有意に保存**され、
   **むしろ test の方が大きい**（+1.48 / +1.33 vs val +1.21 / +0.77）。
3. **Syringe だけが val +1.213 → test −0.487 と反転する**。
   §3.1 の per-class AP でも **Syringe は val 0.582 → test 0.417（−16.5pt）**と落ちており、
   **val で rare な術具の per-class 結論は test で覆る**という本プロジェクトの教訓の実例になっている。
4. **overall は val +0.228pp → test +0.156pp と縮むが有意に残る**。
   **phase→det で「小さいが実在する」と言える唯一の解**である。

**含意**: phase→det は overall では弱いが、
**「rare ∧ phase-排他」な術具に限定した class prior 注入だけは test でも生き残る**。
本研究の貢献としては **「効かない」の一言で片づけず、この 1 例を明示的に残す**べきである。

### 4.1 停滞から読み取れる共通構造（§3 の新規集計を反映した改訂版）

1. **「rich にすれば効く」系の仮説が 5 連続で否定されている**
   （容量拡張 / 入力次元拡張 / Set encoder 圧縮 / ROI 背景除去 / 把持 5 次元追加）。
   **per-frame 表現の"量"を増やす方向はすべて外れている。**
   §3.18 が理由の一部を示す — 大域特徴（GAP）は **クリップ ID を 99.8% 識別する動画指紋**であり、
   次元を増やすほど動画固有の手がかりを持ち込む。
2. **val→test の反転が 2 件**（T1a-RegionTrajectory・検出器改善）。
   本書のプロキシ検証（§3.8）が **3 例目**になる。
   原因は「val は 2 動画・test は 3 動画」という極端に少ないクラスタ数と、
   **val が術具⇄工程の対応が異常にきれいな split** であること（§3.8(d)）。
   LOVO（§3.9）で **動画間のばらつきが支配的**（acc 0.459〜0.996）と定量化した。
   → **今後の判定は 15 動画 LOVO で行う**（§6.2 E8）。
3. **把持信号系は 60-seed・ビット単位決定化まで詰めて「上限が見えない」と結論した**。
   方法論としては最高水準の締め方だが、**問いの選び方が誤っていた**
   （把持は §3.3 の意味で価値の低い信号だった）。
   D-aux 系統①が既に「**手情報は tool に対し冗長**（上乗せ +0.04pp・不有意）」と実測していたのだから、
   **その延長にある把持も冗長である可能性が高いと事前に予測できた**。

4. **主終点の選択を誤っていた**（§5.5）。検出器改善の効果は accuracy には出ず、

5. **【本セッションの教訓】代理モデルで見えた効果は、本番の構造で消えることがある**（§3.16(d)）。

   **最後に per-frame 分類器へ 8 フレームの文脈を与えたら利得が消えた**。
   **代理モデルが本番と構造的に違う点（ここでは時間方向の受容野）を先に洗い出し、

## 5. 関連研究の調査（本セッションで実施）

「per-frame 検出信号の時間的安定性が律速」という本書の診断に対し、近い領域で使える手法を調べた。

### 5.1 直接効く手法

| # | 手法 / 論文 | 内容 | 本研究への適用 |
|---|---|---|---|
| L1 | **HMM-Stabilized Deep Learning for Surgical Tool Recognition**（arXiv:2404.04992） | 深層学習の per-frame 予測を**ノイズ観測**とみなし、phase 軌道と tool 軌道の **coupled HMM** で真の状態を推定。emission = 予測の混同行列、遷移は EM/Baum-Welch で学習。Cholec80 で tool mAP・phase mF1 とも一貫改善 | **本命**。ただし論文は **Viterbi（オフライン）**。本研究は online 制約があるので **forward filtering（因果）**に置き換えれば規約を壊さずに使える。§3.4 の「予測は GT の 1.74 倍ちらつく」に直撃。**本書 §3.5 で因果版を実装し、ちらつきが 0.596→0.355（GT 0.342）へ解消することを実測した** |
| L2 | **Privileged Knowledge Distillation for Online Action Detection**（arXiv:2011.09158） | 訓練時のみ観測できる情報（未来フレーム）を持つ teacher → online student へ蒸留 | 本研究では **teacher = GT presence**、student = 予測 presence。**ただし §3.9(e) のとおりオラクル presence は情報量の上限ではない**ので、蒸留の目標は「presence を当てること」であって「工程 accuracy の上限に届くこと」ではない、と明示する必要がある |

### 5.2b 本書の発見の新規性（文献に照らした正直な整理）**[本セッションで調査]**

本書が提案する 2 つの介入は、**技術としては目新しくない**。既出を明記しておく。

| 本書の要素 | 既出か | 位置づけ |
|---|---|---|
| **検出信号の時間平滑化そのもの** | **既出**。術具検出の online 後処理として確立している（例: adaptive transfer learning for tool presence detection, arXiv:2510.15372）。オフラインの forward-backward 平滑化も既出（medRxiv 2025.09.02.25334297） | **技術は新しくない。** 新しいのは「**何が直るか**」の分解（下記） |
| **工程認識の過分節対策** | **既出**。MS-TCN の smoothing loss、Neural FSM、task-graph refinement など多数 | 同上 |
| **split の代表性の問題** | **既出**。`Surgical phase and instrument recognition: how to identify appropriate dataset splits`（IJCARS 2024, PMC10973055）が、**術具の共起や術具⇄工程の対応が split 間で違う**ことを可視化し、再分割を推奨している | **本書はそれを「性能への影響」として実測した**点が違う。当該論文は診断ツールであり、モデル性能への効果は測っていない |

**したがって本書の新規性は「手法」ではなく「測定と分解」にある。**

1. **誤りの"形"による選択性**（§3.10）。同じ誤り率で
   **孤立フリップは分節を、持続誤りは分類を選択的に壊す**（選択性 3.9 倍）を
   **介入実験（iid vs burst ノイズ）**で示した。
   平滑化が「なぜ分節にだけ効くのか」をこの分解が説明する。
   **この分解を報告している文献は見つからなかった。**
2. **オラクル術具存在の追加的価値がほぼゼロ**（§3.9）。
   「検出を完璧にすれば工程も上がる」という広く共有された前提を、
   **15 動画 leave-one-video-out で反証**した（+0.22pt・平均の絶対値/標準誤差 = 0.06）。
3. **工程を弁別しない術具を落とすと汎化が上がる**（§3.11）。
   split 代表性の文献は「揃えるべき」と言うが、**「揃わない次元は捨てた方がよい」**という
   逆向きの処方は見当たらない。しかも **6 凍結源すべてで再現する**。
4. **大域特徴（GAP）が動画指紋である**（§3.18）。クリップ ID を 99.8% で線形識別できる。
   動画単位 hold-out における過適合源としての定量化は見当たらない。

**逆に、以下は本書の貢献ではない**（先行研究がある／技術として既知）。
- 因果 HMM で検出信号を平滑化すること自体。
- 工程の遷移事前分布を使うこと自体。
- split の代表性が問題であるという指摘自体。

### 5.3 文献との比較可能性についての重要な指摘

- 公式 **EgoSurgery-Phase** の split は **train 14 / val 2 / test 5 動画・27,694 frame**、
  報告値は TeCNO Jaccard **27.3%** / Trans-SVNet 23.1% / GGMAE（提案）**33.9%**。
- 本研究は **EgoSurgery-Tool の subset（15 動画・15,437 frame・train 10 / val 2 / test 3）**を使っており、
  S4 TeCNO の Jaccard は **0.6447**。**同じ指標名だが直接比較できない**
  （プロジェクトも「同一表に載せない」と明記している）。比較できない理由は 3 つある:
  1. **split が違う**（21 動画 14/2/5 vs 15 動画 10/2/3）。
  2. **母集団が違う**。本プロジェクトの `phase_macro_f1` / Jaccard は
     **その split に GT が存在する工程のみ**で平均する。公式値が 9 工程平均なら分母が違う。
  3. **backbone が違う**。本研究の S4 は **EgoSurgery 上で術具検出を学習した Relation-DETR の
     凍結特徴**を使う。公式の TeCNO ベースラインはそうではないので、
     本研究の S4 は「単なる TeCNO」より構造的に強い。**この差を SOTA 主張に使ってはならない。**
- **この非可比性は論文化の実務的な弱点**である。EDA / HTS 受入監査（G-4）が既に指摘しているとおり、
  **動画 17–22 には disinfection 115 / irrigation 321 / dressing 196 が存在する**。
  工程側だけを公式 21 動画 split に拡張すれば、(a) 構造的に F1=0 になっている 3 工程が復活し、
  (b) 文献と比較可能な表が 1 枚作れる。
  **ただし本チェックアウトには動画 01–15 しか無い（本セッションで実測）**ため、
  これは再分割ではなく追加データ取得を要する（§6.2 E6）。

## 6. 今後の方針

### 6.0 診断（最終版）

当初、本書は val の再集計から次のように診断した。

> 残 headroom は「検出信号の時間的一貫性」に律速される。

**test（§3.8）と LOVO（§3.9）と介入実験（§3.10）を経て、診断は 2 つに分かれた。**

> **(A) 分節（edit / seg-F1）は、検出信号の"ちらつき"に律速される。ただし十分な受容野を持つ
> 時系列モデルは、それを自力で吸収できる。**
> 同じ誤り率でも **孤立フリップは分節に選択的に効き（accuracy 1pt あたり edit −6.1）、
> 持続的な誤りは分類に選択的に効く（同 −1.6）**（§3.10・15 動画 LOVO・ノイズ seed 3 本）。
> **しかし per-frame 分類器に 8 フレームの文脈を与えるだけで、入力側デノイズの利得は消える**
> （edit Δ +9.11 → +0.008・§3.16(d)）。
> **TeCNO の受容野は 128 フレームなので、入力側デノイズは本番でほぼ効かないと予測される。**
>
> **(B) 分類（accuracy / macro-F1）は、検出精度には律速されない。**
> LOVO では **オラクル presence の追加的な accuracy 利得はほぼゼロ**（+0.22pt・\|m\|/SE=0.06）。
> 律速は **術具⇄工程の対応が手術ごとに揺れること**で、
> その主因は **工程を弁別しない汎用術具**である
> （落とすと LOVO で acc +1.61pt・2.37σ / macro-F1 +2.29pt・2.80σ・§3.11。6 凍結源すべてで正）。

**なお、研究の中心的主張 P1（det→phase は効く）は LOVO でも成立する**（§3.9(d2)）。
ただし **本当の効き所は分類ではなく分節**であり、
GAP のみに対し **edit +32.20 / seg-F1@50 +0.338 が 15/15 動画で正**（accuracy は +7.28pt）。

過去の負の結果は次のように整理し直せる。

| 過去の負の結果 | 最終的な説明 |
|---|---|
| 時系列核の差し替えが無効 / 容量拡張が無効 | 入力信号が律速（変わらず） |
| 入力次元拡張が無効（GAP は有害） | **GAP はほぼ完全な動画指紋**（クリップ ID を 99.8% 識別・§3.18）。LOVO でも GAP を足すと利得が +7.28pt → +1.54pt に削がれる |
| ROI 背景除去が無効 | ノイズ源は空間ではない（変わらず） |
| 検出器強化が phase へ非頑健（accuracy で判定） | **終点の誤り**（§5.5）。強 aug が減らしたのは主に **ちらつき**なので、効果は分節側にしか出ない |
| T1a が edit を悪化 | rich な信号ほどちらつきを運ぶ（§3.2） |
| 素朴な移動平均が hemostasis を壊す | 平滑化は ちらつきを消すと同時に **持続的な誤りを作る**（§3.10 の burst 側へ回る） |
| val→test の反転が繰り返し起きる | **val は術具⇄工程の対応が異常にきれいな split**（§3.8(d)）。加えて動画間のばらつきが支配的（LOVO で acc 0.459〜0.996） |
| 把持信号が無効 | §3.3 の感度が低い信号だった（手は tool に冗長・D-aux で実測済み） |

### 6.1 主路（再改訂）— 「揺れる信号を捨てる」を主、「分節を直す」は反証テストへ格下げ

> **【重要】§3.16(d) を受けて、本節は当初案から大きく変えてある。**
> **入力側の因果デノイズは、受容野を持つ時系列モデルの前では冗長になる可能性が高い。**
> 主路は **「工程を弁別しない術具を信号から落とす」**の一本に絞り、
> デノイズは **安価な反証テスト**として残す。

**主張したい命題（改訂版・2 つに分ける）**

> **(P3) 検出の誤りは"量"ではなく"時間構造"で、壊す場所が変わる。**
> 同じ誤り率でも **孤立フリップは主に分節を壊し（accuracy 1pt あたり edit −6.1）、
> 持続的な誤りは主に分類を壊す（同 −1.6）**（§3.10・介入実験・15 動画 LOVO・ノイズ seed 3 本）。
> 実際の検出誤りは 73.8% が孤立フリップなので、**因果デノイズはちらつき成分だけを除去でき、
> 結果として分節だけが直る**。検出器は一切変えない。
> **LOVO では短い工程を潰さない**（design 0.587→0.584・§3.14）ので、
> 当初懸念した「短工程感度との引き換え」は **単一 split の現象だった**。
>
> **(P4) 分類側の律速は検出精度ではなく、術具⇄工程の対応が手術ごとに揺れることである。**
> LOVO では **オラクル presence の追加的な accuracy 利得はほぼゼロ**（+0.22pt・\|m\|/SE=0.06）。
> 揺れの主因は **工程を弁別しない汎用術具**で、それを信号から落とすと LOVO で
> **acc +1.61pt（2.37σ）/ macro-F1 +2.29pt（2.80σ）**（§3.11・しきい値プロトコル）。
> **6 凍結源すべてで正**（+1.13〜+2.13pt・§3.16(b)）。
> ただし **分類器の表現力を上げると accuracy の利得は消え macro-F1 だけ残る**ので、
> **TeCNO で期待すべきは macro-F1 である**。

**候補手法（両方とも既存インフラで即座に試せる）**

```
入力: 凍結検出器の per-frame tool-presence（15-d sigmoid）。GAP は足さない（動画指紋・§3.18）
  ├─ 分類を上げたい → ① H(phase|tool) > 0.45 の 5 術具を落とす（train のみで決まる）
  │                     = Gauze / Mouth Gag / Suction Cannula / Tweezers / Forceps
  │                     LOVO: acc +1.61pt（2.37σ）/ macro-F1 +2.29pt（2.80σ）
  │                     ※ 標準 split では acc は上がらず macro-F1 が上がる（val +6.36 / test +1.83）
  └─ 分節を上げたい → ② 因果 HMM で時間デノイズ（遅延 2 frame。素直な形が最良・§3.15）
                        LOVO: edit +8.99（3.00σ）/ seg-F1@50 +0.067（3.10σ）
                        ※ 効果量は凍結源で +1.0〜+9.1 と振れる（符号は 6/6 で正）
causal TeCNO → 工程
```

**この 2 つは独立した介入である。併用の優位は頑健でなかった**（§3.11 の訂正）。
**さらに §3.16(d) により、②（デノイズ）は受容野を持つモデルの前では冗長になる可能性が高い。**
**実務上の推奨は ①（術具の除去）の一本である。**
ただし **最難関の hemostasis だけは併用が最良**（F1 0.626 → 0.691）で、
**dressing は除去のみが最良**（0.096 → 0.145）＝**工程によって最適構成が違う**。

**なぜこの形なのか**: (a) 反証可能、(b) 上限が実測済み、(c) 既存インフラで検証可能、
(d) 文献（HMM-stabilized・Privileged KD・Neural FSM）に接続する、
(e) **検出器を再学習しないので安価**、という性質を全部満たす。

改訂前の「分類も分節も改善する」という単一の主張は **test と LOVO で反証された**（プロキシ上で）。
**2 つの命題に分けたことで、それぞれが独立に反証可能になった。**

### 6.1b 何を測れば「効いた」と言えるか（終点の再定義）

| 主終点 | 理由 |
|---|---|
| **test の edit_score / seg-F1@50** | §3.8 で唯一 transfer した指標。効果量も大きい |
| test の短工程 F1（design / irrigation） | **監視項目**（ブロッカーではない）。LOVO では崩壊しない（§3.15）が、単一 split では崩れうる |
| **test / LOVO の macro-F1**（汎用術具の除去の腕） | P4 の主終点。プロキシ LOVO で **+2.29pt（\|m\|/SE=2.80）**、標準 split では val +6.36pt / test +1.83pt。**表現力を上げても残る唯一の指標**（MLP で +2.02pt・2.26σ） |
| 副次: test accuracy | デノイズ単独では **非劣化**（−1pt 以内）を条件にする。改善は期待しない |
| 副次: val の同指標 | 過去との比較可能性のためにのみ報告する |

**「val で良くなった」は成果として報告しない。**

### 6.2 実験計画

すべて **工程側のみ**（キャッシュ済み特徴を使う CPU/GPU 軽量学習）で、
1 run は数分〜30 分。検出器の再学習は E4 のみ。

**判定の規約（2 段構え）**

- **seed 3〜5 本の実験**: 既存規約 §10.1 — **paired-σ（対 seed 差）で `|mean| > pstdev` かつ全 seed 同符号**。
- **LOVO（15 fold）の実験**: **`|mean|/SE ≥ 2` + 符号検定**（12/15 以上で両側 p<0.05）。
  fold 数が増えると「全 fold 同符号」は原理的に成立しないため（60-seed 契約と同じ理由・§6.2 E8）。

**主終点は目的で分ける**（本書の中心的な発見に基づく）。

| 介入 | 主終点 | 根拠 |
|---|---|---|
| **因果デノイズ** | **edit_score / seg-F1@50** | LOVO で 3.0σ / 3.1σ。accuracy には効かない（§3.9） |
| **高エントロピー術具の除去** | **accuracy / macro-F1** | LOVO で 2.37σ / 2.80σ。分節にはほぼ効かない（§3.11） |

副次に hemostasis F1（最難関）と短工程 F1（design / irrigation）を必ず併記する。
すべて 3-seed（42/123/456）、LOVO まで回すなら 15 fold。
**accuracy だけを主終点に置かない**（量子化幅 1/1515 = 0.00066 に対し効果が小さく、
過去に「非有意」と誤結論した実例がある・§5.5）。

各実験は **走らせる前に `prereg.md` を commit**（既存 TASK 契約の作法）。

`--eval-test` 相当の経路で test を評価するだけ（`t1a_base_test_*` が既にこの経路を使っている）。

（`eval_t1b_test.py` が確立した作法。過去に bit-exact 一致を実証済み）。

**成果**: E1 の事前登録に書く「回収すべき幅」が実測値で決まる。

**test でオラクル presence が生の予測 presence に accuracy で負けた**（0.7512 vs 0.7890）。

#### E0（**プロキシでは実施済み**・本番 TeCNO で追認）— 「誤り率」か「時間構造」か

**状況**: §3.10 で **プロキシによる介入実験は本セッションで実施済み**。
明確な二重解離が出た（iid はちらつき経由で **分節だけ**を壊し、burst は **分類だけ**を壊す）。
残っているのは **本番 TeCNO で同じ介入をする**ことだけである。

**予測（事前登録・プロキシ実測に基づく改訂版）**: 同じ誤り率で比べたとき、
- **iid ノイズは edit / seg-F1 を大きく下げるが accuracy はほとんど下げない**
- **burst ノイズは accuracy / macro-F1 を大きく下げるが edit の下げ幅は小さい**

**なぜやるか**: 成立すれば「**検出の誤りは"量"ではなく"形"で、工程認識の別々の側面を壊す**」という
本研究独自の主張が、**介入実験（相関ではなく因果）**で立つ。
プロキシで既に出ているので、本番での追認は主張の強度を上げる作業である。

**実装**: `scripts/train_b2a.py` の `noise_rate` 分岐に `--tool-noise-mode {iid,burst}` を追加（約 20 行）。
burst は「幾何分布長 L のランを確率 q で反転し、期待誤り率が iid と一致するよう q を決める」。
`L ∈ {8, 32}`（＝GT の平均在室長のオーダー）を掃引する。

**構成**: base = `b2a_regiononly_oracle`（drop-gap・オラクル・acc 0.9666）。
ノイズ対象 = 全 15 dim と 上位 3 術具の 2 系統。`p ∈ {0.10, 0.20}`。
iid 側は **既存 run を再利用できる**（`b2a_base_oracle_noise_*` / `b2a_ro_oracle_top3noise_*`）ので、
新規に走らせるのは burst 側だけ = 2(dim系統) × 2(p) × 2(L) × 3 seed = **24 run**。

**判定**: `Δ_iid − Δ_burst` を同一 seed で対にして paired-σ。
edit_score で有意に `Δ_iid < Δ_burst`（iid の方が悪い）なら **成立**。

#### E1（本命・低コスト）— 因果 HMM フィルタ済み presence を工程へ渡す

**問い**: §3.5 で presence 品質を改善した因果フィルタは、工程認識を改善するか。

**予測（事前登録・§3.8 のプロキシ実測を反映した改訂版）**:

| 指標 | 予測 | 根拠 |
|---|---|---|
| **test edit_score** | 生 presence 比で **有意に改善**。**効果量は +3〜+5 を見込む**（+9.11 は seed42 固有の上振れ・§3.16） | §3.8(b)・§3.16 |
| **test seg-F1@50** | 有意に改善 | 同上 |
| **test accuracy / macro-F1** | **改善しない。悪化しうる** | プロキシでは −4.9pt / −11.4pt |
| test の design / irrigation F1 | **単一 split では悪化しうる。LOVO では悪化しない** | §3.8(c) vs §3.15 |
| val の各指標 | 改善する（が成果として報告しない） | §3.7 |

**成功基準（事前登録）**: **test の edit_score と seg-F1@50 がともに paired-σ で有意改善**し、
かつ **test accuracy の劣化が −1.0pt 以内**であること。
短工程 F1 は **監視項目**として必ず数値で報告する（LOVO では崩壊しないが、単一 split では崩れうる・§3.15）。

**腕の選択（§3.15 を受けて）**: 改良案（非対称 HMM / max(生,デノイズ) / 生⊕デノイズ）は
**どれも素の因果デノイズより分節指標が悪かった**。**素の L=0 と L=2 の 2 本に絞ってよい。**
ただし **生⊕デノイズ の連結だけは accuracy で最良**（LOVO で +0.89pt・1.67σ・12/15）なので、
「分類も落としたくない」なら 3 本目として入れる。

**最大のリスクは既に実測で顕在化している（§3.16(d)）**: プロキシの per-frame 分類器に
**8 フレームの文脈を与えるだけで edit の利得は +9.11 → +0.008 に落ちる**。
TeCNO 相当の K=128 でも **+2.83（1.09σ・7/15）で有意でない**。
**MLP に上げるだけでは利得は残った**（+6.02・2.20σ・§3.16(c)）ので、
**消しているのは表現力ではなく時間方向の受容野である**。
→ **本契約は「効かないことを確かめて経路を閉じる」ための反証テストとして回す。**

**結果の読み方（事前に決めておく）**:
- **改善しない（予測どおり）** → **入力側デノイズは工程モデルに対して冗長**と結論し、経路を閉じる。
  閉じた根拠として対の差の実測値を残し、同じ問いを再び立てない。
- **改善した（予測が外れた）** → **工程モデルの実効受容野が想定より狭い**ことを意味する。
  その場合は受容野そのものを広げる方が筋が良いので、デノイズではなく時系列側の設計を見直す。
- edit は改善するが accuracy が劣化 → 「時間的安定性と短工程感度のトレードオフ」として報告する。

**実装**:
1. `docs/analysis_scripts/hmm_presence_filter.py` を
   `scripts/build_hmm_presence.py` に昇格し、train/val/test の 3 split 分の
   フィルタ済み信号を `data/processed/b2a_detsignal/relation_detr_seed42_hmmfilt/` に書く
   （**train の GT のみでフィッティングし、val/test には適用のみ**）。
2. `scripts/train_b2a.py` に `--signal-tag`（既定 = `RELDETR_FROZEN_TAG`）を追加（約 5 行）。
   これで GAP のタグと信号のタグを独立に選べる。

**構成（3-seed × 4 腕 = 12 run）**:

| 腕 | コマンド |
|---|---|
| A 生 presence-only（対照・既存） | `train_b2a.py --drop-gap` |
| B **HMM presence-only** | `train_b2a.py --drop-gap --signal-tag relation_detr_seed42_hmmfilt` |
| C 生 presence + GAP（対照・既存） | `train_b2a.py` |
| D HMM presence + GAP | `train_b2a.py --signal-tag relation_detr_seed42_hmmfilt` |

**ラグの掃引（§3.6 を受けて追加）**: 信号は `L=0`（純因果）と `L=2`（遅延 2 frame）の 2 種を作る。
§3.6 のとおり L=0 は GT の遷移率に最も近く、L=2 は presence F1 が最も高いが GT より平滑になりすぎる。
**どちらが工程認識に効くかは未知**なので両方測る（腕は 4 → 6 に増える）。

**陰性対照（必須）**: HMM の遷移行列を **一様（0.5/0.5）**に置き換えた版を 1 系統走らせる。
これで「時間構造の事前分布」が効いたのか「単に確率へ写像した」だけかを分離する。

**追加の腕**: `生 + デノイズ を連結`（30 次元）。
LOVO では **accuracy で最良**（+0.89pt・1.67σ・12/15）だが分節利得は縮む（edit +5.76 vs +9.11）。
容量対照（生⊕生）は §3.13 で実質ゼロと確認済みなので、この差は容量由来ではない。

**注意（誠実性）**: HMM の遷移・emission は train GT から推定する。
これは学習データ内の情報のみを使うので規約違反ではないが、
**test split でも同じ推定器（train fit）で評価する**ことを事前登録に明記する。

#### E2（本命の一般化）— 学習型の因果デノイザ（Privileged Distillation）

**問い**: HMM（2 状態・クラス独立）を、**クラス間の共起**と
**region-token の情報**まで使う学習モジュールに置き換えたら、上限にどこまで近づくか。

**設計**: 小さな causal TCN（TeCNO と同じシェル・stages 1 / layers 4 / f_maps 32 程度）を
「presence refiner」として置き、入力 = 検出器の 15-d スコア（＋任意で region-token 3840-d）、
出力 = 15-d の presence 事後、**教師 = GT presence（＝privileged information）**。
その出力を凍結して工程 TeCNO へ渡す（2 段・疎結合＝本研究が確立した安全な結合様式）。

- 学習は **BCE + 遷移ペナルティ**（隣接フレームの出力差に L1）。
- **完全に因果**（causal conv のみ・未来不使用）。
- teacher（オラクル）が到達する 0.9666 が上限で、そこまでの回収率が指標になる。
- 文献対応: Privileged Knowledge Distillation for Online Action Detection（arXiv:2011.09158）の
  「訓練時のみ観測できる情報を online student へ蒸留」する枠組みそのもの。
  ただし本研究では privileged 情報が「未来」ではなく「GT ラベル」である点が新しい。

**§3.10 を受けた設計上の制約（重要）**:
デノイザは **ちらつきを消すこと**が目的だが、やりすぎると **持続的な誤り（短い在室の消失）を作る**。
§3.10 の二重解離によれば、それは **分類を壊す側**へ回る。したがって
- 損失に **「GT の遷移率に合わせる」項**を入れる（遷移を最小化しない。§3.6 で純因果 L=0 が GT 遷移率に最も近かった）、
- **短い在室（design の Skewer など）を保存できているか**を per-class の短区間 recall で監視する、
の 2 点を設計要件にする。

**段階**: E1 が成立してから着手する（E1 が失敗すれば前提が崩れるため）。

**ablation（事前計画）**:
(i) refiner なし（= B2a-RO）、(ii) HMM（E1）、(iii) 学習 refiner（15-d 入力）、
(iv) 学習 refiner（region-token 入力）、(v) 遷移ペナルティ無し、(vi) 教師 shuffle（陰性対照）。

#### E4（説明の確定・GPU 数時間）— presence 品質で凍結源の下流有用性を予測できるか

**問い**: 「凍結源の det→phase 有用性は、検出 mAP ではなく presence の時間品質で決まる」を確定する。

**方法**:
1. 既に持つ 4 種の凍結源（relation seed42/123/456・augstrong ×3・hires）について
   **presence 品質（マクロ F1・ちらつき倍率・完全一致率）と下流 phase acc の対応**を取る（既存 run のみ・再学習不要）。
2. **AlignDETR の presence を再抽出**して追加する（`DISCARDED` キャッシュは来歴不明のため使えない）。
   AlignDETR S0-frozen の再学習が必要（2 GPU × 約 6h）。これが最大コスト。
3. 回帰: phase acc ≒ f(presence マクロ F1, ちらつき倍率)。
   **ちらつき倍率が mAP よりよい説明変数になるか**を検定する。

**意義**: 2026-07-13 の「per-class AP では負転移を説明できない」という
**未解決の問い**にケリをつける。論文では「検出器選択の指標」として提案できる
（＝ **mAP ではなく presence stability を見よ**）。

#### E5（分節の残り・中コスト）— 工程側の構造事前分布

E1〜E3 で「入力側のちらつき」を潰した後、**残る過分節**を工程側で取る。

- **現行の到達点**: debounce k=2 の後処理で edit 32.96 → 56.4（acc −0.95pp）を既に実測済み。
- **提案**: **Neural Finite-State Machine**（arXiv:2411.18018）の causal 版を TeCNO の上に載せる。
  学習可能な工程状態埋め込み + 動的遷移表。EDA が実測した **工程順序遵守率 0.943 /
  自己遷移 0.982** をそのまま構造事前分布として使える。
- **比較の対称性**: debounce(k=2) は全腕に一律適用してから比べる（既に方針として確立済み）。
- **判定**: acc を落とさずに edit / seg-F1 を上げられるか。
  T1a-Boundary の実験で「学習 boundary head は online では効かない」ことが実証済みなので、
  **NFSM が boundary head と何が違うのか**（＝ frame ごとの境界ではなく系列の状態遷移を持つ点）を
  ablation で明示する必要がある。

#### E8（最重要級・**プロキシでは実施済み**）— 本番 TeCNO で leave-one-video-out

**状況**: §3.9 で **プロキシによる LOVO は本セッションで実施済み**。
残っているのは **本番 TeCNO で同じことをする**ことだけである。

**問い**: §3.9 のプロキシ LOVO が示した 2 つの結論は、本番 TeCNO でも成立するか。
- (i) オラクル presence の accuracy 優位は 15 動画平均で消える（+0.22pt・\|m\|/SE=0.06）
- (ii) 因果デノイズは分節指標を一貫改善し、オラクルより大きく改善する（edit +9.11・12/15）

**方法**: 15 fold × {生 presence, 因果デノイズ, オラクル} × 3 seed = **135 run**。
1 run は数分（B2a 系は軽量）なので現実的。`--drop-gap` 構成を使う（GAP は有害・§3.2）。
manifest を fold ごとに作る必要があるため、`scripts/build_lovo_manifest.py` を新規に書く
（既存 `phase_manifest` の clip を動画キーで再分割するだけ）。

**判定**: 15 fold の対差で `|mean|/SE ≥ 2` と符号検定（12/15 以上で両側 p<0.05）を併記する。
**既存の「全 seed 同符号」規約は fold 数が増えると原理的に成立しない**ので、
60-seed 契約が採用した `|mean|/SE ≥ 2` 基準へ移行することを事前登録に明記する。

**得られるもの**: 本研究の **すべての Δ を 15 fold で貼り直せる**。
現在すべての結論が「たまたま引いた 2〜3 本の手術」に依存しているという最大の脆弱性が解消する。
**分母を取り直すので既存表との直接比較は失われる**が、既存表は残して併記する。

**追加で測るもの（改訂）**: 動画ごとの「対応の揺れ」の指標を作り、
**動画ごとの det→phase 利得がそれで説明できるか**を回帰する。
**素朴な JS ダイバージェンスは既に試して無相関だった**（§3.12・n=15）。
次に試すのは (a) 工程単位のずれ、(b) signature 術具に限ったずれ、(c) ずれの方向（signature が欠けるのか別のものが混じるのか）。
どれかが効けば `gain ≈ headroom × signature × 安定性` という拡張予測式になる（§6.6 の P4）。

#### E9（**プロキシでは実施済み**・本番 TeCNO で追認）— 汎用術具を信号から落とす

**状況**: §3.11 と §3.16(b) で **プロキシ LOVO による検証は本セッションで実施済み**。
**本書で最も信頼できる知見**である。

| 検証 | 結果 |
|---|---|
| 単一凍結源（seed42）・しきい値プロトコル | **acc +1.61pt（2.37σ・8/15）/ macro-F1 +2.29pt（2.80σ・9/15）** |
| **6 凍結源での再現性** | **Δacc は 6/6 で正・範囲 +1.13〜+2.13pt・5/6 で `\|m\|/SE ≥ 2`** |
| 落とす本数の安定性 | 6 凍結源 × 15 fold で平均 **4.9 本**（ほぼ常に 5 本） |
| 強 aug 検出器でも効くか | **効く**（+1.13〜+1.94pt）＝**検出器を良くしても消えない利得** |

**ただし E9 は標準 split（train → val / test）で走らせる契約である。**
標準 split で測り直すと挙動が変わる（§3.11 の「参考」）:

| 条件 | 落とす本数 | Δaccuracy | Δmacro-F1 |
|---|---:|---|---|
| LOVO（15 fold・6 凍結源） | 4.9 | **+1.13〜+2.13pt（6/6 正）** | +0.83〜+3.38pt |
| **標準 split（train 10 動画）** | **4** | **−0.20pt（val）/ −0.33pt（test）** | **+6.36pt（val）/ +1.83pt（test）** |

**したがって事前登録の主終点は `macro-F1`、`accuracy` は非劣化条件に置く。**
LOVO で見えた accuracy の改善をそのまま期待してはいけない。
`docs/task_drafts/E9_prune_high_entropy_tools.spec.yaml` はこの実測に合わせてある。

**手続き（事前登録可能・そのまま本番へ）**
1. **train のみ**から各術具の正規化エントロピー `H(phase | tool present) / log2(9)` を計算する。
2. **`H > 0.45` を満たす術具を落とす**（`scripts/train_b2a.py --mask-tool-dims` で実装済み・コード変更不要）。
   ※ 全 train で計算すると 5 本
   （Gauze 0.646 / Mouth Gag 0.566 / Suction Cannula 0.530 / Tweezers 0.520 / Forceps 0.474）。
   6 位 Retractor は 0.347 で **0.13 のギャップがある**ため、しきい値は安定している。
3. **しきい値は事前に固定する。k を掃引して最良を選んではいけない。**

**構成**: 3-seed × 4 腕（{生, デノイズ} × {全 15 次元, `H>0.45` の除去}）。
`--drop-gap` 構成で行う（GAP は有害・§3.2）。
LOVO まで回すなら 15 fold × 4 腕 × 3 seed = 180 run（1 run 数分）。

**主終点**: **macro-F1**。**accuracy と edit は非劣化条件**。
標準 split のプロキシでは macro-F1 が val +6.36pt / test +1.83pt 改善する一方、
accuracy はわずかに下がる（−0.20 / −0.33pt）。

**併用の扱い（重要）**: プロキシ LOVO では **併用の優位は頑健でなかった**（§3.11 の訂正）。
順位ベースの k 掃引では 4 指標すべてで基準を上回ったが、
**しきい値プロトコルでは acc +0.51pt（0.47σ）にとどまる**。
**4 腕すべてを測って格子を作り、「提案手法」を先に決め打ちしないこと。**
工程別には **hemostasis が併用で最良（0.626→0.691）、dressing は除去のみが最良（0.096→0.145）**なので、
**per-phase の表を必ず出すこと**。

#### E7（新規・極低コスト）— 信号から「動画指紋」を落とす

**問い**: §3.18 が示した「GAP は 99.8% の精度で動画を識別できる」を踏まえ、
**信号から動画固有成分を除けば汎化（test acc）と分節（edit）が改善するか**。

**最小の実装（学習不要・因果性に注意）**:
1. **オンライン累積 z-score**: 各動画の先頭からその時点までの平均・分散で標準化する
   （未来を使わないので `PHASE_EVAL_PROTOCOL` を壊さない）。
2. 比較のため **オフライン動画単位 z-score**（動画全体の統計を使う＝因果でない）も測り、
   「因果制約でどれだけ損をするか」を明示する。
3. さらに強い版として **動画識別に対する adversarial（gradient reversal）**を
   工程ヘッドの前に置く案があるが、これは学習が要るので後段。

**構成（3-seed × 4 腕 = 12 run・数分/run）**:
A GAP そのまま（＝S4 base・対照） / B GAP + オンライン z-score /
C GAP + オフライン z-score（上限参照） / D region-token + オンライン z-score

**判定**: 主終点は **test accuracy と test edit**（この実験の狙いは汎化なので val では意味が薄い）。
既存 §10.1 の paired-σ。

**期待と反証**: B が A を test / LOVO で上回れば「動画指紋の除去が効く」。
上回らなければ「GAP の害は動画指紋ではなく別の要因（容量・スケール）」となり、§3.18 の解釈を修正する。

**P4 との関係**: 動画指紋の除去は **「手術ごとの揺れに頑健にする」方向の最小実装**でもある。
効くなら、同じ発想を presence 側（動画ごとの presence 統計の正規化）へ広げる価値がある。

### 6.6 論文としての主張の再構成（改訂）

| 柱 | 内容 | 状態 |
|---|---|---|
| **P1（強化）** | det→phase は効き、利得は `gain ≈ headroom × signature` で予測できる（val hemostasis F1 0.353→0.800）。**15 動画 LOVO でも成立し、分節側で桁違いに強い**（GAP 比 edit +32.20・seg-F1@50 +0.338 が **15/15 動画で正**、accuracy は +7.28pt） | **確定**（per-phase 分解・shuffle 対照・per-slot ablation・LOVO） |
| **P2** | phase→det は機構非依存で弱い（4 機構・L0 監査つき）。ただし phase-排他ゲート付き class bias だけは test でも小さく有意 | **確定** |
| **P3（改訂・強化）** | **検出の誤りは"量"ではなく"時間構造"で、壊す場所が変わる。** 同じ誤り率で **孤立フリップは分節に選択的に効き、持続誤りは分類に選択的に効く**（選択性 3.9 倍・§3.10・介入実験・15 動画 LOVO・ノイズ seed 3 本）。実際の検出誤りは 73.8% が孤立フリップである。**ただし入力側デノイズは「実務提案」から取り下げた**: per-frame 分類器に 8 フレームの文脈を与えるだけで利得が有意に検出できなくなり（edit +9.11 → +0.008）、**時系列モデルが自力でちらつきを吸収する**（§3.16(d)）。**科学的主張（誤りの"形"の選択性）は介入実験で直接示しており、受容野の有無とは独立に成立する** | **科学的主張は確定寄り（介入実験・LOVO）／実務提案は取り下げ（E1 は反証テスト）** |
| **P4（新・本書で最も信頼できる部分を含む）** | **det→phase の分類側の壁は検出精度ではない。** LOVO では **オラクル presence の追加的な accuracy 利得がほぼゼロ**（+0.22pt・\|m\|/SE=0.06）。原因は **術具⇄工程の対応が手術ごとに揺れること**（closure の Needle Holders 0.83/0.92/0.51、Mouth Gag 1.00→0.29）。**揺れの主因は工程を弁別しない汎用術具で、`H>0.45` の 5 本を落とすと LOVO で acc +1.61pt（2.37σ）/ macro-F1 +2.29pt（2.80σ）**（§3.11）。最も純粋な実例は **動画 14（止血に Bipolar Forceps を使わない手術）**（§3.13）。**除去の利得は 6 凍結源すべてで正・範囲 +1.13〜+2.13pt と狭く**（§3.16(b)）、**時間方向の受容野を TeCNO 相当（K=128）まで与えても残る**（macro-F1 +3.08pt・2.24σ・§3.16(e)）＝**本書で最も信頼できる知見** | **仮説（E−1 / E8 / E9 で検証）** |
| 副 | 検出器の選択指標は mAP ではなく presence の時間安定性であるべき | **仮説（E4）** |
| 副 | GAP のような大域特徴は **動画指紋**（クリップ ID を 99.8% 識別）であり、動画単位 hold-out では過適合源 | **確定（§3.18）／除去効果は E7** |
| 副 | **手法は 15 本中 14 本で多数決ベースラインを +32.6pt 上回る**（\|m\|/SE=5.70）。唯一の破綻は動画 14 | **確定（§3.13）** |
| 副 | 評価上の注意: signature 部分集合 AP は下流有用性を予測しない／**単一 split・プロキシの構造で見た結論は繰り返し覆る**（本書自身が 8 回） | **確定** |

**新規性の所在（§5.2b の調査に基づく）**: 本研究が新しいのは **手法ではなく測定と分解**である。
検出信号の時間平滑化も、工程の遷移事前分布も、split 代表性の問題提起も既出である。
新しいのは (a) **誤りの"形"による選択性の分解**、(b) **オラクル術具存在の追加的価値がほぼゼロという反証**、
(c) **「揃わない次元は捨てた方がよい」という逆向きの処方**、(d) **大域特徴が動画指紋であることの定量化**。
**論文の書き方もこれに合わせるべきである**（「新手法を提案する」ではなく「広く信じられている前提を測って覆す」）。

**P4 が成立すると、本研究の物語は次のように変わる。**

> 「検出→工程は効く。しかしその効き方は **val の術具⇄工程対応がきれいだから**であり、
> 未見の手術では対応が揺れて上限そのものが下がる。
> したがって伸ばすべきは検出精度ではなく、**対応の揺れに頑健な結合**である。」

これは negative result ではなく **設計指針の転換**である。
ただし **「signature の split 間安定性」を第 3 の因子として定式化するのは時期尚早**である。
**素朴な定量化（動画ごとの `P(tool|phase)` の JS ダイバージェンス）は per-video 性能を説明しなかった**（§3.12・n=15 で相関ゼロ）。
現時点で言えるのは **「対応の揺れが効く」ことと、「揺れる術具を落とすと改善する」こと**（§3.11）までであり、
**揺れの適切な測り方は未解決**（Q12）。最良の指標は `signature 欠落率`（r=−0.557）だが、
**per-video 性能の最良の予測子は依然として「動画の長さ」（r=−0.778）**という皮肉な状態にある（§3.13）。

| 「デノイズ + 術具除去の併用が 4 指標すべてで基準超え」 | 順位ベース k 掃引でしか出ず、**しきい値プロトコルでは再現しない**（acc +0.51pt・0.47σ）。2 つの独立した介入として扱う（§3.11） |

**8 件のうち 4 件は「単一 split で見た所見が LOVO で覆った」型、
2 件は「選択の仕方（順位 vs しきい値・凍結源 1 本）に敏感だった」型、
1 件は「交絡を疑ったが対照を取ったら杞憂だった」型、
1 件は **「プロキシの構造的な制約（受容野の欠如）が利得を生んでいた」型**である。**
本書自身が **8 回**この型に嵌ったことは、
**§6 の「val 単独の結果を成果として報告しない」方針の実証**でもある。
**そして本書の結論のうち LOVO を通ったものだけが残った。**
