# sessions — 対話から抽出した記録

## 中身

    ~/claude-sync/session-digest/<ホスト名>/<日付>-<セッション識別子>.md    # 2026-10-07 から
    docs/sessions/digest/<日付>-<セッション識別子>.md                       # 2026-10-07 より前（追跡済み 48 件）

ホスト名は `SERVERNAME` → repo の `.servername` → `hostname` の順に決める（`m2-sync.sh` と同じ）。
既定の出力先は、書き込まずに表示できる。

    python tools/session_digest.py --show-out-dir

対話記録から機械的に抽出した要素のみ。会話本文・所感・評価は含まない。
抽出するのは次の 4 つで、いずれも様式が定まっているものだけである。

| 要素 | 出所 |
|---|---|
| 契約の識別子 | コマンドとファイルパスに現れる `T-YYYY-MM-DD-slug` |
| 実行されたコマンド | ツール呼び出しの `input.command` |
| 編集または参照されたファイル | ツール呼び出しの `input.file_path` |
| 失敗したツール呼び出し | 結果ブロックが失敗を示すもの |

コマンドは先頭 200 文字で切り詰める。ヒアドキュメントはコマンド文字列に文書全体を
含むため、そのまま残すと抽出物が文書の再掲になるからである（実測で 176KB から 22KB へ）。
**切り詰めであって要約ではない。** 切り詰めた場合はその旨を末尾に付す。

## 伏せ字

抽出後に必ず適用する。既定で伏せ、通す方を例外にする。

| 対象 | 規則 |
|---|---|
| 秘密を示す名前への代入 | 名前は残し値を伏せる |
| 鍵らしき接頭辞を持つ長い文字列 | 接頭辞だけ残して伏せる |
| 32 文字以上の十六進 | 先頭 4 文字だけ残して伏せる |
| ファイルパス・短い十六進 | 伏せない |

短い十六進を伏せないのは、commit の短縮形が日常的に現れるためである。

## 生の記録

**版管理へは入れない。** 秘匿情報が混入しうるためである。
各実装系の既定の保存先に残るので、必要ならそこを直接参照する。

## 抽出物の扱い

**抽出物は版管理へ記録しない。** 出力先は repo の外の共有フォルダ
`~/claude-sync/session-digest/<ホスト名>/` である（Syncthing の共有フォルダ。全台へ配られる）。

**2026-10-07 に、2026-08-09 の「抽出物は版管理へ記録する」を撤回した**（利用者の決定。
`T-2026-10-07-pause-release-tool-digest-relocate`）。理由は二つある。

1. repo は公開であり、会話由来の抽出物を公開する必然性が薄い。全台からの検索は共有フォルダで保てる
2. 終了フックはセッションの最後、つまり契約の最後の commit の後に抽出物を書く。旧い置き場では
   次の契約の `make task-start` が、未追跡の抽出物による作業ツリーの汚れでほぼ毎回止まっていた

旧い置き場 `docs/sessions/digest/` は `.gitignore` に載せた。**追跡済みの 48 件は追跡のまま残す。**
各ホストに残っている未追跡の抽出物は、無視されるため汚れに数えられない。

**共有フォルダが無いホストでは何も書かない。** セッションの終了は妨げない。

**第二の実装系の走査は、旧い置き場に同じ名前の抽出物があれば作り直さない。** 置き場を移した直後に、
全台で過去分が一斉に書き出されるのを避けるためである。内容は比べない（旧い版の書式で書かれた
抽出物を「未抽出」と取り違えないため）。

伏せ字は抽出の後に従来どおり適用される。生の記録は伏せ字を経ていないため、引き続き共有フォルダにも置かない。

## 判断

抽出物は素材であり判断ではない。判断は `tasks/inbox.md` へ 1 行で置く。

## 手で作る場合

セッション終了の事象が使えない実装系では、記録のパスを渡して直接実行する。

    python tools/session_digest.py --transcript <記録のパス>
    python tools/session_digest.py --transcript <記録のパス> --stdout
