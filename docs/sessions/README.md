# sessions — 対話から抽出した記録

## 中身

    docs/sessions/digest/<日付>-<セッション識別子>.md

対話記録から機械的に抽出した要素のみ。会話本文・所感・評価は含まない。
抽出するのは次の 4 つで、いずれも様式が定まっているものだけである。

| 要素 | 出所 |
|---|---|
| 契約の識別子 | コマンドとファイルパスに現れる `T-YYYY-MM-DD-slug` |
| 実行されたコマンド | ツール呼び出しの `input.command` |
| 編集または参照されたファイル | ツール呼び出しの `input.file_path` |
| 失敗したツール呼び出し | 結果ブロックが失敗を示すもの |

コマンドは先頭 200 文字で切り詰める。ヒアドキュメントはコマンド文字列に文書全体を
含むため、そのまま残すと抽出物が文書の再掲になるからである（実測で 176KB から 22KB へ）。
**切り詰めであって要約ではない。** 切り詰めた場合はその旨を末尾に付す。

## 伏せ字

抽出後に必ず適用する。既定で伏せ、通す方を例外にする。

| 対象 | 規則 |
|---|---|
| 秘密を示す名前への代入 | 名前は残し値を伏せる |
| 鍵らしき接頭辞を持つ長い文字列 | 接頭辞だけ残して伏せる |
| 32 文字以上の十六進 | 先頭 4 文字だけ残して伏せる |
| ファイルパス・短い十六進 | 伏せない |

短い十六進を伏せないのは、commit の短縮形が日常的に現れるためである。

## 生の記録

**版管理へは入れない。** 秘匿情報が混入しうるためである。
各実装系の既定の保存先に残るので、必要ならそこを直接参照する。

## 抽出物の扱い

対話記録の抽出物は**版管理へ記録する。**

機械抽出のテキストであり、会話本文も要約も含まない。伏せ字は抽出後に必ず適用される。
量が小さく（2026-08-09 の bengio 実測で 6 件 48KB）、他のホストからも検索できる価値がある。

生成のたびに作業ツリーへ現れるため、**次の契約の記録と一緒に含める。**
放置すると未追跡ファイルが残り、自動統合が止まる（`git merge --ff-only` は未追跡ファイルの
上書きを、内容が同一でも拒否する。B-30 参照）。

    git add docs/sessions/digest/

記録する前に、伏せ字が効いていることを目視で確かめる。一致が出た場合は
**何に一致したのかを見る**（伏せ字済みの `NAME=***` に一致しただけのこともある）。

    git diff --cached docs/sessions/digest/

前節の**生の記録とは扱いが逆である。** 生の記録は伏せ字を経ていないため版管理へ入れない。
抽出物は伏せ字を経ているため入れる。

## 検索

    rg <検索語> docs/sessions/

## 判断

抽出物は素材であり判断ではない。判断は `tasks/inbox.md` へ 1 行で置く。

## 手で作る場合

セッション終了の事象が使えない実装系では、記録のパスを渡して直接実行する。

    python tools/session_digest.py --transcript <記録のパス>
    python tools/session_digest.py --transcript <記録のパス> --stdout
