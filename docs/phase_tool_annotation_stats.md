## 要点

**術具**（[§1](#s1)）
1. 長い裾の分布。box の最多 / 最少は Tweezers / Skewer = 29.1 倍。1 フレームの術具は平均 2.83 種
   （最大 6 種）で、術具の無いフレームは 123（[§1.1](#s1-1)・[§1.2](#s1-2)）
2. box は大きく、画像端で切れやすい。COCO の large が 96.6%、画像端に接する box が
   34.3%、中心が画像中央 1/9 にある box は 28.3% だけ（[§1.3](#s1-3)・[§1.4](#s1-4)）
3. Mouth Gag は 5/15 動画にだけ出て、その動画では注釈フレームの 96.5〜99.4% に写る。
   工程よりも動画に結びつく術具（[§1.6](#s1-6)）

**工程**（[§2](#s2)）
4. closure と dissection で 75.6%、最多 / 最少 = 57.8 倍。
   術具注釈の被覆は工程で偏る（disinfection 8.8%、dressing 37.1%、design 58.5%。[§2.1](#s2-1)）
5. 工程は行単位ではほとんど変わらない。隣り合う行の 98.2% が同じ工程で、境目の行は 3.5%（[§2.5](#s2-5)）
6. 並びは大筋で参照順に沿うが往復が多い。初出の順序が参照順と一致するのは 9/15 動画、位置で比べた順守率は
   0.942〜0.953。一方、区間の遷移で参照順に前向きなのは
   197/305（0.646）。後戻り 108 回の多くは
   hemostasis → dissection 45 回（9 動画）、dissection → incision 25 回（8 動画）、closure → dissection 12 回（8 動画）。closure が現れる 12 動画のうち
   8 動画で closure の後に別の工程へ戻る。closure の無い動画は 09、14、15
   （dissection で終わる）（[§2.6](#s2-6)〜[§2.10](#s2-10)）

**術具 × 工程**（[§3](#s3)）
7. ほぼ 1 工程に専属する術具がある（P(工程 | 術具)、[§3.1](#s3-1)）。Needle Holders → closure 99.9%、
   Skewer → design 99.7%、Bipolar Forceps → hemostasis 98.0%、
   Scalpel → incision 97.4%、Syringe → anesthesia 84.2%。
   逆向きの在率（[§3.3](#s3-3)）も anesthesia の Syringe 95.2%、
   incision の Scalpel 94.6%、design の Skewer 90.5% と高い
8. dissection に専属の術具は無い。在フレームの 75% 以上が dissection にある 5 術具（Electric Cautery・Hook・Scissors・Raspatory・Retractor）は
   lift 2.25〜2.52 だが、dissection での在率は最大でも 42.0%（[§3.3](#s3-3)・[§3.5](#s3-5)）
9. 陰性対照群は工程をまたいで広く出る。実効工程数 3.14〜4.13
   （[§3.2](#s3-2)）。Mouth Gag の動画一つ抜きの AUROC は 0.361（[§3.10](#s3-10)）
10. 術具の顔ぶれが似ていて区別しにくい工程の組は anesthesia ⇄ irrigation（0.82）、dissection ⇄ hemostasis（0.81）（[§3.8](#s3-8)）。
    dissection ⇄ hemostasis は区間の遷移でも 102 回往復する（[§2.4](#s2-4)）
11. 術具集合だけで工程はかなり決まる。集合ごとの最多工程を当てる規則で frame accuracy 91.3%（同じデータ）、
    75.1%（動画一つ抜き）。常に closure と答える基準は 42.7%（[§3.10](#s3-10)）
12. 工程が変わると術具集合もほぼ変わる。隣り合う注釈フレームで工程が変わる対の 92.6% で
    術具集合が変わる（工程が同じ対では 30.5%。[§3.13](#s3-13)）

**手**（[§4](#s4)）
13. 手は 99.7% のフレームに写り、自分の手は 97.0%、他者の手は 73.2%。
    他者の手の在率は工程で 9.1〜97.7% と変わる（[§4.2](#s4-2)）
14. 術具 box の 60.3% が手と重なる（IoU > 0.1）（[§4.3](#s4-3)）

**注意**
- 旧 EDA の手の値は出所の違う注釈から計算されていて、本書とは合わない（[付録 C](#sC)）
- 公式 split では disinfection × val、disinfection × test、irrigation × val の術具注釈フレームが 0（[§5.1](#s5-1)）

### <a id="s0-4"></a>0.4 用語と記号

| 記号 | 意味 |
| --- | --- |
| 在フレーム | その術具の box が 1 個以上あるフレーム（同じ術具が 2 本写っても 1 と数える） |
| 在率 | 母集団のフレームのうち在フレームの割合 |
| P(工程 \| 術具) | その術具の在フレームのうち、各工程に属する割合（行で 100%） |
| P(術具 \| 工程) | その工程のフレームのうち、その術具が写っている割合（工程ごとの在率。多ラベルなので工程内で合計は 100% にならない） |
| 工程内構成比 | その工程での術具の在フレーム数を全術具で合計し、各術具の占める割合（工程ごとに 100%） |
| lift | P(術具 \| 工程) / P(術具)。1 より大きいほどその工程に偏る。0 はその工程で一度も出ない |
| † | 術具注釈のあるフレームが 200 未満の工程（disinfection 11, irrigation 177, dressing 119）。割合は不安定 |
| 群 | `context/conventions.md#det_groups` の標的群（5）・陰性対照群（4） |
| 区間 | 同じクリップ内で同じ工程が連続する範囲。長さは工程 CSV の行数で数える（フレーム番号は欠番を含むため） |
| 進行度 | 動画ごとに工程 CSV の全行を時系列に並べた順位を 0（開始）〜1（終了）に正規化した値 |
| 参照順 | disinfection → design → anesthesia → incision → dissection → hemostasis → irrigation → closure → dressing（標準の手術の流れ）。本書の工程の列はすべてこの順 |
| 工程の略号 | DI = disinfection、DE = design、AN = anesthesia、IN = incision、DS = dissection、HE = hemostasis、IR = irrigation、CL = closure、DR = dressing |
| 手 | 「自分」はカメラを着けた術者、「他者」はそれ以外の人の手（raw02 の First Person / Other Person） |

- 術具の並びは §1 では box の多い順、§3 では最頻工程の順（同じ最頻工程の中ではその工程への集中度の高い順）

## <a id="sC"></a>付録 C：旧文書と値が違う箇所

同じ母集団・同じ定義の値は旧文書と一致する（例: 術具 box の最多 / 最少 29.1 倍、工程の最多 / 最少 57.8 倍、隣り合う行が同じ工程である割合 98.2%、旧 A §21 の順守率 0.943、画像端に接する box 34.3%）。違うのは次の箇所である

| 箇所 | 旧文書 | 本書 | 理由 |
| --- | --- | --- | --- |
| 手の注釈の出所（§4 全体） | A §3・§14・§18・§22、D §6 は `egosurgery_tool_hand/` の手 | raw02（[§0.1](#s0-1)） | 2026-07-29 に raw02 を正本と決めた（`docs/experiment_log.md`）。手の box 数はクラス × split の単位で 4 クラス版と raw02 で同じだが、どのフレームに付くかが違う。さらに A §14・§18・§22 が使った 19 クラス版 `instances_*.json` は手の box を画像 ID で結合しており、4 クラス版（`egosurgery_tool_hand/{split}.json`）とファイル名で照合すると手の box が一致するフレームは train 16.5%（1,595/9,657）、val 100.0%（1,515/1,515）、test 32.5%（1,384/4,265）。4 クラス版は画像が train 30、test 10 枚少なく、その分だけ ID がずれる |
| 工程ごとの手あり率（§4.2） | A §14 は dressing 0.10 など | dressing 95.8% など | 出所の違いに加え、A §14 は train の手だけを読み、val・test のフレームを「手なし」として分母に入れていた |
| A §14 の「平均手数」 | 手のクラスの種類数の平均 | §4.2 は手の box 数の平均 | 定義を変えた |
| 術具の面積（§1.3） | D §1 の「平均面積(px²)」 | 「面積の中央値」 | D §1 の値は実装上は中央値だった（`np.median`）。値は同じ |
| P(術具 \| 工程)（§3.3） | D §3a は分母が box 1 個以上のフレーム（15,314） | 分母は術具注釈のある全フレーム（15,437） | box 0 個の 123 フレームを含めるかの違い |
