## 1. 改訂後の中核方針（新フレーム）

- **コア主張**: 「最良の組み合わせ発見」ではなく **タスク結合の原理提案**（指導コメント②への応答）。
- **研究順序**: **分析ファースト** = 既存結合を複数試す → 単一タスクとの Δ を測る → 差の要因を分析 → 観察から結合仮説を立てる（STEP A–D）。
- **当面のスコープ**: **術具検出 × 工程認識の2タスク結合**。手検出は検出タスク内の追加（別の結合軸にはしない）。**関係（mask 依存）と Exo 多視点は Phase-2 に延期**。
- **仮説プール（格下げ）**: H-C（不確実性駆動の双方向結合・最大の新規性）/ H-A（トリプレット畳み込み・統一の土台）/ H-H（ラベル効率結合・価値の示し方）。STEP C の観察で選ぶ/作り直す候補。
- **二段構え（保持）**: Δ が有意でなくても「既存結合の異粒度・open surgery 挙動の体系的分析」「未ベンチマークモデルの初評価（D-A/D-B）」で論文が成立。

### §1 研究のゴール（刷新）
- §1.1 長期: 4タスク（検出・手・工程・関係＋将来の動作）統合の Ego 認識（**維持**）。
- §1.2 短期スコープ: **検出×工程の2タスク結合**を主軸。手検出は検出タスク内（15 tool＋4 hand）。**結合の原理を主張**し、分析ファーストで仮説に至ると明記。Phase-0/Phase-1 構成は維持し、関係(mask)/Exo は Phase-2 と対応づけ。
- §1.3 含めない: 動作レベル、Exo 推論利用（維持）。関係・Exo を「当面のコア外（Phase-2/将来）」と明記。

### §2 研究の問いと仮説プール（刷新・最重要）
- 冒頭: 研究の中央問い = **「異粒度（検出=疎instance × 工程=時間区間）のタスク結合は、単一タスクに対し精度をどう・なぜ変えるか。その観察から、いつ・どう繋ぐべきかの結合原理を導けるか」**。
- **方法論（分析ファースト）**: 既存結合を複数実装→Δを実測→要因分析→仮説。新結合を先に賭けない理由（motivation の強さ・negative transfer の実証・最悪でも分析が貢献）を明記。
- **結合効果予測（旧 H1/H2 を内包）**: ①工程文脈→検出（形状類似・遮蔽・クラス不均衡の救済、Δ mAP）②object-centric 表現→工程（境界信号、Δ Phase F1）。これらは「結合で何が改善するかの予測」であり、検証対象。
- **仮説プール**: H-C（不確実性駆動の双方向結合）/ H-A（トリプレット畳み込み）/ H-H（ラベル効率）。各々の4層上の位置と「STEP C の観察で選ぶ/作り直す」位置づけ。
- **延期**: H3（関係・mask）/ H4（Exo）を Phase-2 と明記（捨てない）。
- §2.5 成功条件（刷新）: (a) 検出単独 = S0-frozen、(b) 工程単独 = S4 を「比較の三角形」の分母とし、結合がこれらを上回るか（Δ>0）。(c) Exo 対照は Phase-2。
