## 1. 問い（yes/no で答えが出る一文）

候補 0 で保存される backbone の特徴（フレームごと 2048 次元）の上で、比較の相手（依頼文 §2 の塔の時間ヘッド）を単方向（過去のみ）の選択的 SSM に替えたとき、val の macro Jaccard（動画単位 5 折の平均）が比較の相手より +1.0 pt 以上高く、かつ val の frame accuracy が同方向か。

## 2. 最も近い先行研究三件（著者・年・DOI か arXiv ID・設定・効果量）

1. **A-19** Oh, Sun 2026, SurgicalMamba（arXiv 2605.14889、プレプリント v3）。設定: Mamba2 の SSD を二経路、online・過去のみ（著者の主張）、ConvNeXt を一部凍結、7 ベンチマーク（Cholec80、AutoLaparo、HeiCo ほか）、1 fps 内視鏡。効果量: 要旨で Cholec80 Acc 94.6・Jaccard 82.7（+0.7・+2.2 pp）、AutoLaparo Acc 89.5・Jaccard 68.9（+1.7・+2.0 pp）、HeiCo Jaccard +3.3 pp（Table 7）。地図の不審点: 要旨は厳密な online と書くが README は 10 秒の境界の緩和に従う（§6）。設定の違い: end-to-end に近い学習、内視鏡、1 fps、学習本数 10〜40 本、分割 1 つ。
2. **A-18** Wu ほか 2025, HID-SSM（arXiv 2506.21330、プレプリント）。設定: 二段階（時空間の事前学習 1 epoch の抽出器＋局所と大域の SSM の頭）、因果的な版あり、Cholec80・MICCAI2016・HeiChole。効果量: 要旨で従来の最良に対し Cholec80 +2.8%、MICCAI2016 +4.3%、HeiChole +12.9%（指標名は地図に無い。A2g は定量の根拠に採らない）。設定の違い: 進捗の教師と抽出器の事前学習が同時に入り、SSM 単独の効果と分かれない（§5）。
3. **A-16** Cao ほか 2024, SR-Mamba（arXiv 2407.08333、プレプリント）。設定: ResNet34 特徴＋Mamba の decoder、双方向（未来を使う）、Cholec80・CATARACTS。効果量: Cholec80 AC 92.6±8.6、JA 81.5±8.6。anticipation の損失で約 +0.5 pp。設定の違い: 双方向なので本案の online-causal の前提に合わず、本案は単方向に直した形で書く（依頼文 §3 の 1）。

## 3. 先行研究がやらなかった／効かなかった理由の推定

## 4. 否定的な先行研究二件

1. **A-107** Soydan ほか 2026, TIDES（arXiv 2605.09742）。Fading Flash の sweep（seed 0 の一回）で test Δ=0.1 の relative error が TIDES 6.56 に対し Mamba-3 141.20、Mamba-2 154.08。学習時の Δ の範囲外で Mamba の誤差が急増する。本案との関係: 区間の境で持ち越す本案では、境の前後の実時間の間隔が学習時と違う分布になりうる（その長さは「依頼文に無い」）。
2. **A-108** Jung ほか 2026, MASCIT（arXiv 2609.34409）。34 の不規則な時系列で、full selectivity が partial selectivity より不利な傾向。MASCIT と ROCKET の Holm 補正の Wilcoxon は p=.394 で有意でない。本案との関係: 選択性の強さが少数データでは利点にならないことがある。
3. 補足（backbone 側の否定例で、時間ヘッドの証拠ではない）: **A-43** EndoMamba は EgoSurgery の凍結 probe で F1 13.90／J 10.32（A-02 の Table 3）。SSM を含む基盤モデルが EgoSurgery で下位だが、これは表現の比較であり時間ヘッドの比較ではない（§5 の A-02）。

## 7. 成功の閾値（主判定規則）

**三版の改訂（2026-10-23。利用者の決定 J1）。** 判定は点推定でなく区間で書く。5 折りの対応差（腕2 − 腕1。各折りは seed 2 本の平均）の平均 d̄ と標準誤差 SE から、区間 d̄ ± t(4, 0.975) × SE を作る。区間の下端が 0 を超えたら採る。区間の上端が下の閾値（元の #7 の値）未満なら捨てる。それ以外は保留。frame accuracy の同方向要件（val の 5 折り平均の差 ≥ 0）はそのまま。test は使わない。元の #7 の閾値は「捨てる」側の境として残す。

val の macro Jaccard（動画単位 5 折の平均）で、本案 − 比較の相手 ≥ +1.0 pt。かつ 5 折のうち 3 折以上で差 > 0。かつ val の frame accuracy の 5 折平均の差 ≥ 0（同方向要件。依頼文 §1）。test の値は使わない。val の動画がほかの折りで test になる点は起票者が prereg に書く（依頼文 §3 の 5）。

## 8. 失敗の閾値と、失敗時に捨てるもの（案／設計／問い）

**三版の改訂（2026-10-23。利用者の決定 J2）。** 掃引の最良点の val の値で判定しない。最良点を別の seed 集合で学び直した値を判定に使い、最良点の元の値・追試の値・掃引全点の中央値を並べて報告する（上振れの大きさを値として出す）。

## 9. 最安の殺し実験

**三版の改訂（2026-10-23。利用者の決定 J3）。** 殺し実験の停止線は「腕2 の 3 seed 平均 ≤ 腕1 の 3 seed 平均」のまま。この判定は「進まない」にだけ使い、「採る」判定には使わない（真の差 +1.0 pt の案を約 1/4 の確率で止め、差 0 の案を約 1/2 通す。批判 4-11）。

- 形: 候補 0 で保存される特徴の上で、1 折（折の選び方は起票者。折表は F 2026-09-17）、3 seed、SSM ヘッド（#14 の掃引集合の中央の一点: 状態次元 64、層数 2、学習率は比較の相手と同じ）対比較の相手のヘッド（同じ特徴の上で同じ recipe で学び直す）。収束規則は依頼文 §2（4 epoch 停滞で lr 1/10、さらに 4 epoch で打ち切り、上限 36 epoch）。
- 殺す条件: 3 seed の平均で SSM ≤ 比較の相手（val macro Jaccard）なら 5 折に進まない。
- 特徴が保存されない場合: 1 折だけ backbone を依頼文 §2 の recipe で学び直し、その特徴を両腕に共有する。backbone の学習そのものは本案の問いに入れない。
- 備考: 1 折・3 seed では seed の散らばりが差を覆う可能性がある（Cholec80 で .017、A-74）。殺し実験は「進まない」判定だけに使い、「採る」判定には使わない。

## 14. 初回にセットで試す設定の掃引集合と固定の理由

## 14. 初回にセットで試す設定の掃引集合と固定の理由

**三版の改訂（2026-10-23）。** 進捗の回帰の損失は **MSE**（原典 A-24 式 (5)）。Δ の定義: クリップ内はフレーム番号の差（EDA: 差 1 以外が 3.2%、最大 254）、クリップ間は配布物に無いので上限値と不明フラグの組で与える。二つの意味を一つの値に混ぜない。止め方は候補 0 と同じ。

**掃引する主要因**:

- 進捗損失の重み {0.1, 1.0}
- タスクグラフ {なし, あり}（あり = train 動画の注釈から作る遷移の有無の行列で、遷移が無い工程への予測を推論時に抑える。学べるグラフは使わない。理由: A-24 Table 3 で学べるグラフは悪化）

**固定する交互作用と理由**:

- TCN の構造・受容野: 比較の相手と同じ
- 区間の欠けの立場: 9-D（Δ を入力）。状態は境で初期化しない（持ち越し）。理由: 進捗は区間をまたいで続くので、初期化すると進捗の教師と矛盾する
- 進捗の回帰の損失: L1。理由: A-24 の形（地図に損失の形の記載は無い。推測）
- 学習率: 比較の相手と同じ。理由: 掃引点を 8 に抑える。進捗損失の重みで実効の勾配の大きさを動かす
