# A5 H(tool|phase) の解析的上界

## 計算式と規約

- **対数の底は 2**（単位はビット）
- 術具在否は **15 次元の二値ベクトル**。各術具 t を独立なベルヌーイとみなし、
  `H(tool|phase) = Σ_p P(p) · Σ_t H_b(P(t=1 | p))` で**上界**を与える
  （相互情報を無視して各術具の条件付きエントロピーを足し上げるため、
   真の同時分布の条件付きエントロピー以上になる。これが「解析的上界」の意味）
- `H_b(q) = -q·log2(q) - (1-q)·log2(1-q)`、`q∈{0,1}` のとき `H_b=0`
- **平滑化は行わない**（q=0 または 1 はそのまま 0 ビットとして扱う）。
  平滑化すると上界が人為的に持ち上がるため。**実測値であり推定値ではない**

## 母集団

- 在否ベクトルの総フレーム: **15437**（train/val/test を連結）
- 工程アノテが引けたフレーム: **15437**
- 工程が引けず集計から除いたフレーム: **0**（補完していない）
- 工程 **9** 種 / 術具 **15** クラス
