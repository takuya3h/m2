## 3. B1 run 型ごとの所要時間

装置は RTX A6000 **1 枚**。`--epochs 50`。学習と評価は同一プロセスで、分離して計測していない。

| run 型 | n | 実時間の範囲 |
|---|---|---|
| 空（`b2a_refin_empty`） | 3 | 12.1 〜 13.6 s |
| 予測（`b2a_refin_pred`） | 2 | 16.3 〜 16.7 s |
| 正解（`b2a_refin_oracle`） | 3 | 11.9 〜 19.1 s |
| 正解 ⊕ 予測（`b2a_refin_both`） | 3 | 24.1 〜 30.0 s |

対象 run 名は audit §4.4 の表にある。**予測段 seed42 は命名確認のため単独で実行したため
計時していない（n=2 の理由）。**

起動に約 4.5 秒、1 epoch あたり約 0.4 秒（試走の実測: 5/10/20 epoch で 5.08/5.54/12.26 s）。

**投稿先の判断材料として**: この型の run は一本あたり**十数〜三十秒**である。
契約の見積もり（24h / 29 run ≒ 50 分/run）は検出器の学習を含む前提であり、
工程側だけの縮退では三桁小さい。
