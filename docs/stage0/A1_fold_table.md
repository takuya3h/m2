## 均衡指標の定義

動画集合 S について、

- 工程の比率ベクトル `p(S)`: 工程 9 種それぞれのフレーム数を S の総フレーム数で割ったもの
- 術具の比率ベクトル `t(S)`: 術具 15 クラスそれぞれの box 数を S の総 box 数で割ったもの
- 全変動距離 `TV(x, y) = 0.5 * Σ|x_i - y_i|`（0 が同一、1 が互いに素）

**均衡指標 `d(S) = TV(p(S), p(全15動画)) + TV(t(S), t(全15動画))`。** 小さいほど全体分布に近い。

表の選び方は、折り B〜E の test について次の順に小さくする。

1. `max_f d(test_f)` — 最も偏る折りを最小にする（minimax）
2. `sum_f d(test_f)` — 同点なら総和
3. 動画識別子の辞書順 — それでも同点なら辞書順（SPEC Task B §2 の規則）

折り A の test は公式分割に固定されているため**最適化の対象ではない**。値は参考として併記する。
分け方は全数列挙した（**15400 通り**）ので、選ばれた表は近似ではなく最適である。

## 無作為対照

無作為割り当てを一件作って同じ指標で比べた（**seed = 20260917**、`random.Random(seed).shuffle`）。

| | max d(test) | sum d(test) |
|---|---|---|
| 提案の表 | **0.2844** | **1.0951** |
| 無作為（seed 20260917） | 0.6102 | 1.6287 |

提案の表は無作為より悪化していない（max で比較）。

全数列挙しているため、無作為一件だけでなく**分布全体**と比べられる。
15400 通りの `max d` は、最小 0.2844 ／ 中央 0.5246 ／ 最大 0.7972。提案の表は**最小値そのもの**である。
最良と同点だった分け方は 1 通りで、辞書順で一意に決めた。
