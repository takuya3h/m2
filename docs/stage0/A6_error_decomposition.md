# A6 検出誤りの分解

## 基準（既存の評価実装から取った。新しい基準を発明していない）

出所: `src/egosurgery/metrics/detection.py` の `_compute_similar_confusion`
> 各 GT box を、最も IoU の高い予測 box（**IoU >= 0.5**）にマッチさせ、(GT クラス, 予測クラス) を集計する。

| 区分 | 定義 |
|---|---|
| 正解 | 最大IoU ≥ **0.5** かつクラス一致 |
| 分類誤り | 最大IoU ≥ **0.5** だがクラス不一致 |
| 局在誤り | **0.1** ≤ 最大IoU < **0.5**（位置は近いがマッチ基準に届かない） |
| 見落とし | 最大IoU < **0.1**（対応する予測が無い） |

**IoU 0.5 は既存実装の値。0.1 は「予測が全く無い」と「ズレている」を分けるための下限で、
既存実装には無いため実行者が置いた。この境の位置は結果の解釈に影響する。**

予測の足切り: `score >= 0.05`（mmdet の既定値。`eval_recipe.py:41` の論文設定 1e-8 とは異なる。
1e-8 では 1 画像あたり数百件の低スコア予測が残り、最大IoU マッチが実質的に常に成立するため、
**誤りの分解には既定値を用いた。この選択は実行者の判断である**）

## 母集団

- GT: `data/annotations/egosurgery_tool/instances_val.json`（4707 annotations / 1515 images）
- 予測: `experiments/hand2det_dev/_identity_ctrl_4ch_seed42/predictions/val_ctrl_best.json.gz`
  （454500 件中 score>=0.05 の 21676 件を使用）
