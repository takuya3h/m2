# A2 追加6動画と Phase 公式 test の動画ID重複

## 突き合わせた対象

- 追加動画: `data/raw/OpenSurgery_Dataset/05_egosurgery_hts/egosurgery_tool_bbox/annotations/phase/*.csv`
  のうち動画IDが16以上のもの → **6 動画 / 23 クリップ**
  動画ID: 17, 18, 19, 20, 21, 22
  クリップ: 17_1, 18_1, 18_2, 19_1, 19_2, 19_3, 19_4, 19_5, 19_6, 20_2, 20_4, 20_5, 20_6, 20_7, 20_8, 21_1, 21_2, 21_3, 21_4, 21_5, 22_1, 22_2, 22_3
- 公式 test: `data/splits/ego_test.txt` → **3 動画**: 04, 05, 07
  （参考）公式 val: 09, 10 / 公式 train: 01, 02, 03, 06, 08, 11, 12, 13, 14, 15

## 対応づけの方法

動画IDは `<vid>_<clip>.csv` のファイル名先頭の数値部分。分割ファイルは動画IDを1行1個で持つ。
**両者とも同じ動画ID空間（ゼロ埋め2桁）であることを確認したうえで集合演算した。**

## 結果

| 相手 | 重複件数 | 重複した動画ID |
|---|---|---|
| 公式 test | **0** | （なし） |
| 公式 val | 0 | （なし） |
| 公式 train | 0 | （なし） |

**追加6動画と公式15動画の動画IDは互いに素**（16以上 対 15以下）。

### 空振り確認（陰性対照）

追加動画の集合に公式 test の `04` を混ぜて同じ集合演算をすると: **1 件**（04）
→ 演算は重複を検出できる。上の 0 件は「検出できていない」ではない。
