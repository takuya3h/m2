# A9 工程塔候補の文献値と推論プロトコル

**出所の種別: 起票者の文献確認（2026-08-29）。リポジトリ内の実測ではない。**

典拠: arXiv 2003.10751、2409.12467、2401.11644、2507.03295、Frontiers AI 2026 のレビュー。

## 結論

**文献値を引く比較表は、三属性の列を必須とする。** 別表が必要である。

## 文献値が割れる三属性

| 属性 | 取りうる値 | なぜ割れるか |
|---|---|---|
| **推論様式** | online / offline | offline は未来のフレームを見られる。online は見られない |
| **境界の緩和** | relaxed / strict | 工程境界の前後に許容幅を置くか否か |
| **数値の来歴** | 原著 / 再実装 | 同じ手法でも実装が違えば値が動く |

## 実例

**TeCNO は因果畳み込みによる online 設計である。**

| 条件 | 値 |
|---|---|
| TeCNO 原著 | **88.56** |
| TeCNO 再実装・relaxed | **90.17** |
| offline 系（例） | **94.1** |

**同じ TeCNO でも原著と再実装で 1.6 ポイント動く。**
offline 系の 94.1 は **online と直接比較できない**（見られる情報が違う）。

## 本研究への含意

工程塔の候補を文献値で比較する表を作る場合、**手法名と数値だけの列では誤読を生む。**
三属性の列（推論様式・境界の緩和・数値の来歴）を必ず添える。

本研究の設計は **online（因果）** を前提としている。
offline 系の数値を上限や目標として引くことはできない。
