## 2. run の列挙と M の項目との対応

構成の数と反復から run 本数を積む。**二通りに読める項目は一方に決めず、低い読みと高い読みの幅で出す。**

- **Tier 1 の反復**: 低い読み = 5 折り × 5 seed = **25 本**。高い読み = 折り A だけ受け取り塔が
  3 seed（M §5.1）のため 3×5 + 4×5 = **35 本**。
- **Stage 1 の反復**: 既定 = 全候補を全折りに掛ける（折り A 3 seed + 他 4 折り 1 seed = 7 本 × K）。
  二段選定の読み（折り A で K 候補 → 勝者だけ残り 4 折り = 3K + 4 本）は縮退の段 2 として出す。

**M の項目で run に対応づかないものは零件である**（`--check-coverage` が数える。分母は M の 38 項目）。

## 7. 前提を変えると判定が変わる（感度の例: 1 日あたり 12 時間）

**同じ試算でも、装置を一日あたり何時間使えるかで判定が反転する。**
