# EgoSurgery-HTS フレーム被覆調査レポート

- 作成日: 2026-07-31 (JST)
- 目的: EgoSurgery-HTS 3種（hand / tool / hand-tool セグメンテーション）が、既存の
  `egosurgery_tool`（bbox）および `egosurgery_phase`（工程CSV）に対してどれだけの
  フレームを欠落しているかを網羅確認する。
- 対象:
  - HTS: `data/raw/OpenSurgery_Dataset/{02_hand,03_tool,04_handtool}/json_per_video/`
  - tool bbox: `data/annotations/egosurgery_tool/instances_{train,val,test}.json`
  - phase: `data/annotations/egosurgery_phase/*.csv`
- 対象動画: 15本 / 26セグメント（01_1〜15_2）

---

## 1. 集計方法（重要な前提）

- HTS の `json_per_video/<seg>/*.json` は `images` フィールドに動画全体
  （例: 03_1/03_2/03_3 で 1472枚共通）を列挙するため、実アノテーション数は
  `annotations[].image_id` 経由の**集合**で数える必要がある。
- ファイル名を全ソースで基底名（`01_1_0059.jpg` 形式）へ正規化してから集合演算。
- phase CSV は 4桁フレーム番号（例 `01_1_0001`）。tool bbox の `file_name` は
  `train/01/01_1_0124.jpg` のようにディレクトリを含むので `basename` を取る。

## 7. 実験計画への含意

1. **完全欠落セグメントは 3件のみ**
   - `03_3`（HTS 3種全欠落・168f・phase側のみ）
   - `03_1`（HTS/toolのみ 127f 欠落）
   - `12_2`（HTS/handtoolのみ 8f 欠落）
   - **全15動画のうち HTS 完全欠測動画は 0本**（どの動画も少なくとも 1セグメントは HTS を持つ）。
2. **tool_bbox との整合性は非常に高い**
   - HTS/hand は tool_bbox のフレームを **99.7%** カバー。
   - HTS/handtool でも **97.0%** カバー。
   - 既存 tool_bbox 実験のフレーム集合を基準に HTS マスクを付加するのは実務的にほぼ問題なし。
3. **phase 基準では 10.7〜13.1% 欠落**
   - phase 認識タスクの全フレームで HTS 特徴を使いたい場合、欠落フレームは
     疑似ラベル生成 or 隣接フレーム補間が必要。
4. **要警戒セグメント**（tool_bbox 基準 5%以上欠落）
   - `05_2`（HTS/tool 42.0%欠落, HTS/handtool 4.9%）
   - `05_1`（HTS/tool 18.0%欠落）
   - `12_1`（HTS/handtool 20.4%欠落）
   - `08_2`（HTS/handtool 9.6%, HTS/tool 5.6%）
   - `07_1` / `07_2`（HTS/handtool 7.2〜7.3%欠落）
   - `08_1`（HTS/handtool 5.9%, HTS/tool 4.5%欠落）
   - これらセグメントで HTS を学習/評価に使う場合は、欠落フレームを split から
     除外するか疑似ラベルで埋めるか、事前に個別判断が必要。
